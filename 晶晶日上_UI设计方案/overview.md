# 晶晶日上 · 全新界面设计方案（暖墨设计系统 v1.0）

交付物：`index.html`（可点击的全量高保真原型 + 设计系统，浏览器直接打开）
设计方向：**近黑舞台 · 暖调赤陶**，参考即梦的「界面中性、内容发光」策略，功能与现网 12.3.1+22 版本**逐页对齐**。

---

## 一、这次改了什么

| 维度 | 旧版（曜石流光） | 新版（暖墨） |
|---|---|---|
| 底色 | 曜石蓝黑 + 液态流光背景 | 暖黑 #0B0A0A（即梦式近黑，但偏暖） |
| 角色 | 玻璃拟态 + 炫光，界面本身抢戏 | 界面中性扁平，把光留给 AI 成片与剧集海报 |
| 主色 | 香槟金 + 冷青 | 赤陶 #E4703F（主行动/价格）+ 陈金 #D9AE5C（圆梦/席位） |
| 质感 | 毛玻璃模糊 + 大面积流光 | 舞台环境光斑 / 噪点肌理 / 渐变描边 / 悬浮玻璃底栏 |
| 底栏 | 贴底 5 槽 | 悬浮玻璃胶囊 + 中央凸起创作键（保留原结构） |
| 表单页 | 暗底玻璃，阅读负担重 | 高对比文字 + 中性卡片，长文/合同/订单可读性优先 |

**为什么保留暖调而不是照搬即梦的冷黑**：晶晶日上不是纯创作工具，还有祝福、定制剧、圆梦席位与交易。全冷黑会让「圆梦 / 做主角」的情感温度消失，所以底色加暖、强调色保留赤陶金。

## 二、质感层（让深色不"素"的六件事）—— v2 显著加强版

> 旧版数值偏弱（光斑 .22、噪点 0.05、玻璃反光 0.045），在原型上肉眼几乎不可见。v2 把光斑搬进屏幕可见区、噪点提到 0.22 + soft-light、玻璃顶反光提到 0.85、并给手机加了顶部聚光 + 暗角。

1. **舞台环境光 v2** —— 4 个色光覆盖屏幕可见区：左上赤陶 .58（聚光，强度×2.7）+ 右上陈金 .48（反光，×3）+ 左下松墨 .16（余绿）+ 底部暖意 .34；外加顶部 160px 赤陶聚光带和 .phone::before 的整面顶部 wash（暖橘 .55）
2. **噪点肌理 v2** —— 22% soft-light 模式（取代原来的 5% overlay，因为 overlay 对深色几乎无效）+ 颗粒更密 `baseFrequency 1.1`，肉眼可辨的纸感
3. **玻璃分层 v2** —— 卡片顶反光提到 .85（原来 .20），底色 `#1C1816`（比 --surface 略暗）以让顶反光更突出；落影 14×32 rgba(0,0,0,.55)；appbar 玻璃透明度 .62→.40 让光斑透下来
4. **渐变描边** —— 主推卡 / 选中态用 mask-composite 做 1px 渐变描边 + 落影 (10×32 rgba(228,112,63,.18))，表达"被点亮"
5. **戏剧光效 v2** —— 主 CTA 辉光 14×36 (.55)，FAB 18×40 (.65) + 1px 高光内圈；chip 背景加 18%/38% 反光内圈
6. **Bento 错落** —— 浏览型页面（艺人广场、首页金刚区）用大小错落模块，让信息密度产生节奏
7. **手机壳 v2** —— `radial-gradient(120% 70% at 50% -8%, #1B1715 → #080706)` 顶部聚光底；::before 加追光 + 底部暗角；::after 内描边 + 顶部反光 + 底部内阴影

## 五、研发落地要点（Flutter）

1. **Token 化**：所有色值、圆角、间距、字阶以 CSS 变量为唯一来源，落地时 1:1 映射到 `app_theme.dart`，页面禁止硬编码。
2. **质感层实现顺序**：先换 token（1 天）→ 再加顶部聚光与手机壳 v2（0.5 天）→ 再加噪点 soft-light 与玻璃分层（0.5 天）→ 再做悬浮底栏与渐变描边（1 天）。可分阶段上线。
3. **性能注意**：环境光用静态径向渐变（非实时模糊）；噪点为 200×200 平铺贴图（v2 已加密），避免逐帧生成；`backdrop-filter` 仅用于顶栏与底栏两处；soft-light 在低端机上注意 GPU 合成成本，必要时退回 overlay。
4. **与 Gate0 性能治理的关系**：本次仅改视觉层，未触碰 `main_scaffold` 的 AnimatedSwitcher / IndexedStack 结构。建议在主 Tab 保活（F-R1）落地后再切这套主题，避免性能归因混乱。
5. **待甲方确认**：主 CTA 采用「亮珊瑚 + 深字」，与旧版「金渐变 + 深字」差异较大，需品牌方确认；若不接受，可退回 `#C0532F → #9E4023` 配白字方案（对比度 4.6:1 同样达标）。
