Daylight Design System v1.0
暖光浅色 · 亲和叙事 —— 面向「让普通人做自己人生主角」的全新视觉体系

设计定位 · 为什么是近黑

参考即梦的处理：界面本身保持中性、扁平、不发光，让 AI 生成的内容成为画面里唯一亮的东西。但晶晶日上不是纯创作工具——它同时有祝福、定制剧、圆梦席位与交易，所以底色取暖黑 #0B0A0A（而非即梦的冷黑 #040404），强调色保留赤陶 + 陈金，冷中带暖，既是"舞台"也是品牌。

原则一
光给内容，不给界面
卡片只有 1px 暖描边与极弱渐变，不做彩色块、不做强阴影
原则二
用光斑造舞台
顶部赤陶聚光 + 右侧陈金反光，呼应「做自己人生的主角」
原则三
暖调对抗塑料感
叠 5% 噪点肌理，中和纯数字界面常见的冰冷质感

色彩体系

正文对比度 ≥ 4.5:1（WCAG AA）。主色赤陶 #E4703F 在暖黑底上 6.6:1，可直接承载文字与价格；主 CTA 用亮渐变 + 深字，白字方案在亮渐变上无法达标，故不采用。

质感层 · 让界面「不素」的五件事

深色界面最容易做成「一片黑 + 白字」。真正拉开差距的是下面这五层，全部可用 CSS 实现，不增加研发负担。

01 · 舞台环境光
三层大半径径向渐变：顶部赤陶、右上陈金、底部余晖。固定在手机框背景层，不随内容滚动。
02 · 噪点肌理
SVG feTurbulence 生成的颗粒，5% 透明度 + overlay 混合，中和数字界面的塑料感。
03 · 玻璃分层
卡片 = 微渐变底层 + 顶部一道高光 + 极弱描边；顶栏与底栏用 backdrop-filter 真模糊。
04 · 渐变描边
主推卡与选中态用 mask-composite 做 1px 渐变描边，比单色描边更能传达「被点亮」。
05 · 戏剧光效
立即录制
主 CTA 用亮珊瑚渐变 + 深字 + 内高光 + 24% 辉光；深字方案是白字在亮渐变上达不到 4.5:1 的必然选择。
06 · Bento 错落
浏览型页面用大小错落的模块网格（艺人广场、首页金刚区），让信息密度本身产生节奏。

字阶与排版

单一无衬线字族（PingFang / HarmonyOS Sans），靠字重与字号建立层级。数字统一 tabular-nums，价格与关键数字用赤陶→珊瑚渐变裁切文字。
