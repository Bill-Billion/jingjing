## 三、前端部署（APP）

### 3.1 安装依赖

```powershell
cd C:\Users\user\Doubao\chats\2026-08-24\new-chat-3\work\app\jingjingshangri_app
flutter pub get
```

### 3.2 配置服务器地址

编辑 `lib/services/api_service.dart`，确认默认地址：

```dart
// 同一WiFi局域网（手机和电脑同一网络）
static const String lanUrl = 'http://192.168.1.82:3000';
static const String defaultUrl = lanUrl;

// Android模拟器使用
static const String emulatorUrl = 'http://10.0.2.2:3000';
```

> 注意：192.168.1.82 是本机局域网IP，更换网络后需用 `ipconfig` 查看新IP并修改。

### 3.3 编译APK

```powershell
$env:JAVA_HOME = "C:\src\jdk17"
$env:PATH = "C:\src\jdk17\bin;$env:PATH"
flutter build apk --release
```

APK输出路径：
```
build\app\outputs\flutter-apk\app-release.apk
```

### 3.4 安装到手机

```powershell
# 方式一：USB连接手机，开启USB调试
flutter install

# 方式二：直接传APK文件到手机安装
```

### 3.5 APP内切换服务器地址

APP安装后，进入「我的 → 设置 → 服务器地址」，可快速切换：
- **局域网**：http://192.168.1.82:3000（同一WiFi）
- **模拟器**：http://10.0.2.2:3000（Android模拟器）
- **公网**：部署到云服务器后填写公网IP/域名

## 五、常见问题

### Q: 后端启动报 "no such column" 错误
A: SQLite要求字符串用单引号。已修复全部路由文件，如新增代码注意SQL语法。

### Q: 手机APP连不上后端
A: 1) 确认手机和电脑同一WiFi；2) 用 `ipconfig` 确认电脑IP；3) 电脑防火墙放行3000端口；4) APP设置页切换地址。

### Q: 防火墙放行3000端口
```powershell
New-NetFirewallRule -DisplayName "JingJingShangRi API" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

### Q: 登录验证码是多少
A: 开发环境固定为 `123456`，任意手机号均可登录。

### Q: 如何停止后端服务
```powershell
Get-Process node | Stop-Process -Force
```

### Q: 数据库重置
```powershell
Remove-Item jingjingshangri.db
node db.js
node seed.js
```
