# 晶晶日上 ·「追光」交互设计方案

**设计方向：** A追光 — 电影感暖金路线  
**核心理念：** 每个人都是人生的主角，APP是你的摄影棚和放映厅  
**设计原则：** 让每一次操作都像"灯光暗下、大幕拉开"——有仪式感，但不拖沓

---

## 一、信息架构

### 1.1 底部导航：5 Tab（4+1创作键）

```
[首页] [剧场]  [✦发光]  [消息] [我的]
```

| Tab | 名称 | 定位 | 核心内容 |
|-----|------|------|----------|
| 1 | 首页 | 发现/逛 | 艺人瀑布流、场景分类、Banner推荐 |
| 2 | 剧场 | 内容/投 | 定制剧项目、认投角色、彩蛋档、抽奖 |
| ✦ | 发光 | 创作中枢 | 底部弹出三选一（见下） |
| 4 | 消息 | 沟通 | 订单消息、艺人/客户对话、系统通知 |
| 5 | 我的 | 个人 | 数字人、订单、钱包、MCN、设置 |

**「发光」按钮设计：**
- 不是简单的+号，而是一个**聚光灯图标**（圆形光晕+光束）
- 点击后：按钮自身发出金色光波（涟漪扩散），同时底部弹出创作面板
- 面板三个选项，像电影开拍前的三个选择：
  - 🎬 **我要录视频**（已有数字人的艺人接单）
  - ✨ **创建数字人**（新用户上传照片生成分身）
  - 🎥 **发起定制剧**（我要当主角，5000元起）
- 每个选项有一行副标题说明，点击后进入对应流程

### 1.2 页面层级（最多3层）

```
一级Tab页
  └─ 二级详情页（艺人详情/项目详情/订单详情）
       └─ 三级操作页（下单/支付/录制/评价）
```

**原则：** 任何功能3步内可达。超过3步的流程用**步骤条**（stepper）展示进度，让用户知道"还有几步"。

## 二、核心用户流程

### 2.1 首次启动流程

```
启动页（0.8s）→ 引导页（3页可跳过）→ 首页（自动定位到推荐Tab）
                          ↓
                   最后一页CTA："开始我的主角之旅"
                          ↓
                   不强制登录！先逛，下单时再登录
```

**启动页：** 黑场→Logo从中心发光浮现（像电影开场的厂标动画）→"晶晶日上"四字渐显→光线扫过→淡出

**引导页（电影预告片风格）：**
- 第1页："每个人都有属于自己的光"（数字分身概念图）
- 第2页："让喜欢的人为你而来"（祝福视频概念图）
- 第3页："这一次，你是主角"（定制剧概念图）
- 每页背景图全屏+底部渐变遮罩+文字，滑动时有**视差效果**（背景图移动比文字慢）

### 2.2 下单祝福视频（核心转化路径）

```
首页/艺人列表
  ↓ 点击艺人卡片（共享元素转场：照片放大展开）
艺人详情页
  ↓ 选择套餐（99/299/1999三档横滑选择器）
  ↓ 点击"立即录制"
下单页（底部弹出半屏模态）
  ├─ 选择场景模板（生日/婚礼/企业...横滑图标）
  ├─ 填写祝福语（多行文本+字数统计+AI推荐文案按钮）
  ├─ 收件人信息（送给谁？可选）
  ├─ 交付时间提示（48小时内）
  └─ 底部：价格明细 + "支付¥99"按钮
  ↓ 点击支付
支付页（全屏模态）
  ├─ 支付方式选择（微信/支付宝，图标横排单选）
  └─ 确认支付
  ↓ 支付成功
成功页（全屏）
  ├─ 金色光粒子动画（2秒）
  ├─ "灯光已亮起，艺人正在准备"
  ├─ 订单号+预计交付时间
  └─ "查看订单" / "回到首页"
```

**关键体验细节：**
- 下单页用**半屏模态**从底部滑入，背景页缩小变暗（像舞台聚光灯效果）
- 支付成功动画是**电影开拍板**："Action!"打板声+光粒子
- 等待交付期间，订单状态用**电影制作进度**表达：剧本确认→录制中→后期制作→即将上映

### 2.3 创建数字人流程

```
"发光"→"创建数字人"
  ↓
介绍页（这是什么？3个卖点+示例视频）
  ↓ 点击"开始创建"
Step 1/4：上传照片
  ├─ 拍照/从相册选择
  ├─ 照片要求提示（正脸、光线好、无遮挡）
  └─ 实时检测：照片不合格时给出具体原因
  ↓
Step 2/4：授权确认
  ├─ 一屏一授权（肖像权、使用范围、期限）
  └─ 必须逐条勾选同意
  ↓
Step 3/4：生成中
  ├─ 全屏动画：数字人轮廓逐渐被光线"雕刻"出来
  ├─ 进度条+阶段提示（"正在分析面部特征...""生成表情模型...""渲染中..."）
  └─ 预计等待时间（约2-3分钟）
  ↓
Step 4/4：完成
  ├─ 数字人360°展示（可旋转/试说一句话）
  ├─ "我的数字人已就绪"
  └─ "去接单" / "分享给朋友"
```

### 2.4 定制剧流程（5000元起）

```
剧场→项目详情
  ↓ 点击"我要当主角"
意向金页（底部半屏）
  ├─ 说明：意向金可退，用于启动剧本对接
  ├─ 支付¥500意向金
  ↓
选类型页（全屏）
  ├─ 对标剧类型选择（爱情/武侠/科幻/都市...）
  ├─ 每类有参考海报+风格标签
  └─ 可多选，选完点"下一步"
  ↓
需求沟通页
  ├─ 文字描述你想要的故事
  ├─ 上传参考图/参考剧（可选）
  ├─ 选择主角性别/时代背景/集数
  └─ "提交需求，等待编剧对接"
  ↓
等待对接（状态页）
  ├─ "剧本顾问将在24小时内联系您"
  ├─ 后续改本、报价、选角均在线下商务沟通
  └─ 平台记录进度节点
```

## 三、转场动画体系

### 3.1 转场规范

| 场景 | 动画类型 | 时长 | 缓动曲线 | 说明 |
|------|----------|------|----------|------|
| Tab切换 | 淡入淡出 | 200ms | easeOut | 像电影镜头切换，不滑来滑去 |
| 列表→详情 | 共享元素放大+右滑 | 350ms | easeOutCubic | 艺人照片"放大"成详情页头图 |
| 详情→下单 | 底部半屏滑入 | 300ms | easeOutQuart | 背景缩放0.95+变暗 |
| 支付/确认 | 全屏模态上滑 | 350ms | easeOutQuart | 重要操作全屏覆盖 |
| 返回 | 进场动画的镜像 | 对称 | 对称 | 右进左出、上弹下落 |
| 发光按钮 | 光波涟漪+面板上弹 | 400ms | spring | 有弹性、有仪式感 |
| 引导页滑动 | 视差+缩放 | 300ms | easeOut | 背景慢、文字快 |
| 弹窗/Toast | 缩放+淡入 | 200ms | easeOutBack | 从0.9缩到1.0 |

### 3.2 共享元素转场（重点）

这是"电影感"最关键的细节：
- 首页艺人卡片 → 艺人详情：卡片图片**无缝放大**成详情页顶部大图，名字和价格也对应过渡
- 剧场项目卡片 → 项目详情：海报放大展开
- 视频缩略图 → 视频播放页：缩略图放大成全屏播放器

**Flutter实现：** 使用 `Hero` widget + `PageRouteBuilder` + `Tween<RelativeRect>`

### 3.3 转场禁忌

- ❌ 不要3D翻转、旋转等花哨效果
- ❌ 转场期间不要加粒子/光效（影响性能和流畅度）
- ❌ 不要超过400ms（慢了让人着急）
- ❌ 返回动画不能比进入慢（要"快进慢出"）

## 四、微交互设计

### 4.1 点击反馈

| 元素 | 按下效果 | 音效/震动 |
|------|----------|-----------|
| 主按钮（支付/确认） | 缩放0.97+金色光晕增强 | 轻微震动(HapticFeedback.lightImpact) |
| 艺人卡片 | 缩放0.98+卡片上浮2px | 无 |
| Tab图标 | 选中时金色光晕扩散 | 极轻震动 |
| 发光按钮 | 按压缩放0.9+光波涟漪 | 中等震动+"叮"音效（可关） |
| 心形收藏 | 心形填充+金色粒子爆裂 | 轻震动 |
| 开关/勾选 | 弹性动画 | 轻震动 |

### 4.2 加载状态

**页面级加载（首次进入）：**
- 不用转圈loading，用**骨架屏**（shimmer微光扫过）
- 骨架形状与真实内容一致（艺人卡片骨架、列表骨架）
- 数据加载<150ms时不显示骨架（避免闪烁），>150ms才显示

**按钮级加载（提交/支付）：**
- 按钮变成loading状态：文字消失，金色进度条在按钮内跑动
- 按钮不可重复点击（防重复提交）

**下拉刷新：**
- 自定义动画：一个**聚光灯**从左扫到右，松手时灯光闪一下
- 文案变化：下拉→"灯光准备中..."→释放→"开拍！"→刷新完成

**视频生成等待（2-3分钟）：**
- 全屏沉浸式动画：数字人轮廓被光线逐渐雕刻成型
- 分阶段文案："正在分析面部特征...""生成表情模型...""渲染中..."
- 允许后台运行，完成后推送通知

### 4.3 空状态（电影感表达）

| 场景 | 插画 | 文案 | CTA |
|------|------|------|-----|
| 无订单 | 电影票根+虚线 | "还没有演出记录" | "去发现艺人" |
| 无消息 | 聚光灯照在空舞台上 | "舞台已备好，等你开演" | "去逛逛" |
| 无收藏 | 空的导演椅 | "还没有心仪的主角" | "去发现" |
| 无数字人 | 一个等待被点亮的剪影 | "你的数字分身还在沉睡" | "立即创建" |
| 网络错误 | 电影胶片断开 | "影片卡带了" | "重新连接" |
| 搜索无结果 | 放大镜照在空导演椅上 | "没有找到匹配的演员" | "换个关键词" |

### 4.4 成功/庆祝时刻

- **支付成功：** 金色光粒子从底部升起（持续2秒）+ "Action!"打板动画
- **收到视频：** 推送通知"你的专属影片已上映"，点击后视频像电影首映一样揭幕
- **首次创建数字人：** 数字人在聚光灯下转身亮相
- **订单完成评价后：** "感谢你的掌声" + 优惠券飞入钱包

## 七、动效规范

### 7.1 时长标准

| 类型 | 时长 | 用途 |
|------|------|------|
| 微反馈 | 100-150ms | 按钮按下、开关切换 |
| 小动画 | 200-300ms | Toast、弹窗、Tab切换 |
| 转场 | 300-400ms | 页面跳转、模态弹出 |
| 庆祝动画 | 1000-2000ms | 支付成功、首次创建 |
| 进度动画 | 持续 | 生成中、上传中 |

### 7.2 缓动曲线

- **标准：** `Curves.easeOutCubic`（快速进入，柔和结束）
- **弹性：** `Curves.easeOutBack`（弹窗、按钮回弹）
- **线性：** 仅用于持续循环动画（shimmer、loading旋转）
- **自定义：** 发光按钮用spring（damping: 15, stiffness: 200）

### 7.3 色彩与光效

- **主光效：** 暖金 `#F5A623` 的glow，用`BoxShadow`实现
- **聚光灯：** 径向渐变，从中心暖白到边缘透明
- **粒子：** 仅用于庆祝时刻（支付成功/收到视频），不滥用
- **shimmer：** 从#1a1a2e到#252535的微光扫过，1000ms循环

### 7.4 性能要求

- 所有动画60fps，不在主线程做重计算
- 转场期间不触发网络请求
- 图片用`cached_network_image`缓存
- 列表用`ListView.builder`懒加载
- 粒子动画限制在50个以内
- 低端机自动降级（关闭粒子/模糊效果）

## 九、声音与触感

### 9.1 音效（可在设置中关闭，默认开启）

| 场景 | 音效 | 音量 |
|------|------|------|
| 发光按钮点击 | "叮"（清脆铃声） | 30% |
| 支付成功 | 电影开场铃音（2秒） | 40% |
| 收到视频 | "Action"打板声 | 40% |
| 收藏/点赞 | 轻快"啵"声 | 20% |
| 下拉刷新释放 | 场记板"咔"声 | 20% |

### 9.2 震动反馈

- 按钮点击：`HapticFeedback.lightImpact()`

## 十一、Flutter技术实现要点

1. **主题：** `ThemeData` 统一配置，主色`#F5A623`，字体`SourceHanSerif`(标题)+`PingFang`(正文)
2. **路由：** `GoRouter`管理，自定义`CustomTransitionPage`实现共享元素转场
3. **Hero动画：** 艺人卡片图片、海报、视频缩略图全部用`Hero`+统一tag规则
4. **骨架屏：** `Shimmer.fromColors`包裹，骨架组件与真实组件同构
5. **毛玻璃：** `BackdropFilter`+`ImageFilter.blur(sigmaX: 20, sigmaY: 20)`
6. **粒子：** `particles_flutter`或自定义`CustomPainter`，限制50粒子
7. **状态管理：** 继续用`setState`+`FutureBuilder`，不引入新框架
8. **缓存：** `cached_network_image`图片缓存，`shared_preferences`存配置
9. **震动：** `HapticFeedback`系列方法
10. **音效：** `audioplayers`包，assets存5个短音效（总计<200KB）
