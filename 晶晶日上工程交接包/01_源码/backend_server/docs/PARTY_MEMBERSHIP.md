# 个人、机构和成员邀请：本轮服务器实现边界

代码在src/modules/party/repository.js，通过createPartyRepository(db, {resolvePrincipal})构造，使用现有MySQL事务连接。SQL和事务内的权限检查集中在本模块；没有新增框架或外部服务。尚未挂载HTTP路由，也未替换旧登录。

## 可信身份与允许的操作

resolvePrincipal必须由服务器的可信登录层提供，返回稳定、不含手机号/令牌/秘密的subject_ref及request_id；默认返回null，因此默认所有操作拒绝。绝不能把请求体或旧JWT中的角色直接作为这个回调的结果。这里只检查已由该边界确认的账号、当前账号状态和机构关系，不宣称已完成短信/会话验证。

- registerAccount：可信登录主体首次创建账号和个人主体，重复调用不改已有显示名或身份；个人主体仍待审核，不等于实名。
- createOrganization：账号创建待审核机构，得到OWNER用于准备申请和组建团队；不是平台管理员或机构审核通过。
- requestCapability：AUTHOR、SCRIPT_SUPPLIER、PRODUCER、MCN、BRAND_CLIENT可分别申请，保存PENDING_REVIEW；不提供自行批准入口。
- inviteMember/respondInvitation/revokeInvitation：只有OWNER可发邀请/撤回；目标账号自己接受/拒绝；接受得到固定MEMBER，不能由请求指定OWNER。必须显式提供UTC截止时间，无默认业务期限。邀请人失去有效管理权限，未接受的邀请不能再授予身份。
- removeMember：OWNER移除本机构普通成员，不能移除OWNER，不删除历史。再次邀请接受形成新的确认记录。
- listParties/listInvitations：只列本账号有效成员关系及发给本人的邀请；停用机构不返回可执行动作。列表是内部结果，公开分页/DTO另按契约实现，不能直接无界暴露HTTP。
- assertPermission：允许READ_PARTY及OWNER的REQUEST_CAPABILITY/MANAGE_MEMBERS；未知操作默认拒绝。列表里的allowed_actions只是显示提示，修改操作始终在自己的事务里重新检查，不能把一次预检查用于未来的付款或其他业务。

组织成员不是MCN旗下艺人商业关系；所有者/成员均无收款、平台管理、作品使用、读取艺人收入权限。待审核机构允许准备工作，不自动启用商业能力。账号ACTIVE仅表示账号未停用，不表示实名通过。

## 请求重放、并发和历史

变更要求operation_key，更新现有对象另要求expected_version。机构范围变更先锁定机构行，再核对当前账号/成员权限，检查重复请求，最后改变数据；不同机构可独立进行。请求摘要只含这里允许的非秘密业务字段，不存登录凭据。未知输入字段、客户端角色/actor/状态会被拒绝。

party_commands按账号、操作、机构和请求键保存结果；同键同内容重放旧结果，不重复变更/写审计，同键异内容报409。重放前仍核对当前权限；被移除成员不能通过重放接受记录重新授权。变更和结果同事务提交，连接提交结果不明沿用基础层COMMIT_OUTCOME_UNKNOWN，调用方凭原键重新核对，不能换键盲重试。当前无自动清理命令结果的任务；保留策略须在公开接口启用前明确。

邀请/成员使用object_version，旧版本报412，缺版本报428；权限403、不可见邀请404、非法输入400、过期422。已接受邀请是历史事实，移除成员不会改掉它。重新加入时成员版本递增，并关联新的邀请。已过期的待处理邀请在读取时显示EXPIRED，重新邀请时把旧行记为EXPIRED；不依赖定时任务才拒绝过期接受。

party_audit_events保留当前调用账号、机构、动作、对象/版本、请求编号和时间，不记录会话令牌、申请正文。成功变更与审计原子提交。拒绝请求的全局安全事件记录、运营审计查询接口和保留策略仍待后续完善；本轮没有宣称全部治理功能已交付。

## 数据库与测试

MySQL迁移0008–0014分别创建账号、主体、邀请、成员、能力申请、操作记录、请求结果表。均为InnoDB，标识区分大小写，有外键、版本约束和同一机构/账号只能有一份待接受邀请的约束。原0001–0007不改。当前不自动导入旧身份、MCN绑定或历史批准；它们缺少可信来源与确认，不能直接变成新成员。

设置隔离测试配置后执行npm run test:party；npm run test:ci也会自动运行这一组。测试严格限制本机33316、jx_local与jx_dev控制连接，使用随机jx_test_*数据库后清理。没有配置不能跳过后报成功，不调用真实供应商。

公开接口和登录接入、本人退出/所有权交接、停用管理、机构审核、商业合作与佣金授权、分页及保留策略仍未全部完成。不能从测试通过推断已可正式给用户使用。
