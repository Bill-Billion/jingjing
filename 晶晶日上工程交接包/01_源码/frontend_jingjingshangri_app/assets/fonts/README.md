# 刊物标题字体

EditorialSerif-Bold.ttf 来自 Adobe 思源宋体 Source Han Serif SC VF 2.003（本机已有原件），SIL OFL 1.1，版权及完整许可证见OFL.txt和字体name表。原字体来源：https://github.com/adobe-fonts/source-han-serif 。

为移动端标题生成700字重静态子集：GB2312、拉丁与中文标点、现有App源码文字，共7823个Unicode映射；修改后字体家族改名Editorial Serif，保留原版权。正文继续使用系统无衬线字体；未收录罕见字由系统回退，用户输入仍完整显示，不做字符过滤。

子集由fontTools 4.61.1生成；工具仅存在本机.local，不增加应用依赖。Web复用此文件，构建打包不请求外部字体服务。
