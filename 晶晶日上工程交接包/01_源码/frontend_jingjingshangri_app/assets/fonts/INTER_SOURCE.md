# Inter 字体来源与本地使用

复用仓库独立预览已取得的官方 Inter 原始 TTF，未修改字体、未重新下载或安装。

- 官方来源：https://raw.githubusercontent.com/google/fonts/main/ofl/inter/Inter%5Bopsz,wght%5D.ttf
- 官方元数据：https://github.com/google/fonts/blob/main/ofl/inter/METADATA.pb
- 字体内版本：4.001;git-66647c0bb。来源元数据称上游 Inter 4.1 Google Fonts archive，两者不混称。
- 原始文件 SHA256：29160a80ff49ddcab2c97711247e08b1fab27a484a329ce8b813d820dc559031
- 许可：SIL Open Font License 1.1，完整原文见同目录 Inter-OFL.txt，许可文件亦列入 Flutter assets。
- 变量轴：wght 100–900、opsz 14–32。本批仅注册独立 WalletBalanceInter，05 本人钱包真实可用余额金额使用 wght 600 / opsz 14；中文沿用 NotoSansSC。opsz=14 是既有本地预览 calibration-05.css 的选择，不是已核实的 Figma 历史轴参数。

依据：独立预览 assets/fonts/FONT_SOURCES.md 与 calibration-05.css。Figma 未提供其历史字体二进制版本，不能声称二进制完全一致。未进行 Flutter 编译或渲染验收。
