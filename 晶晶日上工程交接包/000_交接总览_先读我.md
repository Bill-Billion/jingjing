## 2. 产品与业务定位（先懂业务再看代码）

- **C 端（买家/普通用户）**：上传一张照片生成数字分身；购买数字人祝福视频；定制"我当主角"的定制剧/圆梦项目；培育自己的数字人、接通告、沉淀数字资产。
- **供给侧（艺人/达人）**：真人创建并授权数字人，接祝福视频、品牌代言订单；查看使用报告与收益、提现。
- **机构侧（MCN）**：MCN 机构管理旗下数字人艺人（仅 H5 后台，不在 C 端下单）。
- **B 端**：品牌代言、企业口播、定制服务、上下游企业入驻与商务合作。
- **平台职责**：撮合 + AI 制作 + 第三方担保交易 + 合规审核；**资金不过平台账户、永久去投资化**（席位/意向金属"内容消费"，非投资理财，不承诺货币回报）。
- **核心使用四步**：开机（创建数字人分身）→ 入戏（古装/都市/穿越/市井/悬疑等多题材剧本）→ 培育（上节目、接通告、拉赞助）→ 成角（出品数字影视作品，做自己的经纪人）。
- **自有 IP（仅这三个，禁止混用其他项目素材）**：《黄帝史诗·天下合》《少年龙武》《边境暗影》。

## 3. 技术架构总览

### 3.1 总体架构

```
┌─────────────────────────────┐        HTTPS(JSON)      ┌──────────────────────────────┐
│  Flutter App (Android/iOS壳) │  ───────────────────▶  │  Nginx 443 (TLS, 静态/反代)    │
│  Provider 状态 + Dio 网络     │                        │        │ 反代到回环            │
│  在线/演示双模式(AppMode)      │ ◀───────────────────  │        ▼                      │
└─────────────────────────────┘                        │  Node/Express :3000 (PM2 jjsr) │
                                                        │  ├─ routes 25 模块 /api/*       │
                                                        │  ├─ services 业务+第三方适配     │
                                                        │  ├─ middleware 鉴权/限流/校验    │
                                                        │  ├─ jobs 定时任务                │
                                                        │  ├─ SQLite(WAL)  [可切 MySQL8]  │
                                                        │  └─ 火山引擎 / 阿里云 / 支付宝   │
                                                        └──────────────────────────────┘
```

### 3.2 前端技术栈

- **框架**：Flutter（Material 3 暗色主题，自研"曜石流光 / Liquid Glass 2.0"设计系统，色值集中在 `lib/theme/app_theme.dart`，520 行）。
- **状态管理**：`provider`（ChangeNotifier + StatefulWidget，**当前刻意不引入 Riverpod/BLoC**，见第 11 节铁律）。
- **网络**：`dio`（统一封装在 `lib/services/api_service.dart`，950 行，含拦截器、性能埋点、离线模拟注入点）。
- **关键依赖**：`tobias`（支付宝原生 APP 支付）、`video_player`（精确锁 2.9.2 / video_player_android 2.12.0，规避 Kotlin 2.4 K2 下 pigeon 重复声明）、`image_picker`、`cached_network_image`、`webview_flutter`、`shared_preferences`、`share_plus`、`screenshot`、`pull_to_refresh`、`fluttertoast`。
- **双模式**：`lib/services/app_mode.dart` 控制"在线真实接口 / 离线 mock 演示"；假数据集中 `lib/services/mock_data.dart`（468 行）。
- **金额铁律**：唯一常量 `lib/utils/pricing.dart`，唯一展示 `lib/utils/money.dart`（对外用元、不 /100、禁止第二处写死价格）。

### 3.3 后端技术栈

- **运行时/框架**：Node.js + Express 4；`jsonwebtoken` 鉴权；`helmet` 安全头；CORS 白名单；全局限流；请求体保留 rawBody 用于回调 HMAC 验签。
- **数据库**：`better-sqlite3`（生产 WAL、外键开启）；**版本化迁移** `migrations/001..005 + runner`（顺序/事务/幂等）；`migrations/mysql/01_schema_mysql8.sql`（920 行，61 张表 MySQL8 DDL，切换文档见 `migrations/mysql/README_mysql_switch.md`）。所有金额字段单位为**分（INTEGER）**。
- **第三方能力（均做了 provider 抽象，可一键回退/缺凭证安全降级）**：
  - **火山引擎（主 AI 供应商）**：方舟大模型(doubao)、Seedream 文生图、Seedance 文生视频（异步任务+重启恢复 `volcVisual.resumeUnfinished`，不丢任务）、openspeech 语音合成 TTS、声音复刻；统一 AI 治理与每日成本上限 `AI_DAILY_COST_CAP_FEN`。
  - **阿里云（合规供应商）**：实人认证/身份证二要素（cloudauth）、人脸核身、内容安全 green（文本/图片/视频机审）；`services/providers/` 下 aliyun 与 volc 双实现，`COMPLIANCE_PROVIDER` 切换。
  - **支付宝**：APP 支付（`alipay-sdk` + 前端 tobias），独立 `/api/pay` 链路与 `payments` 表，沙箱已 33+33 断言联调，**当前为沙箱开关，待经营进件后切正式**。
  - **对象存储 OSS**：抽象已备（`services/storage`），当前未开通、暂用本地 `/uploads`，生产建议切 OSS。
  - **短信**：代码具备，当前**免验证码登录**，短信定时任务已按要求删除（禁止擅自重建）。
- **工程化**：幂等键表、对账（reconciliation）、异常监控、审计日志、敏感字段加密（FIELD_ENC_KEY）、定时任务调度 `jobs/scheduler.js`。
