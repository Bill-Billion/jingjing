## 一、四条产品线（边界必须清晰，不得交叉混卖）

### 线① 祝福视频（数字人接单）——大众走量、冲动消费
- 卖方：已入驻数字人艺人（真人授权的数字分身）。
- 商品：15/30/60/90 秒祝福、口播、庆祝福短视频。
- 定价【A-04】：**艺人完全自主定价，最低 ¥99，上不封顶**（299/699/2999/6999/19999…自定）。平台只给建议价区间；单笔 ≥1 万元转人工审核。
- 平台抽成【A-04】：99 档 0%；299 及以上 10%；通道费 0.6%；AI 成本 15 元/条由艺人承担（新人前 90 天补贴为 0，AI 走火山引擎 A-19）。
- 沟通规则【A-05】：**先下单，才能在平台 IM 内沟通**；未下单不可私信。
- 售后【A-15】：99 档交付后 48h 内免费重做 1 次；质量问题 3 日内免费修改，仍不达标可退款。定制数字商品不适用七天无理由，下单时非默认勾选确认。

### 线② 个人定制剧（"我当主角"圆梦短片）——高客单、项目制重服务
- 本质：**项目制内容服务**（不是标品、不是投资）。标准流程：
  交意向金锁档 → 选对标类型/对标剧 → 编剧据此写本 → 商务协助改本（含免费轮次）→ 用户定稿 → 制作样片/宣发片 → 成片交付。
- 分档【A-20，固定四档不再增减】：
  | 档 | 价格 | 内容 | 成交方式 |
  |---|---|---|---|
  | 彩蛋档 | ¥1,000 | 在自有 IP 项目中片尾署名+专属彩蛋镜头+数字成片，限量 | 在线直接下单 |
  | 普通定制（主推） | **¥5,000 起，上不封顶** | 选对标+定制剧本+2 轮免费改本+AI 宣发片 3–5 工作日 | **两段式：99 锁档→定稿补尾款（撮合担保分账）** |
  | 进阶定制 | 面议 | 资深编剧/导演，可做中剧/短剧/网大 | 商务一对一、线上电子合同、里程碑担保 |
  | 电影级定制 | 面议（几万–几百万） | 电影班底、可约明星/专业演员 | 线上/线下签约、里程碑担保分账 |
- **意向金【A-07：统一 ¥99，可退可抵】**
  - 锁档/启动选剧与编剧对接的小额意向金，**不是总价、不是定金罚没**；成交计入总价（普通档再付 ¥4,901 起）；
  - 剧本定稿前放弃可原路退（已发生第三方实费据实扣除）；承制方/平台原因无法交付全额原路退；
  - **全站只允许出现"意向金 ¥99"一个数字**（现状 launch/样片订单页残留"1000+4000"为待修 P-01）。
- 普通档付款【A-21】：**两段式「¥99 锁档 → 定稿付尾款 ¥4,901 起」，普通档不用里程碑**；仅进阶/电影级用里程碑。
- 高端里程碑【A-22，全站唯一一套】：**剧本 20% / 开机 25% / 粗剪 25% / 成片 30%**，按节点担保分账释放（废弃 30/30/30/10）。
- 改本：含 2 轮免费修改，超出 ¥200/轮（前端需补，P-09）；成片交付后 7 天内可申请 1 次免费修改。
- 角色规则【A-23】：用户定制时自选当哪个主角；其余角色可被他人购买或用户自行上传人选（线②与线③一体两面，不是两个独立商城）。

### 线③ IP 项目角色/席位（自有 IP：黄帝史诗·天下合 / 少年龙武 / 边境暗影）

## 二、资金流与平台角色（A-18 统一撮合分账）
- 全部交易（祝福/代言/角色/定制剧）走**撮合分账**：用户付款 → 持牌支付机构备付金（微信电商收付通/支付宝直付通）→ 验收后分账给艺人/项目方/**承制方**二级商户，平台只抽服务费；**资金永不进入平台自有账户**（避二清，见05）。
- 定制剧：平台只做**撮合+技术服务+担保交易**，不承制、不收全款。**承制方（编剧/制作工作室，完成 KYB 的 B 端二级商户，A-28）直接对客户收款、交付并开全额"内容制作"票；平台向承制方开"平台/技术服务费"票，平台不开全额制作票。**
  - 意向金 ¥99 走担保/待分账，不沉淀，未交付原路退；
  - 普通档定稿后尾款进担保，验收分账；高端按 A-22 里程碑逐节点释放；
  - 大额受支付机构分账比例/单笔限额约束，需提前申请提高额度（A-28）；禁止私下打款给平台或个人；
  - 交付主体责任在承制方，平台负责担保、工单、验收、纠纷与退款规则。
- 艺人保证金【A-11】：入驻不预收，**首笔收入冻结 ¥500** 起，按近30天成交额/投诉率动态调增（500/1000/3000/5000），退出 30 天无纠纷退。

## 四、订单/状态机（一套命名，禁止同义多名）
- 祝福视频：pending 待支付 → paid 制作中 → delivered 待验收 → completed / after_sale / refunded。
- 定制剧普通档（两段式+撮合担保）：
  draft 待付意向金 → intent_escrow 意向金担保中/待选类型 → genre_selected 待选对标剧本 → scripting 剧本创作/改本中 → script_finalized 已定稿（付尾款到担保）→ producing 制作中 → delivered 待验收 → settled 验收后分账完成；未交付节点可 cancel_refund 原路退意向金。
- 进阶/电影级：线索提交（custom_request）→ 商务跟进 → 签约 → 里程碑担保（**剧本20/开机25/粗剪25/成片30，A-22**）逐节点释放。
- 命名统一："样片"只是定制剧环节，**不得作为独立产品名**；线②③统一入口（见03、A-24）。

## 五、命名与对外话术规范
- 对 C 端禁用词：投资、理财、回报、分红、票房收益、稳赚、众筹、定金（用"意向金，可退可抵"）。
- 统一产品名：祝福视频 / 定制剧（彩蛋·普通·进阶·电影级）/ 角色席位 / 品牌代言；底部"剧场"改名"**圆梦**"（A-24）。
- 价格主次：**总价为主、意向金为辅**，按钮形如"付 ¥99 意向金锁档（总价 ¥5,000 起）"，禁止只显示 99（P-03）。金额千分位，"起"只用于上不封顶档。
