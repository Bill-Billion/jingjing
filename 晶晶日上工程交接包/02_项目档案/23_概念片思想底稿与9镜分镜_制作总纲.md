## 一、灵魂主张（逐字定稿，不得再改）

- **主口号（七字）：做自己人生的主角。**
  - 已否决："做自己，人人都可以做自己人生的主角"（太臃肿）；"人人都是自己的主角"。
- 镜01 开场钩子：**你，有多久没做过主角了？**
- 品牌副标：**每一个角色，都为等待的人而生。**
- 全片落点：回到"做自己人生的主角"。

## 二、核心思想（面向所有普通人，不是行业人）

晶晶日上是**数字人 IP 经纪 + 让普通人做自己人生主角的定制圆梦平台**，双边市场，需求侧＝供给侧。
主线是"一个普通人"在 App 里的完整旅程：

1. **共同底座｜先有数字分身**：每个普通人进来，先录制 / 生成属于自己的数字人。
2. 由这个数字分身，长出三条互为镜像的路径：
   - **① 入戏（我演别人的戏 / 帮别人圆梦）**：带自己的数字人去参演别人发起的、或平台已有的剧；花一点钱，以**消费式认领角色**，换来**确定权益**（出镜、署名、成片）。**不是投资、没有分红、没有回报承诺。**
   - **② 立戏（我当主角 / 大家来演我的戏）**：我自己选剧本、定一部戏，做自己人生剧的主角；把其余角色开放出来，让其他普通人的数字人一起来共演。与①互为镜像（我既能入别人的戏，也能立自己的戏）。
   - **③ 成角（我的数字人成为"艺人"被需要）**：把数字人上架到艺人广场，别人可以选购它做祝福视频、品牌代言；**普通人也能被需要、有收入**。
3. **撮合**：定制剧环节做**上下游撮合**（剧本、角色、数字人、制作资源的匹配），**平台不承制、不碰资金**（资金担保托管，不过平台账户）。
4. **真明星同台仅为远期预留，本期概念片不出镜、不重点讲。**

一句话叙事：**我是个普通人 → 生成我的数字人 → 我能入戏帮人圆梦、能立戏做自己的主角、还能成角被人需要 → 人人都能做自己人生的主角。**

## 三、不可逾越的口径红线（写片 / 改码一致）

- 全片**不出现价格数字、不出现"投资 / 分红 / 回报 / 众筹 / 定金"**等字眼（产品界面内既有合规文案除外）。
- 个人定制剧只有"意向金 ¥99（可退可抵）"一个金额概念，且**概念片不主动报金额**。
- 自有 IP 仅三个：**黄帝史诗·天下合 / 少年龙武 / 边境暗影**；不绑定其中某一部做全片 demo。
- 三端边界：C 端买家、艺人（**同一个 App，创作中心切换身份**）、MCN（**独立 H5 后台，C 端绝不下单、不出机构表单**）。
- 四产品线（背景，不堆进片）：祝福视频（≥99，99 档 0 抽成）、个人定制剧"我当主角"（意向金统一 ¥99 可退可抵）、自有 IP 角色席位（永久去投资化）、品牌代言（单品 1999 / 季度 19999）。
- 品牌名统一"**晶晶日上**"，清除"精彩 / 经典剧场 / 晶典剧场"等旧词；底部 Tab"圆梦"保留。

## 五、制作总纲（为什么这样做，详见 Skill `app-concept-film`）

- **第一硬约束：成片里任何清晰 UI 必须逐像素等于核字终版图，绝不让 AI 重绘中文界面（AI 写中文必出错字，且原理级不可控、无锁帧、无 OCR 自检）。**
- **时间轴分离**：AI（Seedance/Seedream）只负责生成**无任何文字**的氛围素材（丝绸流光、粒子、光带）；带字 UI 一律用核字 PNG 做**元素级程序动画**（切块飞入、模糊落定、光带遮挡）。
- 运动过程中文字**不可成形**（大模糊、只见发光块），**落定瞬间才清晰**，从根上消灭"可读但形变 / 重影 / 错字"。
- 流水线：scene.html（纯函数 `window.setT(ms)` 驱动，便于逐帧 seek）+ render.cjs（puppeteer-core 驱动系统 Chrome 逐帧截图）+ 绿色 ffmpeg（libx264 编码）。详见 Skill。
- 每镜渲染后必须**抽帧目检**：运动帧无字、落定帧逐字对、无水印、无 AI 重绘。
- **先小样板审定再批量**：镜01 认可后，复用同一 scene/render 模板批量 02–09，最后 concat 约 45s 整片，避免返工。

### 7.3 本棒新增的确定性技术（已同步进 app-concept-film skill）
1. 真人层 #faceLayer：无文字人物视频逐帧铺底，faceWin 内按 30fps 换帧 + eOutCubic 1.02→1.10 缓推 + 末段淡出；与第一个页面的圆形揭示构成匹配剪辑。
2. 单侧光人脸补光（ffmpeg，先于切帧）：`eq=gamma=1.38:contrast=1.06:brightness=0.015` 再 scale/crop；gamma 抬暗部把阴影里的五官拉出、contrast>1 压回黑位保持曜石黑（gamma1.5 会发灰，1.3 早期帧偏暗，1.38 为平衡点）。舞台层只再补 brightness1.04。
3. 多章节卡 S.chapters[]（青 kick+金主标+金副标），浮出期间对整屏 #pages 同频 `blur(8a) brightness(1→0.42)`，把圆形揭示圆外仍清晰的上一页一并虚化压暗，彻底避免金色卡与清晰 UI 文字重叠；章节卡 win 精确包住"新页 at-0.35 ~ at+0.55"的扩散模糊期。
4. 独立 S.caps（不依赖页面）：开场钩子、结尾口号走独立字幕轨；页面内嵌 cap 仍只放在样板逐帧验证过坐标的 src2/p16/p26，其余 19 页不配内嵌字幕，叙事交旁白+章节卡，从根上杜绝压字/错字。
5. 时间轴与 60s 旁白逐句对齐（九句旁白对应九个叙事段，页面 at 落在对应语句窗口内）。
