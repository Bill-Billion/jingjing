# 03 · UI/UX 设计规范与逐页改造台账（追光 · 唯一视觉）

> 追光是**唯一在役视觉**，多巴胺/粉橙/霓虹紫全部废弃。任何 UI、素材、PPT 视觉都以本文件为准。
> 最后更新 2026-08-29。前端共 41 个 dart 文件，页面状态见第四节，改一页勾一页。

## 一、设计理念（产品灵魂，别丢）
- 主题：**追光**——"每个人都可以做自己人生的主角"。电影开场前灯光暗下、一束追光打在主角身上的仪式感。
- 气质：电影感、暖金、克制光晕、海报式排版、衬线标题；**不是**高饱和多彩、不是二次元、不是卡通。
- 三个情绪关键词：被照亮（主角感）、值得期待（开场仪式）、被认真对待（高客单的信任与质感）。

## 三、字体 / 组件 / 素材 / 交互
- 字体：标题一律衬线 `AppTheme.serifFont`（海报感）+ 字重 800/900；正文无衬线。字号阶梯：大标题32/24、页面标题20、卡片标题16、正文14-15、辅助12-13。
- 圆角：按钮/标签/输入框用胶囊（StadiumBorder/999）；卡片 20-24；图片卡 12-16。
- 主按钮：金底深字胶囊；次级：金边描边胶囊；**一页只有一个主 CTA**。
- 光晕：克制，用在启动 logo、中间发光键、主 CTA 阴影（brandShadow），不要满屏发光。
- 毛玻璃：底部导航/浮层用 BackdropFilter，白 6-8%。
- 素材铁律：
  1) 数字人/艺人**必须用真人风格照片/真人数字人**，禁止动漫/二次元/插画风当艺人；
  2) 剧集只用**自有 IP**（黄帝史诗·天下合 / 少年龙武 / 边境暗影），禁止未授权剧名；
  3) 图片统一放 `assets/images/` 并在 pubspec 声明，压缩到单张百KB级控制包体；
  4) 缺素材用统一深色占位组件，不用纯色方块糊弄。
- 转场：页面进入 0.32s 上滑+淡入（easeOutQuart）；发光面板从底部升起。
- 价格展示：总价最大最亮（衬线、金色），意向金/分期为次级说明；CTA 必须带总价语境（见 01 第五节）。
- 信任感组件（高客单必备）：样片集、制作流程、可退保障、真实评价、商务/客服入口。

## 四、信息架构（A-24 已定，解决入口绕 P-07）
- 底部 5 项：首页 / 艺人 / [发光✦] / 圆梦（原"剧场"改名）/ 我的。
- 中间发光键 `glow_panel` 三选一：①录祝福视频 ②创建数字人 ③发起定制剧（"我当主角，¥5000起"）。
- "发起定制剧"统一进入**唯一的定制剧主链路**：项目/类型选择 → 详情（档位/权益/流程/信任）→ 付99意向金锁档 → 选对标→改本→定稿→尾款→制作→交付。样片选择、剧本阅读都是这条链路里的环节页，不再是并列产品。
- 定制剧从任意入口到"付意向金"不超过 2-3 步；线②个人定制 与 线③角色席位 在同一套页面用"档位/角色"表达。

## 六、UI 验收清单（每页改完逐条过）
- [ ] 无任何硬编码旧色，全部走 AppTheme
- [ ] 标题衬线、字号符合阶梯、一页一主CTA
- [ ] 价格主次正确、与01口径一致（总价为主）
- [ ] 真素材、自有IP、无动漫艺人、无纯色块糊弄
- [ ] 小屏(360宽)/常规/折叠展开/平板四档不破版
- [ ] 深色下文字对比度足够、点击态/禁用态清晰
- [ ] 空态/加载态/失败态/断网兜底都有
- [ ] 与后端字段对得上，不靠写死假数据
