## 四、目标部署拓扑（阿里云，"先本地跑通再上云"）
1. 本地阶段（先做）：本机起 Node + SQLite，APP 用局域网/内网穿透连本地，跑通登录→AI→支付沙箱全链路，沉淀部署文档。
2. 上云阶段：
   - 轻量服务器/ECS：Node 进程用 PM2 守护，Nginx 反代 + HTTPS（Let's Encrypt 或云证书）；
   - 数据库：RDS MySQL（或自建），由 SQLite 迁移，做定时备份；
   - 对象存储 OSS：存人脸特征/成片/素材，私有 bucket + 签名 URL，CDN 加速公开素材；
   - 安全组只开 80/443/22；数据库不暴露公网；密钥用环境变量，不入库不入 git；
   - 日志、监控、告警、崩溃采集（Sentry/Bugly）、灰度发布。
3. APP 端：`api_service` baseUrl 改为线上 https 域名；保留"演示模式"开关仅用于离线演示包，正式包默认在线、失败给明确错误而非静默假数据。

## 六、AI 供应链（产品成立的根，优先级高于 UI）【已定 A-19 主用字节系】
- 分工：**生成走火山引擎，投放获客走巨量引擎**（同属字节但不是一回事，别开错账号/买错服务）。
  - 火山方舟 Ark：大模型（脚本/文案/对话，Doubao 等，建推理接入点 endpoint 调用）；
  - 即梦 AI / Seedance：图生视频、文生视频、口播短片合成；
  - 火山数字人（数字分身/视频数字人）：真人素材训练数字分身、形象驱动；
  - 火山语音（声音复刻 2.0 + TTS）：音色克隆与配音；
  - 巨量引擎/巨量千川：后期广告投放与获客（营销侧，非生成能力）。
- 需跑通链路：上传真人照片/视频 → 人脸活体与授权 → 火山数字人训练分身 → 输入文案（方舟）→ 声音复刻 TTS → 即梦/数字人合成口播视频 → 机审+水印 → 交付。
- 开通清单：火山引擎账号实名认证 → 开通上述服务 → 拿 AccessKey/Secret、Ark API Key 与 endpoint、各服务 AppID；确认并发配额与计费方式（按 token/秒/分钟/次）。
- 成本口径进 UE（见05/F-03）：视频15元/条、代言500元/单为当前估算，**必须用火山正式报价校准**（D-火山）；记录单条耗时、合格率、失败重试。
- 合规：火山作为云/模型方虽已备案，**不免除平台自身的生成式AI/算法/深度合成备案、AI标识与水印义务**（见05）；保留 1 家备选（如可灵/腾讯）防限流涨价单点风险。
