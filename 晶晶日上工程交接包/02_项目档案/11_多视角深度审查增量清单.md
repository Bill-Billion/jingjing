## 一、P0 商业逻辑 / 合规红线

- **C1 定制剧仍是旧价格（违反 A-07/A-21）**：`pages/launch/launch_page.dart:49-60,71` 仍是"基础档¥5,000＝意向金¥1,000＋制作款¥4,000""立即定制¥5,000"。必须改为**意向金¥99 锁档 → 定稿补尾款 ¥4,901 起**，按钮"付¥99 意向金锁档（总价¥5,000 起）"；后端 `config.sample` 同步为意向金 9900 分、普通档 5000 起两段式。全站只允许出现"意向金 99"一个数字。
- **C2 里程碑两套错口径（违反 A-21/A-22）**：① `launch_page.dart:102` 高端档还是废弃的 **30/30/30/10**，改 20/25/25/30；② `project_detail_page.dart:362`、`wallet_page.dart:130` 把"四节点里程碑"错误套到**普通定制**和**席位**——普通档不用里程碑（99+尾款即可），线③席位不按里程碑，**里程碑仅用于进阶/电影级**。
- **C3 角色市场违规（违反 A-09/A-23、P-05）**：`pages/role_market/role_market_page.dart:10-14` 仍是《长安锦帐》《赛博迷城》《江湖故人》**非自有 IP**，且把 **¥500,000/¥300,000 主角明码挂 C 端**。该页废弃，角色并入 project_detail"角色档位"，只用自有 IP；后端 `seed.js:133` 主角档 ¥50,000（5 万整，踩"C 端≤数万、5 万以上进商务"边界）改为"商务洽谈"不在 C 端直接成交。
- **C4 线②③数据模型纠缠（P-04 根源未除）**：后端 `projects` 用 `goal_amount/raised_amount`（50 万/32.8 万**金额**），前端 `projects_page` 却写死 claimed/total=72/100 当**席位数**，`home_page._buildProjectCard:582-590` 又拿金额去除以算百分比。线③席位必须由 `project_roles.stock_total/stock_sold` 汇总出"席位 X/Y"，**禁止用项目预算金额当席位/进度**；线②定制剧是独立流程（99 意向金），不要和 IP 项目页混在同一实体同一页面。
- **C5 供给侧/分账信息暴露给买家**：`wallet_page.dart:124-131`"结算规则（99 档 0 服务费/代扣税/保证金/里程碑拨付）"是**艺人侧**内容，买家钱包不应出现。钱包也要分买家（充值/退款/优惠券）与艺人（可提现/待结算/冻结/分账规则）两视角。
- **C6 活体检测是假的（合规阻断项）**：`audition_page.dart:105-131` 用 `Future.delayed 2s` 模拟"活体通过"。演示可保留 mock，但必须：①UI 标注"演示模拟"；②列入上线阻断清单——正式版必须接腾讯云/阿里云活体 SDK，否则任何人可持他人照片建数字人，肖像授权链条失效。
- **C7 真人定位被"赛博朋克"回潮污染**：`humans_page.dart:24` 筛选分类、`audition_page.dart:381` 风格选项含"赛博朋克/玄幻"；`seed.js:146` 评价"赛博朋克风格太酷"。统一改为真实人像风格标签（商务/温婉/青春/国风/军旅等），清掉赛博/玄幻与相关评价。
