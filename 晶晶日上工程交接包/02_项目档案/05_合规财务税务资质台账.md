## 二、资金合规：避二清（红线）
- 二清=无支付牌照却让交易资金先归集到平台自有账户再二次清分给艺人/商家/承制方，违法。
- 撮合业务（祝福/代言/角色/定制剧，A-18 统一走撮合）正确做法：接入**持牌机构的分账产品**（微信电商收付通/支付宝直付通），用户付款进备付金/二级商户，平台只按比例抽服务费，资金不过平台账户。
- 定制剧【**已定 A-18：走撮合分账，"平台承制直收"已否决**】：
  - 平台只撮合并抽服务费，**承制方（编剧/制作工作室，完成 KYB 的 B 端二级商户）直接对客户收款、交付并开全额"内容制作"票**，平台向承制方开"平台/技术服务费"票；
  - 意向金 ¥99 走担保/待分账、未交付原路退；大额受支付机构**分账比例上限与单笔限额**约束（默认分账比例有限，需向机构申请提高/大额额度，见07 D-承制方）；超限走线上/线下签约但资金仍须过持牌监管，禁止私下打款给平台或个人；
  - 平台不承担承制交付主体责任，但须做担保交易、里程碑工单、验收、纠纷与退款规则；落地前置是承制方入驻 KYB（02 L-08）。
- 反洗钱：单笔≥1万人工审核、禁止自买自评、新号72小时冷却、异常价格/频次监测（config 已有阈值，需真实启用）。

## 三、税务与财务
### 1. 艺人/承制方个税与结算（F-01，高客单关键）
- 现状仅实现"劳务报酬"预扣：≤4000减800、>4000减20%，税率20/30/40%，速扣0/2000/7000。高客单（19999代言、5000定制、数万元角色）下税负最高40%，到手差、易逼向站外。
- 合规优化通道（择一/组合）：
  - 个体工商户/个人独资（工作室）集群注册 → 按"经营所得"，部分园区可核定征收（注意政策收紧，选合规园区、留痕）；**定制剧承制方优先用工作室/公司主体**；
  - 通过合规灵活用工/众包平台结算，由平台完税开票；
  - MCN 以机构身份签约结算，艺人与MCN内部分配。
- 前端必须向艺人/承制方展示"含税收入/平台费/通道费/税费/预计到手"，避免事后纠纷。
### 2. 发票链（F-02，撮合口径）
- 撮合模式：商品/制作款由二级商户（艺人工作室/承制方）向客户开票；**平台只开"平台服务费/技术服务费"票**，不开全额制作票；
- 艺人/编剧/制作方给平台的进项（服务费成本）票路径要打通，否则平台所得税成本无法列支。
### 3. 单经济模型 UE（F-03/P-10，必做）
- 逐档算：客单价、抽成/撮合佣金、通道费0.6%、AI成本（火山正式报价校准，暂估视频15/代言500）、商务/编剧/制片/售后人力、带宽存储、获客成本（巨量投放CAC）、补贴、退款率；
- 重点复核：99档0抽成是否亏通道/审核成本；定制剧5%撮合佣金是否覆盖担保+工单+售后（疑似倒挂）；新人90天AI补贴总预算与上限。
- 输出：各档贡献毛利、盈亏平衡所需单量、LTV/CAC、12个月现金流。
### 4. 保证金与提现
- 保证金首笔收入冻结500起、按风险动态调增、退出30天无纠纷退；提现 T+N、对账、差错处理与审计留痕；承制方另设交付保证金/质保金规则。

## 四、个人信息 / 人脸 / 声音（PIPL，红线）
- 人脸为敏感个人信息：单独同意（一屏一授权，不与总协议捆绑）、最小必要（只存特征向量不存原图，或原图加密短期保存后删）、个人信息保护影响评估 PIA、可随时撤回与删除、未成年人特别规则。
- 声音克隆（火山声音复刻）：单独声音授权、授权范围/期限、被冒用申诉与下架通道。
- 数据安全：传输加密、私有存储、访问审计、等保三级；人脸数据出境需满足中国数据出境规则（安全评估/标准合同）。

## 五、AI / Deepfake 内容治理（A-19 主用火山引擎）
- 供应商：生成走火山引擎（方舟/即梦Seedance/数字人/语音复刻），投放走巨量引擎；**火山作为云/模型方已做上游备案，不免除本平台自身的生成式AI/算法/深度合成备案与内容责任**。
- 四件套：真人活体校验 + 肖像/声音授权链 + 生成内容显著AI标识 + 盲水印(C2PA或等效)；
- 机审前置：涉政/色情/暴力/虚假宣传/名人冒充先审后发；投诉下架与举证留存；对火山返回内容仍需平台二次审核；
- 禁止伪造真人（未授权名人/他人）、禁止用于诈骗；自身算法/深度合成备案完成前不大范围开放。

## 六、"下单后沟通/私下交易"的责任边界（L-04）
- 满足业务诉求（成交后可进一步沟通）同时隔离平台风险：
  1. 仅在存在真实订单后开放平台 IM，未下单不可联系；
  2. 沟通留在站内，IM 做敏感词/异常行为监测与风控（config 已有阈值）；
  3. 用户协议+下单页显著提示"请使用平台担保交易，站外私下交易平台不承担责任、不受平台保障"；
  4. 主体实名（承制方 KYB）、举报、封禁、留痕；对黄赌毒/诈骗零容忍并配合执法。
- **前端任何页面、客服话术都不得出现"加微信/加联系方式/站外交易"等明示引导**；平台不主动组织、不承诺、不抽成站外行为。这是"自然发生但平台无过错"与"平台组织引导"的法律分界。

## 七、消费者保护
- 定作的数字人视频不适用七天无理由：下单时**非默认勾选**确认；
- 99档48h免费重做1次、质量问题3日免费修改/退款；定制剧意向金可退可抵规则透明、按里程碑担保释放；
- 未成年人：年龄验证、单笔500/月2000限额、禁购定制剧、退款机制；
- 广告/代言强制"广告"标识，授权范围期限渠道书面化。

## 八、去投资化红线（永久，不可为融资叙事松绑）
- 角色/席位只对应内容交付物（出镜/署名/镜头/成片/参与证明）；
- 永久禁止：票房分账、收益分红、货币回报承诺、回购、增值、稳赚、众筹式募资（`filmBoxOfficeShare.enabled=false` 不允许再打开）；
- 对外材料禁用"投资/理财/回报/分红"等词，避免非法吸收公众存款/变相证券发行风险。

## 九、数字资产叙事（融资加分但要克制）
- 用户把数字人/素材授权平台形成"数字资产台账"，可用 DCF 收益法做内部估值（折现15%、收益年限5年为当前假设）；
- 但这是**内部管理口径**，不得对 C 端宣称资产增值/可交易变现，否则触碰金融化红线；对银行/资方可作为版权资产与现金流质量的佐证。

## 十、出海合规双轨（P3，先新马华人市场）
| 维度 | 中国(境内) | 新加坡/海外 |
|---|---|---|
| 数据法 | PIPL+数据出境规则 | PDPA；需指定DPO、数据泄露通报 |
| AI监管 | 生成式AI/算法/深度合成备案 | IMDA Model AI Governance、内容标识建议 |
| 主体 | 境内公司 | 注册 Pte Ltd，对公账户、GST 9%（达阈值注册） |
| 支付 | 微信/支付宝分账 | Stripe/PayNow/信用卡，本地收单与清结算 |
| 人格权 | 肖像权/声音权（法定） | 普通法 right of publicity / passing off，需重签海外授权 |
| 内容 | 中国公序良俗与审核 | 种族/宗教/种族和谐高度敏感，本地化审核词库 |
| 语言币种 | 中文/人民币 | 中英双语、多币种、多时区、本地税率 |
| 数据跨境 | 人脸出境需安全评估/标准合同 | 服务器与数据驻留方案，境内外环境隔离 |
- 策略：国内 MVO 跑通、合规闭环稳定后再出海；首站新加坡做华人市场单点验证，不提前分散精力。

## 十一、给资方/银行/政府的口径
- 银行/支付：展示撮合分账架构、KYC/KYB（含承制方）、备付金不经过平台、反洗钱与对账机制；
- 政府：强调普通人数字就业增收、AI+文化、持证纳税经营，主动清理高价角色/站外导流等减分项；
- 资方：如实区分"演示数据 vs 真实经营数据"，给资质与合规路线图、资金闭环证据，不夸大已落地能力。
