## 二、部署拓扑（当前 = 单机全栈）

```
手机 APP(任意网络)
   │  http://8.222.213.43  (80)
   ▼
阿里云轻量 · Nginx :80  ──proxy_pass──► 127.0.0.1:3000 (Node/Express, PM2 进程名 jjsr)
   两层防火墙都已放行 22/80/443/3000：① 阿里云控制台防火墙 ② 主机内 ufw（active）
   后端目录 /opt/jjsr；SQLite=/opt/jjsr/jingjingshangri.db（demo 期，后续迁云 MySQL）
   静态素材 /opt/jjsr/uploads ── Nginx 同源经 /uploads 访问
   PM2 开机自启：systemd 服务 pm2-root（enabled）
```

- Nginx 配置：`/etc/nginx/sites-available/jjsr`（软链 sites-enabled，已删 default），`client_max_body_size 50m`，proxy 超时 120s。
- 旧版备份：`/opt/backup/jjsr_20260830_001214.tar.gz`；上传暂存 `/root/deploy/`。
- **关键踩坑：双层防火墙。** 只在阿里云控制台放行不够，主机 `ufw` 默认只放 22，必须再 `ufw allow 80/tcp; ufw allow 443/tcp; ufw allow 3000/tcp`，否则公网 80 fetch failed、但服务器本机 curl 正常。

## 五、本地部署工具（work/deploy/）

- `_ssh.py`（执行远程命令，标准 exec，勿用 pty 会卡）、`_sftp.py 本地 远程`（上传）。
- `deploy_release.sh`：备份→复用已编译 node_modules→替换代码/素材/.env/库→PM2 重启→自检。
- `nginx_setup.sh`：装 Nginx、写反代、PM2 开机自启。
- 发布步骤：本地停后端并对 SQLite `wal_checkpoint(TRUNCATE)` → 打包代码/uploads/.env/db 四个包 SFTP 到 `/root/deploy/` → 远程跑 `deploy_release.sh`。

常用运维：
```bash
python work/deploy/_ssh.py "pm2 list"                 # 进程状态
python work/deploy/_ssh.py "pm2 logs jjsr --lines 50 --nostream"  # 日志
python work/deploy/_ssh.py "pm2 restart jjsr"         # 重启
python work/deploy/_ssh.py "nginx -t && systemctl reload nginx"    # 改完nginx配置重载
```
