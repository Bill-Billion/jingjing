## 六、成本控制与常见坑
- 别一上来开 1080p/4k 和 pro 档：先用 720p + fast/mini 跑通，效果不达标再升档。
- 视频按 token、语音按字符，**不是"包月随便用"**；设费用预警/预算告警，避免测试期烧钱。
- 区分三类密钥：账号 AK/SK、方舟 API Key、各服务 AppID/Token，不是一个通用 key。
- Endpoint（ep-xxx）是"接入点"，和 API Key 是两回事，调用模型两个都要。
- **实时互动数字人按并发卖（约4.2万/并发/月），我们离线出片不需要，别误购。**
- 火山上游有备案 ≠ 我们免备案：本平台仍需自行完成生成式AI/算法/深度合成备案（见05）。
- 商用授权、肖像/声音授权链要留痕；生成内容平台仍需二次审核。
- 保留 1 家备选（如可灵/腾讯）用于对比与故障兜底，避免单点。

## 真人数字人合规链路（2026-08-29 实测 + 官方文档 82379/2315856，决定性结论）
### 实测事实
- Seedance 图生视频(i2v) **直接传写实真人照片 → 400** `InputImageSensitiveContentDetected.PrivacyInformation: may contain real person`（平台防深伪，禁止写实人脸直传）。
- 同一接口传**非真人**虚拟人图 → 约 90 秒成功出片（脚本 scripts/volc_i2v_smoke.js 已验证）。文生视频同样正常（volc_video_smoke.js）。
- 网传“去真人化/风格化绕过审核”属违规灰产，**严禁使用**。

### 唯一正路：方舟「真人人像库 / 可信素材库」授权（与我们人脸授权 L-02 完全对应）
1. 我方（已企业认证）方舟体验中心：我的 → 真人人像 → 管理素材 → 创建资产组 → 设授权有效期 + 同意《真人人像使用协议》→ 生成**邀约二维码**；
2. 艺人扫码登录本人火山账号 → 同意人脸信息处理与授权 → **真人活体认证** → 上传素材（竖版全身正面图 + 面部特写[肩以上、脸占约2/3]；或 2–15s 视频 / 2–15s 音频）→ 人脸一致性校验 → 入库即**自动授权我方账号**；
3. 我方在真人人像库点“接收”，拿到 **Asset ID**；一次真人认证、多妆造复用；**一个艺人 = 一个 Asset Group**；
4. 视频生成 API 用 `"image_url":{"url":"asset://<asset_id>"},"role":"reference_image"` 即可**合规调用该艺人形象，不再被拦截**。

### 对产品/工程的硬约束（必须据此改入驻流程）
- APP「艺人入驻/创建数字人」流程改为：填资料 → 平台生成邀约二维码 → 引导**艺人本人手机端**完成真人认证+授权 → 后端轮询资产组状态、保存 asset_id → **拿到 asset_id 才允许接单出片**；禁止“上传任意真人脸直接生成”。
- 后端 humans 表需增 asset_group_id / asset_id / 授权有效期 / 真人认证状态字段；出片统一走 asset:// 引用。
- 选型：真人形象→真人人像库 asset；非真人/场景/空镜→Seedance 直调；口播用 Seedance `generate_audio` + 声音复刻/TTS，备选「克隆数字人」（单视频建形象+音频驱动，单次≤12 分钟）。**前期不买**实时互动数字人 SDK、不买高级创作权益包（10 万/年起）。
- 素材规格：图 jpeg/jpg/png/webp/heic、<30MB、宽高比 0.4–2.5、边长 300–6000px；视频 mp4/mov、<50MB、2–15s、24–60fps；音频 mp3/wav、<15MB、2–15s。

## 语音线办理结果（2026-08-29 晚，TTS 已真实打通；声音复刻待样本）
### 两个决定性的坑（别再踩）
1. **openspeech 与方舟是两套鉴权**：用 `ARK_API_KEY` 调 openspeech 直接 **401 `Invalid X-Api-Key`**。必须在「豆包语音控制台 → API Key（/speech/new/setting/apikeys）」单独建 Key（即 `.env` 的 `SPEECH_API_KEY`）；新版无需 AppID（页面 AppID 2253768025 仅备用）。
2. **有 Key 不等于已授权**：没在「开通管理 → 快速购买」开通模型时返回 **403 `requested resource not granted (volc.seedtts.default)`**。服务管理列表里的内联"开通"按钮在自动化点击下会静默无效；正路是：购买页 → 计费方式选**后付费** → 选择服务（大模型）→ 勾三个协议 → 确认开通（**0 元**、邀测送免费额度，约 1 分钟生效）。

### 已开通（均后付费·字符版，约 0.0003 元/字）
- 语音合成2.0（资源ID `seed-tts-2.0`）：已开通、已实测出音频。
- 声音复刻2.0（资源ID `seed-icl-2.0`）：已开通，等真人录音样本即可训练复刻音色。
- 弹窗"授权数据用于模型训练换免费额度"已选**暂不授权**：平台会处理艺人/用户声音，不授权上游训练，合规优先（损失少量免费额度，余额可覆盖）。

### TTS 调用契约（已验证）
- `POST https://openspeech.bytedance.com/api/v3/tts/unidirectional`
- Header：`X-Api-Key: <SPEECH_API_KEY>`、`X-Api-Resource-Id: seed-tts-2.0`（复刻音色改 seed-icl-2.0）、`X-Api-Request-Id: <uuid>`、`Content-Type: application/json`
- Body：`{"req_params":{"text":"…","speaker":"<预置音色或复刻voice_id>","audio_params":{"format":"mp3","sample_rate":24000}}}`
- 返回 HTTP chunked，多片 JSON，把每片 `data`（base64）顺序拼接后解码即完整 mp3；`code=0` 为成功。
- 实测：预置女声 `zh_female_vv_uranus_bigtts`、祝福词 46 字 → 26 片、83,757 字节、合法 mp3（ID3v2.4 头），约 1 秒返回。脚本 `scripts/volc_tts_smoke.js`，支持 `node volc_tts_smoke.js "文本" "音色ID"`。

### .env 已固化（明文仅本地、gitignore 忽略；.env.example 只放占位）
`SPEECH_API_KEY`、`ARK_TTS_MODEL=seed-tts-2.0`、`ARK_VOICE_CLONE_MODEL=seed-icl-2.0`、`ARK_TTS_SPEAKER=zh_female_vv_uranus_bigtts`、`SPEECH_APP_ID=2253768025`；`VOLC_VOICE_ID` 暂空。

### 声音复刻：已实测跑通（2026-08-29 晚，样本=经典传媒企业介绍 342KB mp3）
- **接口**：`POST https://openspeech.bytedance.com/api/v3/tts/voice_clone`，Header `X-Api-Key=SPEECH_API_KEY`、`X-Api-Resource-Id=seed-icl-2.0`、`X-Api-Request-Id=uuid`；body `{speaker_id, custom_speaker_id, audio:{data:base64,format:"mp3"}, language:0, extra_params:{demo_text}}`。
- **三个必踩的坑（按顺序排掉才通）**：
  1. 不带 `X-Api-Resource-Id: seed-icl-2.0` → 500 `resource ID is mismatched`；
  2. 后付费音色 **`speaker_id` 必须填固定字符串 `custom_speaker_id`，自定义名放 `custom_speaker_id`**（字母开头、仅数字字母-_、8~256 位，且不能撞 S_/ICL_/_bigtts 等官方前缀后缀）；传空 `""` 会去要平台槽位资源而报错；
  3. 必须先在「开通管理→音色槽位→**后付费音色开通**」（0 元开通、约 1 分钟生效），否则 403 `volc.megatts.timbre requested resource not granted`。
- **实测结果**：12.8 秒训练成功，`speaker_id=jjsr_zh_voice_01`、`status=2(Success)`、剩余训练次数 15，返回 `speaker_status[0].demo_audio`（RIFF/WAV 数据，1 小时有效，脚本已落盘）。脚本 `scripts/volc_voice_clone_smoke.js`，结果存 `uploads/smoke/clone_result.json`。
