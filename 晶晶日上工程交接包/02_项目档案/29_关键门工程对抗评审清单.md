## 3. 安全官 · 安全与支付门（含本次支付专项核验）

### 3.1 通用安全
- [ ] 任何密钥只写服务器 `.env`，不进仓库、不打进 APK、不在日志/回复里回显；代码里只允许读 `process.env`。
- [ ] JWT 失效/过期有处理；需要登录的接口一律走 auth，不依赖前端藏入口。
- [ ] 越权：所有"查/改我的单、我的钱包、我的数字人"接口 SQL 必须同时带资源 id 与当前 user_id 归属条件。
- [ ] 入参校验/参数化查询，无字符串拼 SQL；输出按最小必要返回，不下发他人手机号/身份证等 PII。
- [ ] 合规：真人头像非动漫、AI 只出无文字素材、UI 文字一律 Flutter 叠加；实人/内容安全走 rms，可 COMPLIANCE_PROVIDER 回退。

### 3.2 支付安全专项（2026-09-06 已对后端源码做一次只读核验）
核验范围：`routes/pay.js`(V12.4 支付宝 APP 支付)、`routes/payment.js`(旧支付占位+苹果校验)、`services/paymentService.js`、`services/alipay.js`、`services/reconciliation.js`。

**已具备（本次读到代码证据，保持不回退）：**
- [x] **金额服务端权威**：`/api/pay/alipay/create` 金额只取业务订单行或 `config.sample`（意向金/制作款），前端夹带的 amount/price 等只用于 `clientClaimedAmount` **比对并拒绝篡改**，绝不参与下单；旧 `/pay` 直接用服务端 `order[amountField]`，请求体不传金额。
- [x] **越权防护**：create / apple-verify 的订单查询 SQL 同时带 `order_no` 与 `user_id`；status 查询带 `buyer_id` 归属或 admin。
- [x] **回调验签**：异步 notify 依次过 RSA2 `checkNotifySign(raw=true)` → app_id 匹配 → trade_status 成功态 → total_amount 与服务端支付单**数值比对**（兼容 99/99.00，NaN/缺失 fail-closed）；未配置支付宝时一律拒绝任何回调，防伪造入账。
- [x] **幂等/防重放**：`applyPaid` 在事务内仅当 payments 为 pending 才 changes=1 推进；相同 notify_hash 直接幂等返回；唯一索引 `idx_payments_one_pending` 兜住并发双击产生第二张 pending 单；苹果收据按 channel_txn_id(transactionId) 去重。
- [x] **防双加**：圆梦席位仅在 claims 真实从 pending→paid（changes===1）时才累加项目 raised_amount/client_count，重复回调不双加。
- [x] **主动查单**：trade.query 开 `validateSign:true`，且金额一致才补入账，网关异常 fail-closed、绝不异常时入账。
- [x] **密钥纪律**：私钥/公钥只从 env 或 PEM 文件读，日志只输出"是否存在/指纹/长度"，不输出密钥与签名串；未配置安全降级为演示占位、不阻断主流程。
- [x] **资金对账**：reconciliation 四本账（订单应收/支付实收/已退/应结）守恒，累计退款不得超过实收，识别孤儿支付、支付与订单金额不符、钱包余额为负；只核对落表/告警，绝不自动改业务数。

**待加固（低危/纵深防御，正式收款前收口；当前不阻断演示）：**
- [ ] W1 旧 `routes/payment.js` 的 `GET /status/:txNo` 仅按 tx_no 查询、未做归属过滤：登录用户若知道他人 tx_no 可读到该单金额/状态（无 PII）。建议补 user/buyer 归属条件或仅查本人。
- [ ] W2 公网回调可再加 notify_id/时间戳去重窗口做纵深防御（当前已靠 payments 状态幂等防重复入账，风险已被兜住）。
- [ ] W3 `trade.refund` 目前为预留能力：正式开放退款前必须补"退款金额≤可退余额、退款幂等批次号、退款审批/二次确认"，且纳入 reconciliation 退款守恒。
- [ ] W4 真机沙箱全链路（创建→唤起→沙箱支付→notify→status 轮询→业务单翻转）仍属 B3 等待项，代码已就绪、未做真机端到端，不得宣称已线上验证。
