规则一 · P1

账号注销、数据删除与 AI 内容退出规则

用户对其个人信息与数字人内容享有完整的知情权、决定权、撤回同意权与注销权。平台提供与开户同等便捷的注销、删除与退出路径。

1. 用户享有的个人信息权利

权利内容与实现方式
知情、决定权清楚知道收集什么、为何收集、共享给谁；可限制处理范围、拒绝非必要授权。
查阅、复制、可携带在 App 内查看/导出个人资料、数字人资产、订单与授权记录；可申请机器可读副本。
更正、补充、删除更正不准确信息；对特定内容行使删除权（"被遗忘"）。
撤回同意可随时撤回人脸、声音、相册、位置、通知等授权；撤回不影响撤回前已进行处理的效力。
拒绝自动化决策对画像、榜单、信用等自动化决策，可要求说明、拒绝或请求人工复核。
注销账号提供与注册同等便捷的注销入口；注销后按本规则处理数据。
近亲属权利用户死亡的，其近亲属可对逝者相关个人信息行使查阅、复制、更正、删除等权利（生前另有安排除外）。

  • 前置条件：无未完成的订单/试镜/承制、无未结清款项或待清分资金、无进行中的纠纷/投诉、无违约或违规处于调查中。
  • 存在未完成交易的，先完成结算或退款；属于交易依法须留存的记录，不因注销而立即删除。
  • 时限：核验通过后，平台在 15 个工作日内完成注销并反馈；法律、行政法规另有规定的从其规定。
  • 注销后无法登录、无法找回数字人资产与历史内容；平台在注销前显著提示后果并要求二次确认。

3. 注销/删除后数据如何处理

  • 删除或匿名化：注销后，对个人信息进行删除或不可复原的匿名化处理；人脸、声纹、生物识别等敏感信息优先删除。
  • 法定保留例外：为履行交易信息保存、税务、财务、网络安全、投诉处置等法定义务所需的最小必要记录，依法保留（如交易记录自交易完成之日起不少于 3 年），保留期满后删除或匿名化，且仅用于法定目的。
  • 已通过第三方（支付、实名人脸、IM 等）处理的信息，按其规则同步处理，平台要求其停止再处理。
  • 已对外公开或被他人合法保存的副本，平台在合理范围内提示删除。

4. 数字人 / AI 内容的退出（重点）

  • 撤回授权：用户可随时撤回肖像、声音、生物识别及 AI 训练授权。撤回后平台停止新增生成、停止新增上架与分发。
  • 下架与停止使用：撤回后，该数字人形象、样片、相关商品从艺人广场、商品页、推荐与搜索中下架，不再产生新交易。
  • 已成交订单：撤回原则上只停止今后新增使用；撤回前已合法成交、已交付买受人的许可副本，按已签许可合同约定处理，不影响买受人在原许可范围内使用。
  • 已训练模型：对已进入模型、无法在不影响整体功能情况下分离的部分，平台通过停用、限制调用、不再输出该形象、到期删除训练数据等方式处理，并在授权协议中事先明确。
  • 多方关系：数字人涉及 MCN、共创多人或已参演剧目的，撤回须结合已签合同、第三方权益与已发行作品处理；平台协助出具下架与停用清单。
  • AI 标识：退出与删除不影响已生成内容依法保留的 AI 生成标识。
撤回授权不等于删除全部已成交内容：为保护买受人合法权益与交易安全，已成交许可副本、已发行作品、已签署合同及法定记录按约定与法律处理；新增使用一律停止。

5. 第三方 SDK 通用要求

  • 最小必要：每个 SDK 仅接入实现功能所必需的信息；能在服务端处理的不下放客户端，能用匿名 ID 的不用实名。
  • 弹窗与授权：涉及人脸、声音、相册、麦克风、位置、通讯录等权限的，在使用场景触发时单独申请、单独同意，不得一揽子授权。
  • 合同前置：接入前签署数据处理协议（DPA），明确处理目的、期限、安全义务、不得留存/转售、事件通报与删除要求。
  • 动态核验：每次发版前核对 SDK 名称、版本、采集字段、隐私政策链接是否与实际一致；新增/变更 SDK 须先评估并更新本清单与隐私政策。
  • 境外提供：确需向境外提供个人信息的，须通过安全评估/认证/标准合同等合法路径并单独同意；境内业务默认数据不出境。
规则三 · P0

数据共享、委托处理与敏感信息规则

区分"共享、委托处理、转让、公开披露"四种对外提供方式，分别设定审批与告知同意要求。

1. 四种对外提供方式的处理口径

方式典型场景要求
委托处理火山/阿里云处理人脸与成片、短信/推送/IM 服务商、持牌清分签 DPA、限定目的与期限、监督受托方、不超范围处理；受托方不得转委托
共享向 MCN 提供其名下艺人的业务数据、向承制方提供必要素材最小必要、单独告知；敏感信息单独同意；签保密与数据处理协议
转让原则上不转让；合并/收购等确需转让时告知接收方信息并重新取得同意（法律另有规定除外），接收方继续履行原义务
公开披露公开展示数字人、样片、作品署名须在授权范围内；敏感信息公开须单独同意，法律另有规定除外

2. 敏感个人信息的特别保护

  • 人脸、声纹等生物识别信息、身份证号、金融账户、精确定位、不满 14 周岁未成年人信息属敏感个人信息。
  • 处理须具有特定目的、充分必要性，采取严格保护措施，并取得单独同意；处理前完成个人信息保护影响评估（PIA），报告与处理记录至少保存 3 年。
  • 人脸模板、声纹模型应加密存储，与身份信息分离，不用于授权外目的，不用于训练无关模型。

3. 用户对第三方处理的控制

  • 可在系统/App 权限管理中关闭相册、麦克风、位置、通知、相机等权限；关闭后相关功能不可用但不影响其他功能。
  • 可撤回授权、要求删除、要求平台通知第三方停止处理；可通过本清单了解每个第三方的身份与目的。
  • 平台对受托方/合作方进行尽调、准入评估、持续监督，发生数据安全事件按预案处置并依法通知用户与主管部门。
待补充（发版前必填）：各 SDK 确切版本号、官网隐私政策链接、最终选定的 IM/推送/电子签/地图/人脸服务商、持牌清分机构名称、是否接入数据分析与海外支付。技术负责人确认后更新本清单并同步《隐私政策》。
