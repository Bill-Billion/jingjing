财务核验对接清单 · V01 / V03

晶晶日上 · 上线前置财务核验清单

下列两项是开发上线的前置外部核验，需财务（联合法务、商务及持牌机构）提供书面或后台截图证据；未到位前，对应功能不上线。每项已注明用途与阻塞点，便于直接对照准备。

V01支付及自动清分（对接：银行 / 持牌支付机构）

目的：确认"代收—担保托管—分账清分—退款追回"全链路持牌合规，平台不设资金池、不触碰二清红线。
核验项为什么需要（阻塞点）期望形式
支付产品全名与版本确认支持"担保交易＋分账/清分"，而非仅普通收款产品页 / 合同条款
签约主体与准入条件确定以哪家公司签约、需哪些资质，避免主体错配准入清单 / 签约要求
持牌与资金监管路线证明资金由持牌机构监管、平台不设资金池、无二清牌照 + 资金流向说明
清分执行时点（T+1）明确指令到实际划付时长、节假日/资料不齐如何处理产品规则 / 结算说明
里程碑 / 担保放款定制阶段托管款能否按客户确认节点逐笔释放功能说明
退款与资金追回清分后退款如何按责任方从各收款方追回/撤回退款规则
保证金 / 风险准备金是否支持保证金账户的冻结、扣划、退还功能说明
费率与发票支付/分账/提现手续费计入成本，能否开票费率表 + 开票说明

V03合同、发票与个税（对接：财务 ＋ 法务 ＋ 商务）

目的：保证合同流、资金流、发票流三流一致，自然人艺人依法完税，结算可开票、可留证。
核验项为什么需要（阻塞点）期望形式
各类合同样例定制片、出演/肖像声音授权、MCN 合作、试镜出场、剧本授权、平台服务协议合同模板
开票主体与税目以哪家公司开票、各业务适用税目（现代服务等）开票信息 / 税目口径
自然人艺人所得所得定性（劳务报酬 / 经营所得）、扣缴义务人、税率口径税务口径说明
委托代征 / 灵活用工是否接入、用哪家、费率与凭证，解决大量自然人结算方案 / 报价
MCN 结算与发票路径MCN 向平台开票、平台向 MCN/艺人付款的完整路径资金/票据路径图
凭证归档清分回单、发票、完税凭证如何关联同一结算单留档归档清单

★协作与反馈方式

  • 建议财务在约定工作日内反馈（时限由财务确认）；先给已有材料，缺口项标注"办理中/预计时间"。
  • 材料回收后由我方逐项核对是否覆盖开发所需，未覆盖的再定向补充，不反复打扰。
  • 密钥、证件原件不在聊天中传输，统一走安全渠道并留痕。
不阻塞说明：开发可先用默认比例、时限、阶段框架推进；上述核验到位后再切换为真实通道与正式税务口径。
本清单用于业务对接与材料准备，不替代持牌机构、税务师或律师的正式意见；最终以主管机关及服务商最新规定为准。
