01产品总览与全局架构

先定清楚"我们是谁、有哪些角色、用户怎么进来"。

1.1 一句话定位

晶晶日上是数字经纪人平台，做的是数字人经济。口号：晶晶日上，做自己的人生主角。

说人话：就像传统经纪公司帮演员接戏、管合约、谈分成，我们帮每个人（明星、网红、普通人）的数字分身去"接活、授权、出镜"，也帮需要"人"的剧组、品牌、想当主角的个人，快速、合法地找到一张能用的数字脸。

1.3 【V4 最大变更】统一入口与底部五框导航

取消"进场先选身份"（沿用 V3），底部导航在 V4 重构为五个框。所有用户进入同一个广场，不进场选身份、不按角色换导航；全员底部固定 广场 / 试镜 / 通告 / 消息 / 我的 五个 Tab。
  • 打开即"广场"：第一个画面直接是广场（前端就叫"广场"，内部即艺人排行榜＋数字人货架，前端不出现"龙虎榜"三个字，"龙虎榜"仅作后台排行逻辑名）；左上角先选地理位置，做区域化、细分化、地方互动，主打"我周边能获取到的优质演员"；
  • 底部固定 5 个 Tab（按此顺序）：广场 / 试镜 / 通告 / 消息 / 我的（全员一致，不随角色变化）；
  • 视频商品不再单独占底部 Tab：样片 / 祝福短视频信息流并入"广场"内的"视频"子频道，同时挂在艺人详情页商品区；
  • 艺人个人页不占 Tab：从广场点选艺人即进入其个人主页；
  • 身份能力进"我的"：艺人、出品人、星探、平台运营（=设置）的专属功能都从"我的"进入；MCN / 卖家的批量管理不放进 APP，走独立 PC 网页后台（见 2.9）；
  • 一人多身份：同一账号可同时具备多种身份（如买家身兼艺人、MCN 身兼出品人），无需切换账号。

三套信用维度（务必分开，不可混为一谈）· 10-11 评审新增

维度是什么由什么决定影响
主角光环
（艺人真实信息认证）		类似"金牌讲师"、闲鱼"擦亮"，点亮＝完成真实信息认证，与等级无关按平台资料上传模板自助上传：模卡、生活照、全身照（一寸照 / 简历等可选），由平台或委托三方人工审核核验真实性；L1 实名免费，达人认证收 10 元 / 次审核费更靠谱可信，榜单曝光与被看到机会加权
等级艺人的成长级别累计接单 / 接商单的次数（数量）等级越高可接更高阶单、进大剧选角优先
好评（评分）服务质量出品人打分：是否真人、是否贴合诉求、成片完整度等好评低则排名降权、影响派单

说人话："主角光环"管你是不是真的、"等级"管你接过多少活、"好评"管你活干得好不好——三者独立计算，共同影响榜单排名。平台只负责把认证资料上传模板做好、艺人自助上传，不替艺人编造资料；认证材料与曝光权益后台可配。

买卖两侧分开算：上面三套（主角光环 / 等级 / 好评）是艺人（卖家）侧；买家（出品人）侧只有一套"晶钻"——消费获得晶钻、按累计晶钻定级（晶钻等级），积分与等级一体，星探是其中的高级身份。两侧分值不互通、不混表。

1.4 全局规则（贯穿所有模块）

  • 真实闭环：分账只动真实成交、已确认的订单，不做虚假过单；
  • 资金安全：资金全程持牌监管，平台不设资金池、不二清；
  • 资产归属：数字人形象、声音、样片版权始终归艺人本人，分成/代理不转移所有权；
  • 配置优先：比例、时限、阶段、许可范围、认证门槛后台可配，变更须当事人在线签署；存量订单按下单时口径执行；
  • 合规底线：合同流、资金流、发票流三流一致，自然人所得依法完税，AI 生成内容保留显式/隐式标识。

02功能模块需求（逐页）

按底部 Tab 与核心链路，逐页说明字段、交互、权限与状态。

2.1 广场 ·【视频】子频道：短视频化视频商品信息流

V4：视频商品不再是独立底部 Tab，而是"广场"内与【艺人】并列的【视频】子频道，同时挂在艺人详情页商品区；下列商品形态与交付逻辑不变。

  • 信息流形态：分类 / 栏目信息流，交互参考短视频 APP，上下滑动浏览视频商品；
  • 未购买状态（"黑内容"，不是黑框）：未购买＝未解锁态，画面整体为黑色，上面标明产品名称 ＋ 未解锁图标 ＋ 价格（带锁预览，不直接放完整内容）；
  • 即点即买：在商品页直接点购买、支付，不填复杂表单；
  • 解锁消费：付款后解锁观看，可自行下载（也可不下载），下载受授权范围约束；
  • 运营配置：平台可在 CMS 配置栏目、推荐位、全年节日套餐、短视频模板与走量 SKU。

2.2 广场 ·【艺人】子频道：数字人货架与排行榜

广场的作用是"看艺人介绍、发邀约"（类比大众点评看店铺介绍册）；而"按城市＋排名直接约试镜"在底部【试镜】Tab（见 2.4）。前端统一称"排行榜 / 榜单"，不出现"龙虎榜"三个字（仅后台逻辑名）。

分类筛选

题材（爱情/古风/都市/悬疑…）、性别、风格、粉丝量级、可授权用途、价格区间、评分、认证状态。

智能匹配

需求方输入剧本角色 / 品牌调性 / 个人故事，AI 推荐合适数字人并给对标参考视频。

数字人档案卡（货架信息要让人能挑、能比、能信）

形象模卡、声音试听、可出镜题材、授权范围（正面清单）、历史作品、评分、成交数、复购率、明码标价、认证标识。艺人主页放什么资料、放什么形象，由艺人自主上传维护，一期不做平台统一下发的"主题/角色标签菜单"。

艺人排行榜：榜单维度（至少包含，可再扩展）

  • 等级榜（成长等级 / 累计接单）、新人榜（保护新入驻、按近期新上架）、好评榜（服务评分）；
  • 建议再补：销量榜（成交金额 / 件数）、人气榜（浏览 / 试听 / 收藏）、复购榜（复购率）；所有榜单按左上角所选地理位置分区计算；
  • 排名权重＝成交 ＋ 评分 ＋ 复购 ＋ 活跃 ＋ 合规，违规 / 投诉核实后降权；
  • 广场另设"找出品人 / 机构"入口（出品人/机构城市榜），艺人可据此向高级出品人投稿自荐，详见 2.6。

2.3 视频商品与供给：自制 / 样品 / 精修 / 认证

本版放开供给：艺人 / MCN 可以自己制作、自己上传视频商品；也可购买平台的样品制作套餐、付费精修、官方认证服务。自制内容须过内容审核与授权校验。
取消"一键生成交付"。上一版"用户填信息、API 一键生成即时交付"废止。低价走量改为销售平台 / MCN 预制好的现成短视频现货（带锁、即买即得、零边际成本），不靠现场生成。

2.4 试镜（底部【试镜】Tab · 试镜中心）：双入口、一口价、试镜归试镜

两个入口分工（V4 定稿）：① 广场＝看艺人介绍/作品、发邀约（像大众点评看店铺）；② 试镜 Tab＝只列出"开放公开试镜"的艺人，选城市＋按排名直接约（像美团外卖点菜）。

  • 是否公开接试镜，艺人自己开关：艺人在"我的"自行设置【是否公开接试镜】【是否公开标价】；关闭者不在试镜 Tab 列表出现，只能在广场被看到后由买家发邀约、艺人同意才成行；
  • LBS 筛选：试镜 Tab 按城市 / 距离 / 评分 / 排名筛选；一期不做"角色/主题标签"筛选（不做主题菜单，见下条）；
  • 发起邀约：填写试镜城市、地址、时间与想试的方向/用途（自由文本说明），不在系统里点选固定角色标签；
  • 费用结构（一口价）：艺人设固定出场费总价，交通费由艺人按距离自行测算并打包进固定出场费、不另列（类似"包邮"）；平台按含交通的总价计入 22% 佣金基数，商品页只展示一个总价；
  • 远距离补差（一期做法）：一口价默认含常规交通；确实太远（如跨城打车约 200 元）一期不新增系统附加费字段，由双方在订单会话里提前协商、艺人改价或出品人补差（类比顺风车高速费），后期再做"远距离附加费"配置；
  • 先付款：按一口价总价支付生成邀约，资金进入托管；
  • 接单 / 拒绝：平台实名校验并推送邀约，艺人 / MCN 可接单或拒绝，未接单全额退款；
  • 试镜就是试镜（V4 定稿，一期砍主题菜单）：试镜是见面/取样，默认交付模板＝6 张照片 ＋ 1 段视频（建议到场后约 1 小时内交付，模板与数量后台可配）；一期不做"古装/医生/老师等主题/角色点选后妆造必须一致"的强制菜单——艺人主页放什么形象就是什么，需要何种妆造、是否自带装备由双方在订单会话沟通，平台不提供服装、不做妆造；
  • 履约认定（出品人确认）：艺人按约到场完成试镜后，须由下单的出品人在 APP 内点"确认履约"方为履约成立、触发清分，不以最终是否被录用为条件；出品人逾期未确认的，系统到时自动确认（保护艺人、防恶意不确认）；
  • 过程留痕：邀约、行程、交付、退款、分账全程记录，客服可介入。
试镜成功之后的"数字人参演/版权"是非标，一人一剧一价（V4 关键定稿）：试镜只是见面/取样，不等于出品方拿到该数字人的角色使用权。数字人后续参演哪部剧、用于什么场景、是否独家、固定买断还是按收益分红、分红比例多少——一律由艺人自行定价、双方线下撮合，平台不做固定档位版权商城。线上只承载标准化的"定制/参演报价单或电子合同 → 出品方付款托管 → 平台按合同约定清分（合同里可写多方分红比例，清分引擎按比例分）"，归入商单 22% 抽佣口径。
防滥用护栏（必须实现）：仅实名买家/出品方可发起；邀约须说明真实试镜用途/剧目方向、明确时间城市与正规试镜地点；费用为出场费（含交通）一口价；对无真实目的、要求去酒店房间等非正常场所的，拦截并封禁；不得以"试镜"名义开展无真实用途的线下见面或陪侍。
真人试镜 → 数字人造型底板（核心底层逻辑，开发须建库）：
数字人试镜是"通过真人试到数字人"——试镜取样的真人影像、妆造、装备直接入库，成为该数字人的造型底板与 AIG 排剧 / 镜头的底层框架；素材以艺人自主准备/上传为主，平台不凭空修造造型，也不接受后期把造型 P 到数字人上。没有真人取样底板，AI 创作就没有起点。试镜素材关联对应 digital_assets，底板归属艺人本人。

03商业模式与分账结算

这是后端分账、清分、开票的核心规格，数字为默认值、后台可配。

3.1 四条收入线

① 撮合抽佣

样片/数字商品抽 18%，商单/线下出场抽 22%；数字商品零边际成本、可无限次售卖。

② 自营定制/承制毛利

定制片、代做样片、剧集承制，平台全额收款、约 30%–70% 毛利。

③ 创建托管增值

数字人创建 60 元/人、托管 29 元/月，精修、认证、样品套餐。

④ 加成项（非前提）

补贴、奖项、多平台回款、爆款分成；业务不靠补贴成立，补贴是锦上添花。

V4 补充收入线：⑤ 星探预充值——成为星探须先向账户余额充值满 300 元（可消费、不可提现、持牌托管）解锁新锐，每个会员年累计充值满 300 续期：锁定预充值资金与年度活跃，收入随实际消费确认；2–6 级靠真实消费累计晶钻成长、不收费买级；⑥ 付费投流 / 广告——艺人/MCN/出品人未来购买排名置顶与曝光，一期不开通、仅预埋字段，有量后开放。另：数字人参演 / 版权为非标"一人一剧一价"，不做固定档位，按合同价归入商单 22% 抽佣、支持合同内多方分红；MCN / 艺人找平台代做样片、代做定制片、代承制剧是平台自营毛利的重要来源（见 3.4）。样片/数字商品零边际成本、可重复售卖是规模效应核心：一份样片做好后可卖给大量出品人，主要大头收入来自艺人把样片/数字形象反复售卖给出品人产生的撮合交易。

3.2 两层分账模型

  • 第一层 · 平台佣金：样片 / 数字商品 18%；商单 / 线下出场 22%；返佣从平台佣金中列支；
  • 第二层 · 供给侧分成：扣佣后的 82%（样片）/ 78%（商单）在艺人与 MCN 间分，默认艺人 80% / MCN 20%（可配 10%–30%）；独立艺人（无 MCN）全额拿 82% / 78%；
  • 自营 / 增值类：平台 100% 收款，承制 / 算力为成本项，不进两层分账。
