4. 状态机与定时任务

新增状态机

对象状态流转
订单会话未付款（不可聊）→ 已付款/邀约已接受（开通双向）→ 履约中 → 已清分（归档只读）；纠纷时冻结
投稿 / 意向submitted → interested（→ 生成客服工单 cs_handled）/ declined；interested 之前不产生双向会话
星探会员inactive → active（达标自动 / 付费）→ expired；降级收回发通告与接投稿权限
晶钻等级按累计获得晶钻每日重算，只升 / 按规则保级（抽奖消耗可用余额、不降级）；阈值后台可配

新增定时任务（cron）

  • 每日：按累计晶钻重算星探 2–6 级成长等级、核对本会员年累计充值是否满 300（满则顺延、到期未满则冻结特权，再充满即恢复 growth_level）、生成出品人 / 机构城市榜快照；
  • 每日/每小时：会话敏感词复核、超期订单会话归档；
  • 投流相关 cron 一期不部署扣费逻辑，仅保留权重读取。

沿用 V3 既有：出品人自动确认 48h、意向卡 72h、数字商品售后 7 天、清分 T+1、成长值 90 天保级、月冠军评选等，不变。

5. 权限 / 鉴权变更（RBAC）

  • 买家：实名即可下单、买数字商品、发试镜邀约与意向卡，无营业执照门槛；
  • 星探（会员有效）：发商单 / 招募、城市榜优先、接收投稿须有效星探（新锐 1 级起）或机构；发活动通告需铜牌（3 级）、大型招募 / 活动主办需钻石（6 级）；会员到期冻结后收回上述权限；
  • 会话权限：订单会话仅买卖双方＋平台客服；投稿信箱单向，未"同意合作"前禁止双向发消息；
  • MCN PC 后台：独立 B 端登录与多艺人授权关系（一号管 10–20 人），与 C 端 token 体系隔离；
  • 所有消息、投稿、合同、改价补差动作实名＋留痕＋敏感词风控，站外导流预警/封禁。

6. 一期"不做但要预留"清单

事项一期处理
付费投流 / 广告建 ad_bids/rank_weights 与广告位字段、总开关默认关；无前端入口、无扣费
试镜主题/角色标签菜单不做筛选器与点选；艺人主页资料自主；后期再迭代
数字人参演/版权商城不做固定档位 SKU；走报价单/电子合同＋多方分红清分（一人一剧一价）
远距离附加费不做系统字段；订单会话协商、艺人改价/出品人补差
剧本提供方自助门户端口/角色预留，本期线下商务签约（沿用 V3）
婚礼/AI 婚庆等细分一期不上线，避免能力不达与反复改版

7. 提测验收清单（测试照此勾）

  • 底部固定且仅有 5 个 Tab：广场/试镜/通告/消息/我的；首屏为广场；全 APP 前端无"龙虎榜"字样。
  • 广场可切【艺人】【视频】；视频商品在视频子频道与艺人详情均可购买/解锁/下载。
  • 试镜中心只出现"公开试镜"艺人；关闭开关后该艺人不在试镜列表、但仍可在广场被发邀约。
  • 试镜下单为含交通一口价、按总价抽 22%；无主题标签点选；默认交付 6 照 1 视频。
  • 未成交时投稿/意向只能单向发送，无法双向聊天；点"同意合作"后生成客服对接工单。
  • 订单付款/邀约接受后，买卖双方出现双向会话与客服入口，消息过敏感词、有留痕。
  • 买家实名即可购买；晶钻等级按累计获得晶钻正确刷新（抽奖消耗可用余额、不降低累计等级）；星探晶钻达标 / 付费后才能发正式通告、接投稿。
  • L1 实名认证免费；达人认证（L2/L3）提交需支付 10 元审核费并进入人工 / 三方审核，通过后点亮主角光环，驳回可补料重提；不收保证金。
  • 星探：未开通用户不能发通告 / 接投稿 / 上榜；向余额累计充值满 300 元（进可消费余额、不可提现、非会费）后即时解锁新锐 1 级；2–6 级仅按累计晶钻自动晋升、全站无付费升级 / 补差价跳级入口；每个会员年累计充值满 300 续期，未满到期冻结、等级与晶钻保留、再充恢复；只充值未消费不得晶钻。
  • 出品人/机构城市榜按城市与等级正确排序；艺人可提交三类投稿并看到状态流转。
  • 通告六类可分类浏览；仅星探/机构可见并使用"发布通告"；招募可收到投稿。
  • 非标参演：可建报价单/合同（含多方分红比例）→ 付款 → 按合同 T+1 清分到多方，金额合计=100%。
  • MCN PC 后台可登录并管理多艺人、上架、分单、看看板；APP 内无 MCN 批量管理入口。
  • 投流/广告无任何可下单入口，相关表与配置存在且总开关为关。
  • 分账 18%/22%、艺人80·MCN20、足额纳税口径、清分状态机与 T+1 无回归。
不变项（防止误改）：平台定位与 slogan、分账比例、艺人三套信用＋买家一套晶钻（积分与等级一体）、持牌清分不设资金池不二清、数字人资产归个人、每部剧平台真实闭环。
