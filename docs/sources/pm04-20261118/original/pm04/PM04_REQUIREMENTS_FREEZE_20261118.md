- `.../26.md`（退款规则）：未成年误充经监护核实后原路退款，非自动退款。
- 正式覆盖：`ACC-DEL-02.01`（真实年龄）、`02.04`（代理及监护）、`23.03`（年龄与消费）是直接核心；`23.04`（偏好申诉）、`19.05`（付费投票限制）是关联项，仍保留原151条分母。全部这些目前为**部分验证**，不得冒称通过。

原文可能存在措辞交叉：制度写“监护人单笔消费同意”，理性使用规则写未成年人不得参与付费经营/充值。当前已实现的解释是**监护同意仅记录，不解锁实际收费**；这不是新策略。若原文仍需律师出具解释，建立“原文冲突解释单”，**不另添功能或私自放宽门禁**。
