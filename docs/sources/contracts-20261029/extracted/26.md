退款 / 售后 / 纠纷处理规则

明确各类订单在清分前后的退款路径、部分履约结算、售后与纠纷裁定，以及风险准备金的垫付与追偿，保障买家权益并保护卖家合法收益。

1. 退款基本原则

买家资金全程在持牌机构监管账户，平台不设资金池；退款按订单是否已清分、履约程度、责任归属分别处理。

退款须通过平台申请，站外私下交易不受平台保护、不予受理。

2. 售后与争议处理

售后时限：数字商品交付后 48 小时确认；服务/定制类可按合同约定设置验收期与售后期。

争议范围：未交付、内容与描述严重不符、质量不达标、授权链瑕疵、错发漏发、数量/时长不符、付款后无法联系等。

买卖双方应先自行协商；协商不成任一方可申请平台介入，双方须在规定时限内举证（订单、聊天记录、交付物、付款凭证、素材源文件等）。

3. 纠纷冻结与平台裁定

冻结：未清分的争议订单全额冻结；已清分的冻结等额风险准备金/保证金。

裁定：平台依据合同、规则与证据组织调解；调解不成的，依双方仲裁/司法结果执行。

平台裁定结果可导致继续清分、部分退款或全额退款；对恶意欺诈、刷单、伪造证据的一方从严处置并记录信用。

4. 保证金与风险准备金

保证金（可选）：MCN/承制方可缴纳保证金，用于担保退款、违约与交付，提升清分优先级。

风险准备金：平台按合规内控要求计提，用于清分后退款先行赔付、向责任方追偿；垫付后依法向责任方追偿。

尾差：分账按"分"四舍五入，须保证各方金额合计＝可分账金额；尾差（通常≤1 分）由平台承担并记录 rounding_diff。
