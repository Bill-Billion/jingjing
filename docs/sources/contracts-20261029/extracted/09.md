第二条　人格权不转移（核心）

尽管著作权归甲方，乙方数字人所承载的肖像权、声音权等人格权始终归乙方本人，不因著作权归属而转移。

甲方行使著作权不得超出乙方在合同1、2、3中授权的用途、地域、期限与改编边界；乙方对数字人形象享有表明身份/不署名、禁止丑化贬损、禁止用于违法及授权外场景的权利。
