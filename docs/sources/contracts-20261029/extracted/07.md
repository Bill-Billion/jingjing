三、保护措施与 PIA

处理者对生物识别原始样本与特征模板加密存储、最小授权访问、去标识化处理、日志留痕，不用于本同意书以外目的，不非法买卖、提供或公开。

处理者已就敏感信息处理、自动化决策、对外提供及数据出境开展个人信息保护影响评估（PIA），评估报告与处理记录至少保存三年；确需出境的，依法通过安全评估/标准合同/认证并另行取得单独同意。

发生或可能发生泄露、篡改、丢失的，将及时采取补救并依法告知与报告。

平台一期不向不满14周岁未成年人提供数字人创建服务；如未来开放，须取得监护人单独同意并适用更严格规则。
