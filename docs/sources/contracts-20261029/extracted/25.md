商单 / 非标参演规则

适用于数字人参演具体影视剧、定制广告、非标合作等无法用标品一口价覆盖的交易。核心是"一人一剧一价、电子合同、付款托管、按合同多方清分"。

1. 非标交易的特点

价格、角色、戏份、用途、地域、期限、独家与否、分红方式均因项目而异，不设固定版权档位，由双方协商确定。

出演方式可能是：买断、独家许可、按收益分红、固定片酬＋分红等；最终以《数字人参演/版权合同》（电子合同）约定为准。

平台仅提供信息展示、撮合、合同签署、付款托管与清分，不替任何一方确定片酬、不承诺出演结果。

2. 交易流程

选角/投稿/撮合  →  报价单（一人一剧一价）  →  电子合同签署  →  付款托管  →  里程碑履约  →  验收  →  按合同多方清分

报价单：列明角色、片酬或分红、付款节点、交付物、修改次数、用途与期限、版权归属、违约条款。

电子合同：非标参演必须签署书面电子合同，作为清分引擎多方分账的依据；无合同不进入付款托管。

付款托管：出品人款项先入持牌机构监管账户，按合同节点（如 30% 开工、阶段款、尾款）放款。

线下撮合边界：主创沟通、试戏、拍摄可线下进行，但资金、合同、确认必须走平台；禁止脱离平台私下付款。

3. 分账、佣金与税务

平台对商单/非标参演及线下成交按成交额抽 22%；含制作/承制的，制作费、客串数字人授权费等按合同列支。

清分按合同逐节点进行，每笔订单可产生多个分账批次，全程幂等、不可重复清分；尾差由平台承担。

自然人收款须先确定税务处理方式（自证企业身份/平台委托代征/自行申报），依法开具发票或代扣个人所得税后方可清分；坚持合同流、资金流、发票流三流一致。

红线：禁止以商单名义进行站外交易、阴阳合同、虚假分成、规避分账或虚开发票；发现即冻结、封禁并依法处理。
