合成语音在语调、语种、情感风格上的调整，以不歪曲、不丑化乙方形象、不损害乙方人格尊严为限。

第三条　禁止性用途

严禁将乙方合成语音用于：伪造他人或乙方本人意思表示、电信网络诈骗、虚假陈述、色情、赌博、涉政敏感、违法犯罪及损害乙方名誉的任何内容。

甲方应通过技术与审核措施防止合成语音被滥用；发现违规使用应立即停止并处置。
