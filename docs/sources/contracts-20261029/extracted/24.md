试镜服务规则（含线下安全）

适用于出品人就特定角色/场景发起的试镜邀约，包括线上试镜与线下试镜（一口价含交通、可由艺人自行上架、由出品人付款）。

1. 试镜邀约与上架

试镜分为线上试镜与线下试镜，均为独立业务、正常上架，可由艺人自行设置是否接受。

线下试镜采用"一口价含交通"（类似包邮）：艺人只设一个固定出场费总价（已含交通），商品页只展示一个价格；不再单列交通费、不做凭票报销，平台按含交通总价计入佣金基数。

艺人可设置试镜公开开关、可接时段、所在城市与可赴约范围；出品人发起邀约后由艺人接受，或艺人自行上架供出品人下单。

2. 标准交付内容

线下试镜默认交付为约定拍摄/试镜过程＋6 张照片＋1 段视频（具体可在商品页约定，以订单确认为准）。

线上试镜按约定交付试镜视频/素材；试镜素材的用途以商品页与电子合同约定为限。

面试/试镜只提供"机会"，不承诺角色：最终出演主角、配角或群演由剧组按人物匹配结果决定，与《晶钻抽奖规则》中面试卡"不承诺角色"口径一致。

3. 下单、付款与安全护栏

出品人下单后款项进持牌机构托管，试镜完成并确认后 T+1 清分；平台不提前放款。

线下安全（重点）：① 平台仅支持在正规、公开、可核验的场所进行，艺人可拒绝偏僻/封闭/夜间场所；② 线上行程、地点、联系人信息留痕；③ 提供一键分享行程、紧急联系/求助入口；④ 建议购买意外险并作安全提示；⑤ 严禁以试镜名义实施违法、色情、陪侍或其他线下违规活动，一经发现立即封禁并上报。

出行、打车等费用已含在一口价内，平台不另设交通费字段。

双方在正式合作前仅可通过平台消息进行单向沟通，建立合作、客服介入对接后才可双向，全程留痕，禁止站外私下交易。

4. 确认、佣金与取消

试镜完成并交付后，出品人48 小时内未确认且无异议的，系统自动确认并清分。

平台按含交通的一口价成交总额抽 22%；供给侧按 MCN/艺人约定分成。

取消：试镜前出品人取消的，按双方约定与平台规则处理（未履约全额原路退）；艺人方无正当理由失约的，影响其信用、评分并可能承担违约责任；因不可抗力或安全原因取消的，按规则四安全免责处理。

后续参演：试镜成功后，数字人实际参演某部剧属于"商单/非标参演"（见规则三），另行一人一剧一价、签署《数字人参演/版权合同》并由出品人付款，不包含在试镜费用内。
