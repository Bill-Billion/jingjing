1  产品定位与总体业务逻辑

### 段落 0034
1.1  一句话定位与业务本质

### 段落 0035
晶选片场是连接“数字人”与“剧本/制作资源”的平台：用户先建立属于自己的数字人，再通过平台完成从试镜（选角/竞拍角色）到定制剧交付的全流程，最终既可以“做自己人生主角”自娱消费，也可以进一步“成角”走向公开发行与商业变现。

### 段落 0036
用户心智可类比“凑资源圆梦”的撮合平台；但对外合规形态是“角色/服务的商品交易”，不是金融意义上的众筹。平台同时承担交易撮合、制作交付、内容审核与资金结算监管四类职责。

### 段落 0037
1.2  最高约束：两条业务线严格分离

### 段落 0038
“对内自娱（主角）”与“对外发行（成角）”是两套不能混淆的逻辑，几乎决定了审核强度、平台责任、界面选项与数据字段。任何功能在设计时都必须先声明它服务于哪条线。

### 段落 0116
5.1  实体关系总览

### 段落 0117
