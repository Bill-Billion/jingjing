### 段落 0024
1.1 项目定位与边界

### 表格 0025
行 1
  列 1：项目定位
晶晶日上是一套连接数字人权利人、MCN、剧本方、制作方、企业客户与影视项目的数字经纪与项目管理平台。它的核心价值是把人、授权、剧本、项目、交付、合同、发行收入和结算记录放到同一套业务体系中。

### 段落 0026
V1 不把晶晶日上做成短剧播放平台，也不试图替代专业 AI 影视制作工具。真正的内容制作可以发生在火山引擎或其他专业制作平台；剧组内部也可以继续使用自己熟悉的工作方式。晶晶日上负责保存经过确认的项目事实、协议、版本、节点和结算结果。
