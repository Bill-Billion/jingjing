## 1. 确认工作区和GitHub身份

工作区：`D:\ccc\博士资料\7.项目\2026-晶晶日上`。

先列顶层目录（包含隐藏项）；检查工作区自身和`repo`子目录是否为Git仓库。如果发现多个仓库，逐个看remote，不扫描用户整个D盘。

可用检查命令：

```powershell
Get-Location
Get-ChildItem -Force
Get-Command git, gh -ErrorAction SilentlyContinue
gh auth status --hostname github.com
gh repo view Bill-Billion/jingjing --json nameWithOwner,defaultBranchRef,isPrivate
```

不要加`--show-token`，不要输出访问令牌。账号不同也不自动logout；先核对能否访问目标仓库并告知用户。认证失败由用户在自己的终端完成交互登录；不让用户把token发到聊天。

仅在没有可复用正确仓库、且`repo`不存在或为空时：

```powershell
gh repo clone Bill-Billion/jingjing repo
```

不使用`clone ... .`，不覆盖现有目录。

已有仓库先记录status和HEAD，不自动pull合并；获准fetch只更新远端引用后比较差异。新clone与已存在工作副本都要明确主分支和审计commit。

```powershell
git -C <已核实仓库路径> status --short
git -C <已核实仓库路径> remote -v
git -C <已核实仓库路径> branch --show-current
git -C <已核实仓库路径> rev-parse HEAD
git -C <已核实仓库路径> log -20 --date=iso-strict --format="%h %ad %s"
```

若remote含凭证，报告中脱敏。GitHub“Code ZIP”没有.git历史，不能据ZIP文件名推断commit。
