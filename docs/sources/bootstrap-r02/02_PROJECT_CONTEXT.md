## 3. 本轮业务是什么

项目不是红果式刷剧平台，也不是重造AI视频模型或完整制片软件。它连接需求方、数字人权利方、MCN、作者/版权方、制作方，并记录交易、授权、内容、项目与结算。

### 私人定制

用户选择自己的数字人、故事/剧本许可和角色，确认报价与授权，支付首款；制作方提交样片；用户修改或确认；确认样片后按约定付尾款；制作并验收成片。私人交付不自动授予公开商业发行权。

### 数字人经营 / 商单

合法可商用的数字人及其管理方提供服务、接单、交付、处理争议并按对应支付方案结算。与私人订单分开确定供给主体、用途、责任、金额和状态。原P1不能再作为本轮不做的理由。

### 成角 / 发行项目

项目可由个人升级、品牌/企业委托、平台或制作方发起；匹配角色和各供给方，按用途重新核验授权、版本、多方确认和实际发行条件。发行账单可以先人工导入，不代表播放平台已打通。角色竞拍等存在于原需求，须识别范围和风险条件，不能只换名称就断言安全。

### 剧本许可

个人作者和机构可出售有权出售的许可，用户在定制中选择或单独采购。出售许可与承接改稿/制作可以组合报价，但不是同一履约义务；不能只新增“上传Word”功能就算完成版权供给。

### 直接对话支持的方向

- 本轮统一定下完整建设任务，不再因旧阶段标签整块后置。

- 15%剧本许可佣金、50%首款、2轮修改、90秒成片、30秒样片、5日工期、5单产能。
- 某一法律身份一定合规、某张证件足以确权、某项服务已通过商店。
- 平台在所有订单上统一自营，或在所有订单上统一只做撮合。
- 非独家一律不能商用、独家一律可发行、藏下载按钮即可防盗。
- 样片六条已经完整收到，或者2分钟旗舰意味着所有成片必须120秒。
