# 本轮完整范围与设计起点

**性质：供首轮归并和详细设计使用的暂定范围，不是全量业务批准书。**

## 1. 范围总原则

本轮交付清单覆盖用户侧、运营侧、合作方侧的真实操作和异常路径。原分期只作来源字段，不作为拒绝纳入的理由。内部工作包的顺序由依赖决定，不称为产品一期二期。

建立一个总清单并分别标注：`本轮已明确纳入`、`本轮建议纳入待确认`、`规则/外部条件阻塞`、`未被本轮明确纳入`。对每条REQ都给去向，不能用“新需求很多”跳过原P1/P2。暂未确认的风险功能也不能悄悄删除。

## 2. 三端实际职责

|入口|用户及职责|本轮要求|
|---|---|---|
|C端App|消费者、数字人权利人；选本、定制、项目参与、查看本人授权和结算|保留旧可复用页面，重排新版业务与真实状态，不只是改栏目名|
|A端运营中心|运营、审核、商务、财务等；代操作、内容/权利审核、订单与项目管理|可以代上传、代录账单，不能代个人同意、代真实付款成功、随意改历史|
|B端合作方工作台|个人作者、机构版权方、MCN、制作方及其工作人员|本轮具备自助申请、管理与查看能力，不能仅留字段或链接|

B端“个人作者”不要求伪装成公司；一家机构可以同时经营数字人、作品许可和制作。各业务能力分别核验、授权人员分别控制。

## 3. 不应混为一谈的对象

- 登录账号：谁操作。
- 个人/机构主体：谁签合同、谁承担责任、谁收款。
- 数字人：谁的形象/声音/数字素材，可在哪些范围使用。
- 机构管理关系：谁在何时可代表谁执行哪些管理动作。
- 原始作品：原著或原创剧本及其版本、来源、作者和权利人。
- 许可商品：可售范围、价格、独家性、地域、语言、期限、数量。
- 已购许可：具体接受方、项目、范围、生效条件和凭证。
- 项目改稿：在许可范围内产生的定制文本和分镜版本。
- 最终作品：样片/成片、版本、确认及传播限制。
- 客户订单：购买哪几种商品/服务，每项谁提供、承诺什么。
- 制作任务：由谁完成、交什么版本、客户如何反馈。
- 发行项目：多人协作、权利汇集、外部发行和发行收入管理。
- 应付/结算单：记录应付义务；付款记录另证实是否真正出款。

以上是候选领域边界，不要求照此机械新建同名表，也不允许本轮先推倒旧表。

## 4. 三类钱与多种交易身份

|类别|例子|设计约束|
|---|---|---|
|客户付出的交易款|许可费、制作费、陪演/商单服务费|报价列明构成与提供方；组合订单不重复收已包含费用|
|向供给方的应付和结算|作者许可结算、制作采购款、演员/机构报酬|区分履约义务与支付通道，不把数据库余额当真实托管资金|
|发行后的项目收入|实际渠道账单、版权收入、合同约定分配|不是用户购买角色的本金回报；按有效合同和真实账单记录|

自营定制与外部作者直接许可可能同时存在，必须按订单明示主体。不能拿R0.1真实自营假设，默认消除新开放交易的收款与责任问题。消费支付、多主体结算和发行财务付款分开核验。

## 5. 剧本版权增量：本轮必须纳入设计的完整链

个人/机构申请供给身份 → 提交作品和权利材料 → 权利与内容分别审核 → 发布获准梗概及试读 → 配置许可商品 → 用户独立或组合购买 → 条款/付款/权利条件满足 → 生成许可并绑定项目 → 指定制作人员受控访问 → 交付版本 → 分别结算许可与制作 → 处理投诉、退款、调整和历史查询。

### 必须同时考虑的异常

- 独家窗口范围冲突、同一时刻重复购买、预留过期后迟到付款。
- 原著改编权缺失、代理人无权转许可、共同作者或旧授权影响新许可。
- 下架商品后旧客户仍需查看自己的有效许可和对应文件。
- 制作取消与许可退款分别判断；权利瑕疵不能被“不可退”简单阻断。
- 必要外部制作导出须合同允许、人员获准且有水印/日志；不承诺绝对防复制。
- AI处理许可与通用训练许可分开，不能把购买后的全本默认发给任意模型。
- 版权方个人与机构的真实收款身份和通道产品分别核验。

## 7. 条件未定但不能假装缺席的范围

- 角色竞拍、保证金、转让、退出：保留原V3来源，先判断购买的服务是什么，及提供方、规则、支付和合法性条件；不要用改文案证明风险消失。
- MCN分销/带量计酬：记录原提案与R0.1修正意见，不能根据“最多两层”自行认定合法。
- 合作人提现、多主体清结算：产品和权限可以设计；具体渠道能力未核验前不能模拟成真实出款。
- 商业发行：完成申请、材料、多方版本确认、渠道档案及账单管理；实际提交与审核结果依真实合作方。

## 8. 未被最新反馈自动纳入的内容

海外正式运营、实时自动抓取发行平台账单、自动影视利润转账、完整制片日历/通告单、自研生成模型、通用流程搭建器，仍须明确范围才能增加。不得借“全部”无限扩张。语言/地区/货币等必要扩展边界可以在设计中考虑，但不等于已经承诺海外上架。

## 9. 普通可配置项与保护条件

可以版本化配置的：商品规格、价格、提醒、产能、经批准的佣金及折扣策略。

不可作为普通运营随意关闭的：用户/机构隔离、真实付款验证、必要身份与授权、内容标识、受限素材访问、旧条款留档。变更用途、独家范围、许可接受方、退款责任和收款主体，不只是改一个数字。
