一、它是第三类供给侧机构，不是 MCN

平台未来有三类 B 端供给方，建议共用一套"机构入驻+资质审核+分账+工作台"底座，用"机构类型"字段区分（这样开发一次，以后加第四类机构不用重做）：

|机构类型|供给什么|对应板块|
|---|---|---|
|MCN / 经纪|数字人、演员|培育、陪演、商单|
|制作方 / 导演|制作产能|入戏、成角|
|剧本版权方 / 编剧机构（本次新增）|故事、剧本版权|选剧本、高定、成角|

二、核心逻辑：用户买的是"开发授权"，不是著作权

版权始终归编剧/机构，用户买的是把这个本拍成数字人剧的授权。建议分两档（正好挂在两线分离上）：

|授权档|权利范围|能否复用|用途|
|---|---|---|---|
|非独家模板授权（便宜）|一次数字人剧改编+摄制+自用传播|一个本能卖给多人|仅自娱定制，不可发行|
|独家/高定授权（贵）|买断影视化开发权或独家窗口期|售出即锁定/下架|可走成角发行，版权方可另谈发行分成|

三、上架展示与防盗（关键，不然本子会被白嫖）

- 公开页只放：故事梗概、题材标签、人物小传、角色数量（决定要几个陪演）、少量试读（前1–2场）、建议集数/时长、适配档位、授权类型与价格；
- 全本在买下授权后才在平台内向制作侧开放、不可下载；
- 剧本上架前先做版权存证/时间戳/DCI（沿用 B5 的持牌存证），把权属先固定。

四、入驻、责任与分账

- 资质：编剧个人=实名+原创权属承诺；机构=营业执照+授权链；签入驻协议含侵权担保条款（侵权由上传方担责，平台走双轨审核+通知下架/避风港）；
- 审核双轨：版权链审核 + 剧本内容合规审核（涉政/低俗/抄袭一并卡）；
- 分账：剧本授权费版权方拿大头、平台抽佣，走 A5 持牌分账、授权/验收后入可结算；版权方是稀缺供给，建议抽佣低于普通商单（10–20%，具体数值你定）以吸引好本子。

五、分期（按你说的"前期线下、端口提前留"）

- P1：开放版权方自助入驻门户 + 剧本方工作台（上传/管理/销售/分账提现）；
- P2：独家高定授权 + 发行权交易、版权方参与发行分成。
