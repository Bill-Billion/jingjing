# 工作日日历的来源和使用边界

CN_2026.json依据国务院办公厅国办发明电〔2025〕7号整理，核对日期2026-11-02。原发2025-11-04；本次读取[北京市政府转载全文](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)，原中国政府网链接本次返回403，未声称已读取原站。仅提取休息日期及调休工作日，不复制整篇文字。

这是一份可供审核的2026年日历，不是自动生效配置。前端/运营创建新规格时纳入此日历，经现有独立审核后随报价和合同保存；已成交订单不随本文件更新。正式发布仍需双方审阅新规则和页面。2027年及以后的日期没有填成普通周一至周五：本文件覆盖外，程序不自动启动验收倒计时；后端维护后续年度官方日历并按新版本发布，客户仍可主动确认。

合同计算暂定口径：北京时间；收到当日不计入；从次日开始数5个工作日，第5日23:59:59.999截止。周末默认休息，working_dates明确覆盖为调休上班，non_working_dates明确覆盖为休假。不存在/重复/冲突日期或覆盖不足直接拒绝，不回退120小时。计时口径是项目实施暂定方案，国务院文件只提供休假安排，不代表其规定本产品验收时限。

测试中的synthetic-calendar-*用于可重复的边界验证，与此官方来源候选文件分开；不得拿合成日历作为正式合同配置。
