# 第十九轮：原消费积分、制作金核销、两笔退款与待冲回

当前为 **T1 首轮机测与确证问题现场修复**，持续目标 ACTIVE。本轮补原 E2E-06 的真实来源：App 新购700元合成现货，售后期后由原消费发7000积分，6000积分兑换制作金，再完成失败释放、重付核销、制作首款退款和原消费退款。26项不同的浏览器接续检查、3项原键API恢复检查及只读数据库核数通过；未确认新的前后端业务缺陷。

## 实际效果

App 选择已生效钱包规则并开户时，现金、可用积分和成长值均为0，没有注册赠分。随后本人在App创建700元现货订单、准备付款；合成渠道确认后，按原付款核对成功，App下载并确认原4965字节可播放合成文件。

原消费收益在7天售后期内保持 PENDING/AFTERCARE_WINDOW，积分不可用，真实兑换被 WALLET_POINTS_INSUFFICIENT 拒绝。专用隔离数据库的业务时钟从第0天前进到第8天后，App同步同一收益，发放7000积分；重复同步仍是同一条收益，没有再发一次。这里使用隔离业务时钟，**不是现实中观察了8天**，也没有修改订单日期、积分余额或业务状态。

本人在App用6000积分兑换50元制作金，剩1000积分，累计发放与成长仍为7000。制作金用于500元原报价后，现金价450元，原30/40/30分期为135/180/135元。

第一笔付款明确失败后，券仍被原订单占用；App取消未收款订单才释放。本人新建故事、制作人在Vue给新报价、另一账号独审后，再用同一张券。付款结果 UNKNOWN 时，取消被 PAYMENT_RECONCILIATION_REQUIRED 拒绝；原付款核对成功135元后，券变成 USED。

本人App申请退回原135元首款，Vue独审批准并执行，App核对同一退款。订单净额0，制作金仍 USED，1000可用积分不因这次现金退款恢复成7000。

随后Vue对原700元消费发起权利争议，独审明确全退700元、撤销许可。App申请原款退款，Vue批准执行，App核对成功。原消费订单 REFUNDED、原文件许可 REVOKED；1000剩余积分冲回，已花掉的6000积分进入待冲回，成长值归零，新兑换被 POINTS_REVERSAL_PENDING 拒绝，新文件下载被拒绝，无关账号不能读该钱包。

重复核对两笔原退款不会重复退款、重复增加积分欠额或恢复已用券。按原兑换 operation key 请求，仍返回原成功回执；改变载荷沿用原键返回 IDEMPOTENCY_CONFLICT。历史回执中的 AVAILABLE 是当时快照，当前 GET 仍为 USED，不能把回执当成一张新券。
