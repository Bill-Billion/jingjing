## 问题归因及准确版本

**QA18-ENV-018：隔离环境遗漏现行艺人合同及平台主体。** 原环境实际 `/artists/services` 返回 `ARTIST_PLATFORM_MERCHANT_NOT_CONFIGURED`、`LEGACY_COMPATIBLE` 和空免费服务。`73fac544` 在 BATCH 工厂补入已有 `ARTIST_CONTRACT_POLICY=CONTRACT_20261029` 及现有平台主体，不直接修改实名、同意或认证状态。新建隔离环境保留旧轮资料，没有重置历史证据。新环境16项真实 HTTP 冒烟通过，其中确认免费建模/托管为零价及无需付款。身份服务和长期模型外部提供方仍未启用，不据此宣称真实服务已接通。

`73494db5` 同时修正冒烟脚本里过时的 rc.1 常量：执行写入前读取当前 OpenAPI 版本并与环境声明相等校验，数据库仍严格检查0225/225。旧常量问题来自静态检查，没有虚构一次失败执行。

**QA18-TEST-019：浏览器测试驱动错误。** 首次上传合成证明用了 text/plain 传输类型，服务要求 application/octet-stream、媒体类型通过 query 声明；首次机构能力定位写成“经纪”，当前 Vue 真实名称为“艺人经营”。第二次精选 select 的标签包含 option 文本，改用真实 accessible combobox 名称。保留3次执行、前2次失败，没有弱化断言或改页面来适应脚本。

最终驱动 `2856e2370f383489600f750984fe38c4b4ac3110` 实际退出0。**G06在第2次执行完成，G05在第3次完成；第3次跳过已完成的G06。** 累计10条检查记录、9个不同名称（含重复读取），不是10条验收标准，也不是同版干净环境的一遍全量回归。准确完整 SHA、每次执行与同记录证据见[结构化回执](../../testing/evidence/pm04-g1-display-20261125-06/EXECUTION_SUMMARY.json)。
