# 九步骤对应范围

来源：[PM01施工原文](../../sources/pm01-20261111/03_本轮施工任务与验收.md)。下列引号内逐字取原文，后文为本轮验收说明，不另造需求。

- W14.1 完成通告到商单的双向合作：原文“普通个人发通告、他人投稿、独审、有意向与客服转单”。普通个人五类发布、独审投稿、有意向同案件与指定客服转报价后端已跑；端侧未执行。
- W14.2 完成通告到商单的双向合作：原文“报价到订单、会话开通、四阶段制作与验收”。同报价合同订单、实际回执后会话、四阶段制作和归档既有后端断言已跑；真实成片质量/页面验收未作。
- W14.3 完成通告到商单的双向合作：原文“取消/退款/撤回时分别核消息权限和账目”。撤回保留历史合同/通知、退款会话冻结/归档及佣金冲回既有断言已跑；真实清分未作。
- W15.1 完成共创开拍、交付与退出：原文“同房间本人授权去重、10人开拍与20人权益”。同本人多个数字人去重、9/10/19/20/21人门槛及实际付款、当前权利既有断言已跑；均合成人物。
- W15.2 完成共创开拍、交付与退出：原文“运营页面实际上传、独审、通知和参与者收片”。现代共创同房间制作/参与者获取的既有后端路径已跑；原文运营页面实际上传及所需端独审收片未在本轮执行。
- W15.3 完成共创开拍、交付与退出：原文“未成团、成员退出、撤权及整包退款有明确结果”。未成团延期/退出/撤权/生产暂停与同单独审退款后端已跑；实际资金退款未接。
- W16.1 完成积分换券、用券及退款冲回：原文“消费取得晶钻、固定兑换、锁券与新30/40/30订单付款”。既有用券锁定、新30/40/30净额与消费积分断言已跑；固定兑换完整入口仍需结合已有redemption专项，非本轮11文件全覆盖。
- W16.2 完成积分换券、用券及退款冲回：原文“失败释放原预留，未知结果查原订单”。未付款释放原锁券、重复持券拒绝、未知付款沿原单恢复后端已跑；客户端未知按钮/系统保存未运行。
- W16.3 完成积分换券、用券及退款冲回：原文“退款关联原消费积分、优惠和佣金，不重复恢复”。同优惠订单消费积分、三期退款及已用券不恢复已跑；共创券排除推荐及商单佣金冲回分别复验，不称单一订单覆盖全部优惠佣金组合。

实现核对：指定客服必须有当前权限且独立于交易双方，转交历史核摘要；商单会话在付款待复核/退款中冻结，已退款或清算归档后不能写消息。共创取消不能把退款申请当到账，恢复制作须当前有效本人及新版本确认。优惠券付款接收保留可信回执，来源后来取消不抹除已收款事实；仅未付款锁定可释放，已用权益保持历史。以上是已有实现的复验，并非新增规则。

未因本轮观察到未覆盖就判定未开发；全文所需端、真实服务和独立审阅仍需既有退出条件。
