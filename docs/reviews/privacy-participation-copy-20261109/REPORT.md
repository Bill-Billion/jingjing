## 本轮前后

1. 先前这些资料分别存放于业务模块；现在account-data新增八类：PRIVACY_REQUESTS、PRIVACY_RESPONSES、PRIVACY_EVENTS、PRIVACY_ACTIONS、PRIVACY_EXECUTIONS、NOTIFICATION_DELIVERIES、GUARDIAN_LINKS、ENGAGEMENT_RECORDS。要求本人的QUERY/COPY申请且PROFILE/ALL范围，不带机构身份头。
2. 活动明确限定十类：排名资料、出品人城市偏好、本人订单评价、候选报名、投票、申诉、推荐链接/点击、奖励记录、有效互动。仅本人个人主体；无主体互动再核提交账号和保存账号一致。不包含全局评委/排名底稿或设备哈希，也不宣称成长、佣金、抽奖兑换等全部活动已提供。
3. 监护只提供本人参与的关系状态/有效期/历史；成年人可看自己提交的关系说明，儿童副本不包含这份说明。对方账号、儿童证明、审核人、退款和信息请求详细材料未纳入；有效授权继续在原监护流程核验。旧关系摘要不能恢复已撤销权限。
4. 通知只提供当前仍留存的个人/无主体发送记录及模拟标识；不提供组织通知、来源索引或供应商回执。UNKNOWN/PENDING不能标已收到；实际设备推送工程仍未完成。
5. 修复旧隐私答复文件无法下载：原入口先核本人申请，再查最新版或已审核历史文件快照，核字节摘要/长度/类型和当前存储状态。过期/删除/篡改仍拒绝；私密下载显式no-store。未新增公开文件地址。
