## 本轮需要单列交接的最小事项

已修复并三宽复验的前端缺陷：公开艺人详情曾使用未映射的 `/auditions`，路由还未透传 catalog 的 city query。现有试镜 HTTP 接口一直可用；本轮已按 canonical 路由、城市、真实目录与可见方案验收，旧的“点击已打开”断言作废。

1. **产品与后端：城市标准。** 确定稳定城市编码、别名与显示名称，保留现有字符串数据的迁移/兼容；IP 粗定位是随后接入的单独来源，不应挤进前端自由字符串猜测。
2. **产品与后端：明星/精选来源。** 确定明星名单、授权、可展示期限、城市关联和排序；现有光环认证、业务榜单与活动曝光不能未经确认改名为明星推荐。榜单可复用，但需要 `city/district/category` 及已公布快照，并非自动首页推荐。
3. **内容与后端：封面和缩略资料。** 确定作品封面与艺人主头像的授权来源、公开字段、失效规则；尚无真实素材时前端只能诚实占位。作品时长/播放量没有来源就不显示数值。
4. **前端：异常状态与恢复。** 登录恢复、切城重置、分页、授权失效清图、个人许可、通告类型/开关、试镜价格与状态属于本侧可修，不等待前三项才能上线代码审阅。

不另列“购买、通告或试镜后端全未做”。现有接口与业务状态已经存在；缺的是上面几项新展示数据、约定及对应界面状态覆盖。

### 密集图片的接口与性能限制

艺人预览当前是附件字节下载：`application/octet-stream`，目录不返回图片格式、宽高或字节长度，也没有缩略图尺寸参数。艺人资产本身有 **8 MiB** 上传上限，客户端现有 `maxArtistBytes` 也是 8 MiB，所以不能说完全没有上限；但这个上限不是首页小头像的合适预算，而且客户端是在读到响应后检查。每个目录项最多 6 个预览资产，密集主页还应限制并发、按需读取和及时释放图像缓存；不要为找头像同时下载每人的全部大文件。后端可在后续契约中明确主头像/缩略图、类型/尺寸/字节预算和撤权一致性。联合沙箱的 PNG 很小，不能据它声称正式人像流量和解码性能已经验收。

## 复现与限制

运行前按现有 `scripts/local-mysql.cjs` 恢复隔离 MySQL，设置 `JX_MYSQL_TEST_ENV_FILE` 指向本机忽略上传的测试配置；依次启动 `scripts/{artists,stock,notices,auditions}-sandbox.cjs`，使用它们输出的本次随机目录。

```sh
JX_REVIEW_SOURCE_COMMIT=<已核对的40位提交> node docs/testing/plaza-dense-20261026/api/readonly-http.cjs artists .local/artists-sandbox/<本次随机目录>
node scripts/artists-sandbox-smoke.cjs .local/artists-sandbox/<本次随机目录>
```

其他三个模块替换名称即可；不要使用上一轮已经删除的访问文件。GET 验证不含 POST；已有 smoke 会关闭自己的沙箱。证据只记录状态、字段名、字节长度与错误码，不保存凭据或私有返回正文。

本轮首次验证器尝试在 Node 中调用系统 `git` 记录提交，遇到本机可执行架构错误，已改为显式传入核对过的提交；首次艺人图片断言错误地要求 `image/png`，依据实际响应和路由改为验证 PNG 字节签名。最终结果为修正验证器后的实测，不把这两个验证脚本问题记成业务后端缺陷。

艺人图片是 1 像素合成 PNG，作品/试镜媒体是明确标记的合成字节；这轮只能证明 HTTP 权限、字段和状态，没有证明正式人像、封面质量、视频可播放或真实水印。未调用短信、实名、模型、外部存储、真实支付/退款、生产数据库；没有代另一位同事审阅或批准。

以上一句对应原四模块沙箱。后加的联合沙箱使用本轮程序绘制的 240×320 人形占位 PNG 和既有做法生成的 1 秒色条 MP4，已通过真实 HTTP 核对 PNG/MP4 文件签名；新版 Chrome 中的实际图片展示、MP4 解码和播放时间推进也已记录。没有把合成人形、色条或预置付款状态当成真实艺人、真实在售作品或真实付款。

浏览器原始运行状态保存在 `api/browser-runs/`。前期语义名称、滚轮位置、输入切焦点和 alertdialog 定位修正属于脚本校准；一次完整运行在写入前主动停止以修正输入时序，其随后浏览器关闭错误不算页面业务缺陷。最终覆盖表逐项选取后续通过结果；撤权项保留原失败与补验方法，不将报告改写为“原自动化全绿”。3 次刻意中断的目录 GET 单列为受控传输失败，成功重试走真实 HTTP，不能把中断当作后端真实故障。
