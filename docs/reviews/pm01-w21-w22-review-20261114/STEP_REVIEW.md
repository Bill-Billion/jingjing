# 原六步骤与本轮范围

来源：[PM01原文](../../sources/pm01-20261111/03_本轮施工任务与验收.md)。引号内为原文，其后为指定验证范围，不新增商业规则。

- W21.1 完成隐私申请、注销与实际处理：原文“分类查看与复制、删除/注销核验及独审”。申请范围/本人权限、分类副本、注销前置与独审已跑；50分类登记不证明全部资料或原件交付。
- W21.2 完成隐私申请、注销与实际处理：原文“本人同一申请下载已审核文件；未完成项目如实保留”。同申请选定实际文件独审后下载、内容缺失/变更/撤权拒绝、重开保留历史已跑；其余未交付部分保持未完成。
- W21.3 完成隐私申请、注销与实际处理：原文“检查保留依据、供应商执行结果、恢复和误操作”。原对象删除未知/恢复、供应商结果核验、合成旧备份重放删除登记及误操作门禁已跑；真实供应商/保留依据/真实备份待。
- W22.1 完成参演变更、发行与收入清算：原文“同项目原合同、加价、降价和换角分别保留依据”。同合同加差价/降价退款/独审激活失败回滚/换角分账已跑，冻结旧约定保留。
- W22.2 完成参演变更、发行与收入清算：原文“各参与者确认、发行凭据、收入到账及独立清算”。同版本各方确认/发行凭据/受限素材/应收与实收/独立清算已跑，外部事件与银行凭据合成，清算不等于已出款。
- W22.3 完成参演变更、发行与收入清算：原文“旧演员与新演员订单隔离，固定片酬不自动获得分红”。换角新演员独立订单、旧款约定保留、固定片酬与另立项目收益协议分别核验；未自动分红。
