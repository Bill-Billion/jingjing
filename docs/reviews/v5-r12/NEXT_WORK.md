# 第12轮接下来按什么顺序补齐

这份表是后续工作安排，不把尚未做的工作写成已完成。第12轮仍在进行，没有额外扩成一个新产品。完整30包、133项登记见同目录FULL_SCOPE_REVIEW与ACCEPTANCE_FOLLOWUP。

|顺序|具体工作|本侧负责|队友可以同时做什么|怎样算做完|
|---|---|---|---|---|
|1|平台代做样片|独立商品和受理；绑定艺人本人及形象，平台人工承制；50%/50%付款；艺人所有权、交付和退款；禁止制作金抵扣|按独立“制作我的样片”入口准备表单、预览和订单，不与买现货混用|从本人授权到下单、开工、预览、付尾款、下载可操作；取消、越权、失败恢复分别验证|
|2|停止作者自助供稿，保留历史及运营入库|核对作品创建/提交/报价所有入口；普通作者不能绕过页面直接提交，运营保留可审计录入及权利来源|隐藏旧自助按钮，同时保留历史订单和已购许可查询|普通用户直接调用被拒绝；运营按明确权限代录；历史承诺不被删除|
|3|参演合同后续变更及无演员分红的发行收入|已付约定改价/换角与历史付款如何承接；补项目收入约定入口，明确确认人与版本|先用已提供接口完成普通约定流程，变更入口明确尚未支持|未获同意不覆盖旧合同；既有钱账保留；无演员分红不等于不能登记真实发行收入|
|4|逐条业务验收|同版本测试数据、撤回删除、迁移与恢复、失败和并发场景；为133项逐条补证据|实际网页和手机走流程，记录可复现问题；核对页面范围，不用PR24标题代替证据|每项写明实际操作、预期/实际结果、版本和证据；不通过项保留|
|5|集中审阅与真实条件核对|按独立成果整理代码、接口兼容、权限与财务证据，处理审阅意见|实际审阅和页面兼容验证后再阶段合入|共同版本经双方检查；真实服务有单独证据，未配置保持关闭|

这些后端代码工作不依赖甲方开通OSS。确需补充的业务规则先查已提交文档、已确认决定及队友材料；查不到再问用户，不能凭空补价格、合同权利或分红比例。运营商品仍使用审核后的版本，不把合成测试数据作为正式配置。

前后端通过统一接口文件协作；每批成果集中上传，待实际审阅再合入。队友尚未确认接手时，不代其认领。已付合同变更若出现新的取消费用或收入归属决定，应先明确业务依据再实现。
