# 离线广场补充示例与新版APK交付

用户原文：“广场上需要罗列各种交互单元的艺人列表、通告列表等信息矩阵”。

## 范围与依据

- 历史设计原文：“页面顺序为：品牌和城市 → 频道及紧凑工具 → 明星推荐 → 本地艺人 → 作品精选 → 同城机会 → 写故事与草稿。”来源[设计说明第15行](../../ux/home-plaza-proposal-20261026/dense-v2/README.md)。这是历史设计依据；本轮同时核对正式lib/plaza/plaza_data.dart已有目录实现及lib/notices/notices_models.dart六类通告，不重复把正式广场派为未开发。
- 原18组中的第5组媒体展示、第6组机构档案/精选艺人、第7组城市浏览在离线样例中体现；本次交付位于第16组模拟资料、第17组局部检查和第18组演示包交付子项，不把这些组整体关闭。
- 流程补全：补充虚构人物/机构和祝福方向，目录首次安装/旧包升级只添加一次；其余6人仅资料浏览，林夏沿用已具备的试镜能力。统一预置短片明确不是六部生成成片。官方公告不可投稿/由普通出品人管理；浏览机构不取得成员权限。此为演示实现，不新增甲方规则或正式价格。
