# 原文、实施范围与验证边界

[00号协议第二条](../../sources/contracts-20261029/extracted/00.md:25)原文：“用户须使用真实身份信息注册。浏览可使用基础功能；发布、交易、创建数字人前须完成 L1 实名认证（免费）。”

实施补全：交易的新办理及成功重放核实际账户当前实名；机构资质与办事人身份分开；付款准备与认领发送跨事务，所以发送认领前再次检查。以上员工、幂等与事务细节是实施解释，不冒充原文。沿用现有成年与机构模型，不新增光环收费，不修改合同快照。历史读取、已有未知付款查询到账和退款不当成新交易。

新23项正式测试覆盖当前人工定制合同接受/新办/重放、三状态、准备后发送前过期、恢复同付款、未知查询到账。接受/发送/恢复是HTTP；准备付款反例直接业务仓库。21文件关联覆盖正常定制、试镜、商单、现货、制作、许可、财务、隐私、机构，不代表每个产品所有实名反例都已验证。整组、页面、真机、实际KYC、真实资金与独审均未因这些测试通过。
