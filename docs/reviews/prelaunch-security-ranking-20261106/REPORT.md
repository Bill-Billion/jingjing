## 原文与真正差距

[28号第一节](../../sources/contracts-20261029/extracted/28.md)：“在 App 内查看/导出个人资料、数字人资产、订单与授权记录；可申请机器可读副本。”

此前账户副本还不能提供系统保留的登录会话与换号记录。本轮在同一本人申请入口补两类记录。限定本人、脱敏、分页、剔除凭证和区分资料覆盖范围属于**流程补全**，不是甲方规定必须保留全部登录历史。现有认证清理会删除过期会话，本轮不延长保留期，不补造已删除记录，也不把返回副本当成隐私申请办结。

[10号第四条](../../sources/contracts-20261029/extracted/10.md)：“曝光系数 L1/L2/L3＝1.0/1.3/1.6；艺人榜单权重为成交 30%、好评 25%、复购 20%、活跃 10%、合规 15%，违规降权或下架。”

原代码验证权重合计和系数范围，但没有限定新合同的具体组合；旧测试资料也采用其他系数。本轮补新合同版本校验。没有证据证明正式环境已用错误权重排名，不能把测试资料当作线上事故。
