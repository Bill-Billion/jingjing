## 先理解这次产品到底要让谁做什么

所有人进入同一个App，固定“广场／试镜／通告／消息／我的”。普通买家可以购买和委托制作；有合法供给能力的人可以经营自己的艺人和视频；星探是买家的进阶资格。机构员工可代表机构办事，每笔交易必须明确签约和付款主体；涉及本次出演或制作时，再绑定真人艺人、数字人及造型声音版本。购买现货不强制买家先建数字人。切换展示对象不能偷偷改变老订单的责任人。

MCN批量管理放在独立PC工作区，App保留个人轻操作。运营人员使用独立权限的运营工作区处理审核、故事受理、报价、派单、客服和财务；三端可以共用账号和已有代码，不能共用所有权限。此变化同时涉及页面与后端关系，不是重新设计几个菜单就能解决。

|用户要做的事|从哪里开始，到哪里结束|最容易混淆的边界|
|---|---|---|
|买一段做好的视频|广场视频→查看许可→付款→解锁及下载|不用先创建数字人，不填故事，不等待制作|
|把自己的故事拍成片|选品类→填故事/补件→客服受理→报价合同→分阶段付款→制作反馈→验收下载|提交故事不是付款；复用已有订单与制作系统|
|找真人艺人试镜|试镜目录→总价下单→艺人接拒→见面取样→确认履约→清分|交通包含在总价；试镜不是取得后续出演版权|
|找人合作或投稿|通告/艺人/出品人→单向意向→感兴趣→客服对接→正式订单|感兴趣不直接开自由聊天、不自动确定角色|
|管理艺人及数字人|本人档案或MCN受托名单→授权/造型/声音→上架与经营|机构管理权不等于脸声同意或资产所有权|
|多人一起定制|发起人整包订单→各人加入及授权→真实权利人去重→开工→各人片段|10人还要检查钱、资料和授权；20人权益不是全单免费|
|使用成长与奖励|合格消费→晶钻/成长→固定兑换或抽奖→核销及兑现|储值钱、供给方应收、晶钻、成长和券分别记账|
|撤回授权或处理纠纷|权益/订单入口→受理→限制新使用或冻结→核验→处理及反馈|提交删除申请不能显示供应商已经删除|
