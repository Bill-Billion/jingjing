## 怎样获取，怎样避免相互覆盖

网页阅读入口使用 `core/v5-d1-planning` 分支的本文件。已有本地仓库先检查未提交改动，再 `git fetch origin`；只查看文件不必切换正在工作的分支。需要独立准备时从确认过的起点开自己的工作分支，保留原改动，不能强制重置或清空。

远端共同版本目前仍为 `integration/28662ab`，旧第23份申请仍草稿未合并；规划分支基于该申请的 `25e6d29` 并增加文档，不能把规划分支整体当成旧代码已获批准。本侧第一轮需复用这些旧接口，会从已发布计划开本地实施分支 `core/v5-r01-story-intake`，明确保留待审依赖。后续共同版本变化时先核对再整合，不盲目挑重复提交。

本次先上传方案分支，供队友阅读与接手，不额外制造一份重复包含旧代码的合并申请。旧成果仍由原申请审阅；第一轮代码到约定交付点再集中上传和申请实际审阅。共享接口可以按约定交接小段，但不能每次聊天随手加申请。不自动合并integration、更新main或部署。

双方接口意见和认领回到仓库任务/交接文件记录；材料可访问不等于对方已经读过、同意或验收。本侧不会代前端标完成，也不同时改其正在负责的页面。
