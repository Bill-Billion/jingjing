3. **分别施工。** 本侧实现规则、数据库和服务器，前端实现App与对应运营/MCN页面。前端可先用明确标注的样例，但正式代码不能回退假成功。
4. **同一数据联调。** 本侧准备可重建的合成账户、故事、订单及异常资料；双方用同一版本运行完整流程。本侧主测、记录和修复后端问题；页面问题给出复现并由登记负责人修复，避免同时改同一个文件。
