# 六处独审缺口：复现、修复和影响范围

来源为PM01 W17中奖补救、W19曝光/月冠军/排名异常。将“独立审核”落实到原业务关联方是本批流程补全，不是新增费率或商业政策。后端业务提交ef3c25cd与0a4ac160；最终完整候选证据见[报告](REPORT.md)。

|实际问题|为什么原检查漏掉|修复时追加核对|正向路径及边界|
|---|---|---|---|
|奖品提供方自审补救|补救案件属于中奖人，提供方不是案件本人|原库存的创建人和当前主体成员|提供方仍可办理履约；补救由独立审核员处理，原中奖与扣分保留|
|提供方审核本方排期|排期可由另一运营人员提交，提供方不一定是提交人|原权益对应库存的提供方关联|独审通过后仍由权益本人确认，不改有效期或位置|
|提供方把本方奖品标完成|权益记录属于中奖人，提供方不属于权益本人|原库存提供方关联|提供方可提交实际证据，独立审核员核定完成；不宣称外部曝光已经发生|
|卖方处置买方对自己的评价|评价的所有人和创建人是买方|原订单买卖双方的当前成员关系|独立审核可下架、申诉恢复；原订单、正文、评分保持|
|艺人处置影响自己的互动|互动由浏览人提交，记录没有艺人所有人字段|原排名档案的创建人和当前主体成员|独立人员可排除、恢复，原账号/设备去重事实和权重保持|
|参赛者处置自己的得票|票属于投票人，参赛者不是投票人|原候选人的创建人和当前主体成员|独立人员可暂停及申诉恢复，原票和已花积分批次保持，不重复返分|

新增检查沿用既有运营权限与SELF_REVIEW_FORBIDDEN错误；不增加角色授权，不修改接口字段、数据库迁移或历史已审核事实。当前拥有运营权限也不免除关联方限制；失去资格后的重试仍按当前权限检查，独立审核员的原键重放保持可用。

真实缺陷先复现为应拒绝却成功，再补检查；没有修改测试预期让越权变“通过”。正式源码相关专项37项通过覆盖新增排名/投票，前述相关58项覆盖曝光/补救及相邻业务，组间重叠不可相加。未运行本机App/Web，无前端代码改动；独立维护者尚未实际审阅。
