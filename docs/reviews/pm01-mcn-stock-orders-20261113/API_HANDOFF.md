# 现货订单分派接口接续

沿既有POST `/api/v1/engagement/mcn/assignments`，以及批量`/api/v1/engagement/mcn/batches`中MCN_ASSIGNMENT。现货传order_id/account_id；请求参数未增加。接口0.31.67-rc.1，迁移0221不变，前端暂停、不代认领。

- 仅机构负责人指派，原订单marketplace_finance分成快照须约定本机构；不把当前合作关系套到别的机构旧单。
- 参与人来自不可变购买快照。机构及目标员工逐人须有有效SUBMIT_LISTING委托/员工MANAGE_LISTINGS，人员或主体关闭/暂停、委托或关系失效均拒绝，原键重放也先查权限。
- 收入另需READ_INCOME、全部参与人当前范围及实际指派。data.person_ids是完整人员集合，旧data.person_id单人填值、多人为null。只分派整单，不擅自拆分个人收益。
- 同机构/同订单只有一个当前指派；转派保留审计。老幂等键返回当时回执，不把当时结果写回当前；应用应重新读取当前经营/指派事实。审计失败整体回滚，原键可重试。
- 批量成功、拒绝或不可用逐项返回，重放不重复成功项；重新读取仍查当前授权。关系结束后员工不能读旧账，机构负责人沿既有历史权限保留核账，不改合同/退款/许可。

本轮同单100分内部模拟付款，原规则机构应计16分；退40分KEEP后净60分应计10分，退余60分REVOKE后为0。不是实际打款；各艺人筛选出来的同单总额不能再次相加。所需端、真实资格和渠道、独立审核另验。
