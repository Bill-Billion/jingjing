## 路由接线

| 路由 | 页面类 | 参数与约束 |
| --- | --- | --- |
| `/search` | `DiscoverySearchPage` | 可选 `city` -> `initialCity`。 |
| `/producers/public` | `PublicProducerPage` | 必填 `partyId` 与原名单 `city`，不得用私有显示名作为补充参数。 |
| `/invoices` | `InvoicePage` | 可选 `orderId`；有效 UUID 回 `/trade/record?recordId=...`，否则回 `/orders`。 |
| `/saved` | `SavedHistoryPage` | 不持久化查询、收藏或足迹数据。 |
| `/help` | `HelpFeedbackPage` | FAQ 仅在本页内筛选，无网络搜索或提交。 |

搜索转入 `/artists/catalog?city=...&tag=...`、`/stock/catalog?city=...` 或 `/notices/catalog?city=...`。艺人标签不传给视频/通告接口。艺人页 `initialTag` 与通告页城市参数由主接线统一处理。
