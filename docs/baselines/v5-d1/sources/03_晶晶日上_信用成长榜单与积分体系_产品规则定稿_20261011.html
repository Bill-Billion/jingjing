0总览：三套信用 ＋ 一套积分，各管各的

先把"真不真、干多少、好不好、怎么回馈"四件事彻底分开，避免一个分数字段什么都管。

体系回答什么由什么决定主要作用
主角光环
（认证）		你是不是真的、有没有资质实名 / 职业技能 / 形象声音授权 / 履约信用，审核点亮准入门槛 ＋ 曝光加权
成长等级你接过多少活成长值 GP（有效单量为主，好评复购加成）选角优先级、额度、荣誉
好评评分你活干得好不好出品人打分（真人度、贴合度、完整度）榜单、派单、降权
晶钻积分消费 / 行为怎么回馈与拉新消费返＋任务＋共创（单向获取）剧集商城抽奖 / 兑换 / 评选

一句话：光环管真假、等级管多少、好评管好坏、晶钻管回馈。前三个决定"谁被看见、谁接到活"，晶钻决定"用户怎么玩、怎么留下来、怎么带新人"。

1主角光环：真实信息认证（三级点亮）

类似"金牌讲师 / 闲鱼擦亮"，是信任标识，与等级完全独立。逐级点亮，越高曝光越多、能接的业务越重。

1.3 审核、有效期与处罚

  • 审核：L1 机审（实名 / 活体）秒级～小时级；L2 / L3 机审 ＋ 人工复核，1～2 个工作日；结果站内信 ＋ 短信通知。
  • 有效期：光环有效期 12 个月，到期前 30 天提醒复核；L3 每月滚动复核单量 / 好评 / 违规，不达标降回 L2。
  • 处罚：材料造假、冒用他人形象 / 声音，立即取消光环、下架、冻结结算，永久不得再认证；投诉成立按违规分级处理。

2艺人五级成长：等级 ＝ 成长值 GP

等级只看"累计干了多少 + 干得好不好"，用成长值 GP 量化。不改基础分佣比例（保护已测算财务模型），等级权益集中在流量、选角、额度与荣誉。

2.1 成长值 GP 怎么来

GP = Σ(各业务类型基础分 × 有效单) ＋ 好评加分 ＋ 复购加分 － 违规 / 退款扣分
 · 现成样片 / 数字商品：1 分 / 有效单（走量，薄积分）
 · 线下试镜：3 分 / 单　｜　私人定制 / 商业商单：5 分 / 单
 · 五星好评 +1；带图 / 视频好评 再 +2；同一出品人复购订单 额外 +2
 · 退款 / 投诉成立：扣回该单 GP 并 额外 −5；重大违规：降级或清零

有效单＝过售后期、未退款、未判定违规的真实成交单。同一支付账户 / 设备高频自买、秒退不计分并纳入风控。

3龙虎榜：六榜 ＋ 综合评分公式

榜单是流量分配的核心杠杆。所有榜单按左上角所选城市 / 商圈分区计算，不设全国榜（区域化战略）。

3.1 综合龙虎榜评分（0–100，近 30 天）

Score = 成交×30% ＋ 好评×25% ＋ 复购×20% ＋ 活跃×10% ＋ 合规×15%
最终排名分 = Score × 光环系数（L1 1.00 / L2 1.15 / L3 1.30，L0 不进榜）
各分项先在同 geo 内做归一化（0–100）再加权；合规项基础满分，违规扣分、严重者清榜

3.2 六个子榜：指标、窗口、更新、门槛

榜单排序指标窗口更新防刷门槛
销量榜有效成交 GMV（兼看单量）30 天每日 0 点新号 7 天冷启动，不计入
好评榜贝叶斯修正评分（先验 10 条、均值 4.0）30 天每日≥10 条有效评价才上榜
复购榜复购买家数 ÷ 总买家数30 天每日≥20 个不同买家

好评榜用贝叶斯平均而非裸均分，避免"2 个 5 分就排第一"：修正分 =（10×4.0 ＋ 实际总星）÷（10 ＋ 评价数），样本越多越接近真实分。

3.3 违规降权与上榜激励

降权 / 清榜

投诉成立、虚假交易、黑内容 / 资质违规：首次虚假交易清虚假量 ＋ 降权 30 天；二次封禁。合规分扣完即清榜。

上榜激励

各榜前 10 / 前 50 给广场资源位、专属角标、流量券；销量 / 好评榜首给月度评选门票。

geo 分区

默认定位城市，可下钻商圈、可手动切换；只做"同城 / 周边"，不做全国大市场。

5月冠军评选：情绪价值的兑现仪式

月冠军总分 = 官方评审 60% ＋ 当月龙虎榜综合分 20% ＋ 晶钻投票 20%
  • 官方评审占 60%：看真人度、作品完整度、贴合度与合规，防止纯刷票；
  • 投票防刷：每票 100 晶钻、每账号每日限 10 票、异常票剔除；
  • 奖励：月度称号与证书、下部大剧角色优先 / 保送候选、金光环加速认定、全站流量包、线下活动名额；
  • 分层评选：按城市 / 商圈与品类（古装、特型、情感等）各设月冠军，让新人也有奔头。

8合规红线（开发与运营必须硬约束）

  • 晶钻不是虚拟币、不是金融产品：不可提现、不可转让、不与法币双向兑换、不承诺增值；只做站内消费回馈。
  • 不做层级 / 拉人头返利：分享与共创奖励只到"一级归因 / 一次性任务奖励"，不按下线层数计酬，避开传销红线。
  • 抽奖明示概率与规则、不诱导未成年人；未成年人不得参与抽奖、打赏、投票；遵守《规范促销行为暂行规定》。
  • 角色名额中奖≠保证出演：获得的是参选 / 试镜资格，最终以剧组评估与合同为准，宣传不得承诺"中奖当主角"。
  • 形象 / 声音 / 人脸授权：为他人或未成年人制作必须授权留痕；未授权不得采集、不得入库底板。
  • 榜单与评选反作弊：虚假交易、刷票、刷好评一律剔除量并降权 / 封禁，保留风控日志备查。
