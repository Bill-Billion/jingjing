# Android 单机离线演示

本分支只交付四组演示流程。它是现有 Flutter 工程内的独立入口，复用现有主题、字体和图片，使用本机 SQLite 服务及专用演示页面。五个账号均为虚构。正常入口 `main.dart` 和线上接口继续保留原行为。

## 构建

使用已有 Flutter、JDK17、Android SDK，设置好各自路径后：

```sh
bash scripts/build-android-offline-demo.sh
```

默认生成可直接安装的 debug APK，应用标识 `com.jingjingshangri.jingjingshangri_app.offline`，名称“晶晶日上·离线演示”，可与原 App 共存。安装包最低 Android 7.0（API24）。这是本机演示包，不是正式发行签名包。

脚本只从已有缓存解析依赖，不安装 SDK。`sqflite 2.4.3`、`path_provider 2.1.6` 原已在锁文件中，本次改为直接依赖。Android 构建根据 `JX_OFFLINE_DEMO=true` 切换应用标识和清单，不新增影响普通构建的产品变种。离线入口额外拒绝 Dart 网络请求，离线 Android 清单移除网络权限。

## 演示路线

首次安装即可开飞行模式，右上角切换账号。

1. **普通客户陈悦**：广场“定制祝福视频”填写对象、场景、内容与素材；提交后模拟平台报价，阅读并确认约定，模拟支付30%首款；模拟平台交剧本，客户确认或提出修改；模拟交样片，确认并支付40%；模拟交粗剪，确认并支付30%；模拟交成片，播放并确认收讫。页面及“我的”保留付款记录。
2. **艺人林夏**：编辑形象资料和头像、模卡，保存后本人确认展示授权并模拟审核。试镜由陈悦预约并付款，切林夏接单、选择样照／短视频并提交，模拟审核后切陈悦查看确认。林夏还可进入独立参演项目，报名、模拟筛选、阅读本人约定、确认、模拟出品方付款及拍摄进度。
3. **机构负责人周宁／成员许安**：负责人修改机构资料并邀请许安；切许安接受；切周宁设置查看资料／协助试镜权限，切许安查看结果；负责人可移除成员，权限立即失效。
4. **出品方顾川／艺人林夏**：顾川创建通告草稿、填写角色和材料要求、确认发布条件、提交模拟审核；可退回修改后再发布。切林夏投稿本人资料；切顾川查看投稿并选“感兴趣”或婉拒。感兴趣只创建模拟客服跟进待办，不自动授角或签约。

“消息”只显示当前账号收到的本机通知，点击可继续办理对应记录。“我的”提供重置，取消确认不改变资料。正常退出与重启保留业务进度和当前账号。

## 素材与范围

图片、字体和两个示意短片随包提供，不依赖先联网缓存。短片是抽象演示素材，不是按当前订单实际生成的个性化成片。可从设备导入图片或视频，文件复制到应用私有目录，SQLite 保存引用。参考图片限20MB，视频限80MB。

演示报价 ¥1,000、试镜 ¥200、参演报酬 ¥200 均是虚构样例。约定和投稿保存当时内容；不改变正式业务规则、合同、接口或订单。退款、争议、换角、机构复杂经营、网页运营后台及真实外部服务不在本次四组演示承诺内。
