# 下一轮手机测试怎么进行

本侧已写好本机测试入口，定制制作资料已通过真实接口检查。现在还没有新版APK或公网地址；不要用旧短信包验收本次修复。

|顺序|由谁做|具体内容|
|---|---|---|
|1|本侧|集中交付固定源码版本、确认本轮测试开放范围，准备HTTPS地址和独立安卓测试包|
|2|用户与本侧|安装后选择本轮客户或制作方账号；验证码由本侧从隔离模拟服务读取，仅用于虚构账号，不发真实短信|
|3|用户操作，本侧记录修复|先切换个人和机构，再分别查看六组订单：报价、首款、样片、修改、尾款、交付结算|
|4|用户操作，本侧记录修复|重点检查身份不乱跳、样片可读、成片能保存、断网有提示、恢复可重试、退出不残留私有内容|
|5|本侧|测试结束关闭入口，记录通过/失败和手机型号；另安排商单、MCN合作、选角和发行组|

每次只使用一组资料，不在登录中切换数据库。用户不用配置服务器或终端；我会提供该次角色号码和每步要看的订单。三个资料组的订单不能串用。所有金额、版权、实名、付款和文件均为合成测试，不发生真实短信、付款或OSS费用。测试上传文件上限16MiB，仅使用提供的合成资料。

建议首轮使用Cloudflare临时HTTPS域名，仅转发本机127.0.0.1:3380的“定制制作”隔离资料入口。入口最多75分钟，测试结束可提前关闭；仅本次登记的7个虚构角色可申请模拟登录码。放行固定接口清单中的155对业务请求方法/路径，实际仍受后端身份权限限制。管理、测试控制、验证码读取、数据库、原始文件目录和支付回调均不公开。用户验证码由本侧本机读取，不能从公网获取。APK通过本地交付文件或已授权仓库构建产物提供，本代理不开放文件目录或APK下载。
