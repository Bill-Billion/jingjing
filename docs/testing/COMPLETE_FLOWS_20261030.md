## 可重复准备与检查

以下命令从工作树根目录执行，需已有 `JX_MYSQL_TEST_ENV_FILE` 指向受限本机测试配置、`FFMPEG_PATH` 指向视频工具。文件不含密钥，配置与登录资料留在 `.local`，禁止上传。

```text
node scripts/joint-test-data.cjs check
node scripts/client-testing/explore-seed.cjs
node scripts/client-testing/complete-check.cjs <刚准备的新隔离数据库名>
```

前两种检查入口不同：第一项自动新建并清理8组临时资料；后两项准备可保留的综合资料，并启动仅127.0.0.1可访问的服务器检查后停止。一份综合资料只执行一次连续修改检查，复跑准备新库，不清空旧库。界面检查开始前由后端负责人准备并启动本次环境，不让用户手工处理命令。

新的换号模拟器仅接受13900009801和13900009802，验证码只写本机被忽略的 `phone-codes.json`，不对API回显、不调用短信商。原持续测试资料未标记新场景时仍不开放短信登录；本轮没有续期公网、更新甲方网站或使用真实服务。
