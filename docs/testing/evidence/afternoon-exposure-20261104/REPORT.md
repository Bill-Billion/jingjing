# 晶钻曝光权益：本人选择与中断恢复局部检查

执行人 Bill-Billion；2026-11-04 08:39—08:40 UTC。基线 PR39 `4c6a23c30d32b3f6bd3379d0933057b6ef80f94f`，本地变更接口 `0.31.32-rc.1`、迁移 `0209`；逐文件源码摘要和测试时段见 [脱敏结果](combined-result.json)。本检查使用本机 Android 模拟器、网页、HTTP 服务及隔离 MySQL 的合成成人资料与测试晶钻，不涉及真实儿童、付款、奖品或对外服务。

## 问题及处理

1. 原 App 券包和任何权益详情都先读报价；报价服务暂时失败时，连与报价无关的面试权益也无法读取。组件反例先失败，修后券包与非报价权益不再依赖报价；制作金在报价暂不可用时仍展示权益，并暂停抵扣、允许重新读取。
2. 原曝光权益页面明确停在“无本人公开资料列表”，无法选择绑定；网页通用表单也没有该引用来源。新增仅本人可读取的当前有效公开榜单资料，App 和网页分别选择本人、数字人及该人物对应的公开资料；绑定、排期、兑现仍由既有服务器规则重新核授权。没有修改奖励价格、概率、历史权益或正式开关。
3. App 重新读取本人资料失败时，旧人物／形象选择原先仍可提交。组件反例先失败；现在清除失效选择并要求重新核对。网页换人物、迟到资料和损坏回复的测试拒绝沿用旧选择。
