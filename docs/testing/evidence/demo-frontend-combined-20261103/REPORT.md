## 验证限制与后续

- 两条链都是桌面网页，不是本轮原生检查。已有前端原生证据单列在其报告中，不冒充本轮独立复验。
- 使用注入的合成登录会话，没有测试真实短信登录。身份/供应商回执均模拟，不启用真实收费服务。
- 试镜选定的 7 份材料为可读取的合成 JPEG/MP4，逐份核对实际浏览器 Blob 内容哈希；通用种子中另有占位素材，未选用它们。共创材料是合成授权关系夹具，本轮不证明其影视制作质量。
- 本轮不等待真实 24/48 小时，不证明超时任务实际执行；只验证生成期限和未到清分时限的拒绝。
- 共创只到单人参加/退出，没有在本轮完成 10/20 人门槛、主订单付款、成片与独立片段交付。那些属于其他主线证据，不合并冒充同一个房间全链。
- 本轮没有重复试镜机构员工撤权、跨设备恢复、共创邀请过期及响应丢失专项；报告里的正常成功不能覆盖这些未跑分支。
- 主线随后修复“试镜引用素材的隐私删除保护”，此报告受测正常链不会自动变成该修复的验证。修复后的后端专项与必要回归由主线另记。
