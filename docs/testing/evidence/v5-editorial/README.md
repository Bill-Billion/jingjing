## 实际发现并修正

- 旧铜橙、圆角白卡与暖调装饰图偏离原稿：换为纸底细线、宋体标题与方形黑白动作。
- 只写系统宋体名不能保证Flutter实际显示：标题字体随包交付，App/Web共用同一开源资源，[字体检查](FONT_DELIVERY.json)。
- Vue局部样式覆盖导航/标签：限定新工作区内提高选择器优先级，恢复唯一黑底高亮及直角标签，[菜单检查](WEB_NAV_QA.json)。
- 报价复核390页面被内部表格撑到638px：让网格子项收缩、两列表格适配；375/390/1440均验证内容仍完整，[窄屏检查](WEB_NARROW_QA.json)。
