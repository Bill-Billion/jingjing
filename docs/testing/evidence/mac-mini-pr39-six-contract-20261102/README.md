# 六项合同页面证据索引

本目录全部使用隔离合成资料。正式标准状态不变；`PARTIAL_ACCEPTANCE.json` 是新增合同子项与原标准的局部关联，`VALIDATION.json` 区分实际页面、原生、API、单元及格式检查。

- `web-main.json`：新旧现货、监护关系/恢复/退款、侵权补件全段、延期与无实际执行拒绝结案。
- `web-finish.json`：同单试镜、直推新旧规则、实际关闭合成账号后的网页独立结案。实际关闭执行由鉴权本地 API 完成，不冒称网页/原生执行。
- `handover-web.json` 与 `handover-native.json`：同一机构关系及订单，网页机构确认→Android艺人确认→网页复读；原收入/退款保留。
- `native-infringement.json`：Android APK 四角色通知、冻结/材料送达、反通知、处理提议、自审拦截、独立恢复及本人读结果。
- `native-guardian-partial.json`：原生综合场景的前七步通过，随后侵权测试点击定位失败，因此整个原场景 `completed:false`。该文件保留真实失败，不修改成通过；侵权已单独修正驱动并重跑成功。
- `native-finish.json`：原生读取同一试镜时钟和实际结案结果。最后日历中文说明修改后重新验证此只读路径。
- `backend-mysql.log`：本轮65项合同/商单真实隔离事务检查，包含到期/撤权、双冻结、安全自动确认等未逐个在原生重走的边界。
- `SOURCE_MANIFEST.json`：本轮最终前端、测试脚本及工作流输入的哈希；后端未改，准确基线 cde0518fac17c5e72b17f77d4744c693bc3c6444。早期原生局部截图在最后中文提示/网页回执展示调整前生成，相关变更分别做了原生只读和同单交接复测；最终自动回归/构建对应此源文件清单。

截图只含合成角色与模拟业务，用于仓库审阅；不包含真实儿童、真实交易或会话密钥。没有复制 `access.json`、`defines.json`、数据库连接或原始数据库。临时测试数据库与登录凭据在验证后由各自脚本清理。完整解释见 [报告](../../../reviews/mac-mini-pr39-six-contract-20261102/REPORT.md)。

为便于Git检查，入仓日志只规范行尾空白/终端换行，原始日志仍在本机隔离工作区保留；未删失败、警告或业务结果。
