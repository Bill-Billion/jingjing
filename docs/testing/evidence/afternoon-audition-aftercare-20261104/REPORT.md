# 试镜售后：重复争议、补交依据和独立核对

本记录是原 18 组中的试镜异常和安全局部工作，不代表整条试镜或全部 151 项正式验收通过。接口 `0.31.33-rc.1`，迁移仍为 `0209`。本地隔离模拟采用合成成年身份、模拟付款和虚构文件；没有真实支付、退款、儿童资料或生产调用。共享权限与业务变更仍需另一方实际审阅。

## 发现与处理

- 同一已出发预约已有未结安全争议时，第二次新取消请求在修复前返回 200，并生成第二条争议、替换当前争议。修复后拒绝重复发起，保留原争议、原原因和既有材料；原幂等键的恢复仍返回原结果。
- 原争议可以不附材料，但之后没有沿原记录补交的入口；运营页面也无法选择实际争议材料，且没有限于本争议的客服文件读取。现在本单获准当事人可各自用本人身份补交私有复核依据；运营必须具有独立试镜客服权限，只能读取当前争议关联且属于本单当事人的文件。读取前后复核权限、限制及文件摘要；结案、撤权或资料受限后不能继续读取。
- 网页要求先取得所选实际文件再确认处理，记录或身份改变会清除已读取状态和旧选择；迟到文件响应不能恢复旧状态。原始数字人材料即使曾作为问题线索，裁定依据仍按既有服务器规则使用复核或本人同意材料；本单当事人可另行补交本人的复核依据。
- Android 记录行程时缺少依据会说明需要上传，不伪称已记录。安全离场仍可先提出争议、之后补证；提交申请不等于退款到账。

组合测试基于同事 PR39 提交 `9f3ad878a38aa6ed8be5fcd0d999b5d868a2b3de` 与本批本地改动，时间 2026-11-04T09:37:53.131Z 至 2026-11-04T09:40:18.870Z；实际受测文件的 SHA-256 见机器可读结果。最终提交和远端 CI 按 PR 精确 SHA 另核；本批共享售后规则尚待另一方独立审阅。
