# 未计为通过的脚本尝试

参演首次取取消前快照时，上一动作“模拟筛选通过”尚未落盘：前快照为applied，后快照为offered。变化只有筛选事件、约定、消息和对应版本号，没有本人确认或付款。脚本现先找到可操作的约定按钮再取基线，在同一project-1的offered状态续办，取消与后续完成均通过。

机构首次输入因光标位于末尾全角括号前而残留“）”，脚本校验立即失败，未点击保存，数据库仍为原资料。脚本现分别清除光标两侧并核对空值，从同一未保存表单续办，准确输入后保存并完成邀请接受。

本目录保留失败结果和日志；它们不纳入13个最终通过场景。原始SQLite快照只保留在本机证据目录，没有加入Git或上传Library。
