- 固定兑换：审核后库存和价格，扣分与发券在同一个数据库事务完成，余额不足、库存不足和重复提交有明确结果。
- 收银：制作金只限平台人工定制/做剧；保留原报价，分期按抵扣后金额计算，实际到账后核销；付款未知不释放，退款不返已用券。
- 免单：按用户确认设置权益全额抵扣订单，现金实付0，开工核销；开工前取消释放，开工后走已公布售后。已经验证从剧本、样片、成片确认到下载。
- 共创：原额度仅关联一次，服务、金额、有效期和提供方一致才能使用；原活动取消/退款后不能继续消费；不与同单推荐佣金叠加。
- 面试/曝光：本人真人及形象、授权和光环复查，运营排期独立审核，再由本人确认；实际兑现附证据，失败按既定规则处理。
- 抽奖：单抽300、十连2700，安全随机、前九次未中指定奖才启用第十次保底；规则与成本由不同人员审核，公布实际概率，库存不够整批不扣分；记录未知可原请求重试查询。
- 稳定性：公开概率用固定精度十进制文字保存，避免数据库小数精度引发规则校验错误；综合测试并发固定4份，避免随机器核数一次启动过多临时数据库。
