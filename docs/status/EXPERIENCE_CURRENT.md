# 队友页面接线：样片、合同变更和项目收入

本侧本批补齐后端与接口，队友负责App/网页入口、表单、提示、构建和实际操作验收。新接口版本0.26.0-rc.1，完整分支 `core/v5-backend-completion`，当前仍在本地自验；实际上传情况见 [Core当前进度](CORE_CURRENT.md)。未代队友认领或宣称其已完成。

详细操作顺序、两方职责、兼容变化与检查命令见 [本批交接](../collaboration/V5_COMPLETION_HANDOFF.md)。优先接“制作我的样片”和艺人本人确认，再接合同改价/换角与独立项目收入。旧自助供稿按钮关闭但历史查询保留。上传后双方锁定同一版本逐项测试，再实际审阅与阶段合入。

个人信息请求及素材检查还在本侧继续开发，不能把这些页面先标已可用。真实服务和正式资料单独验收。
