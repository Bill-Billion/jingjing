# 现货售后：逐案核定退款金额与许可

来源：PM01 W11施工原文“同一订单走取消、部分/全部退款、会话到期和失权”，见[任务原文](../sources/pm01-20261111/03_本轮施工任务与验收.md)。

2026-11-11本轮用户明确选择：“由独立审核员在每个售后案件中明确退款金额及是否撤销许可”。此决定补充原文未明确的退款后许可处理，不冒充20261029合同条款。

实施：原case-resolution仍使用REFUND；新增成对字段refund_minor（本案金额，分）与license_action（KEEP/REVOKE）。独审不得自审，金额不得超剩余已收款；审批记录及累计应退保存在售后，不改合同快照。到账前暂停使用；实际退款后按决定保留/撤销。保留不得恢复已撤销许可，不绕过权属、实名、本人授权及内容限制。未决退款不得重开或重复申请；实际退款等于本案批准剩余额度；后续案件再决定剩余退款，不能追认超过原收款。

兼容：旧客户端两项均省略，仍是原整单退款并撤销许可；不默认KEEP。新网页要求独审员显式填写金额与许可；App显示本案金额及许可决定，已核实部分/全额退款不再单独等同于失权。原许可范围、期限及历史合同保持。

接口0.31.57-rc.1，迁移0211。真实渠道未启用，具体实现、四种组合/连续退款验证和限制见[报告](../reviews/pm01-w10-w15-recovery-20261111/REPORT.md)。
