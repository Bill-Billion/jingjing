# 作者与作品资料：本批页面方案

沿用暖白 App（赤陶色主操作）及浅色网页（深绿主操作），采用已批准图册APP-36、WEB-05、WEB-07、WEB-08的最终修订。原图和逐字段依据来自图册提交acd5f99，筛选后的页面、字段、操作和状态保存在[页面依据](page-plan.json)。

|业务|App|网页|必须遵守|
|---|---|---|---|
|供给申请|当前个人/机构、名称、说明、权利证明、申请与补正|申请表、本人历史、独立审核队列和详情|通过供给资格以后才可投稿；补正生成新修订|
|作品资料|本人版本列表、原作表单、版本详情、新修订|作品列表、当前版本详情、投稿和补正表单|正文和权利材料分开，作者、权利人、代理分别填写与举证|
|作品处理|保存草稿、提交审核、填写理由撤回|同上，另有独立权属与内容审核|双审完成只代表两项审核，不表示上架、售出、许可或发行|
|私有材料|选择真实文件、上传状态、获准下载|同上，审核员按权限读取相关材料|单文件不超过8 MiB；只有服务器确认可用才可引用；不提供公开材料地址|

资料列表只使用服务器返回的记录与翻页游标，不加全库总数、实时搜索、价格、封面、评分或人物头像。长编号缩略显示且可查看完整值。申请/作品详情从已读取的记录进入，不让用户改写版本关系。

本人供给资料只允许当前有效负责人身份查看/修改；运营审核使用当前账号的实际授权，不是可自选的角色。身份或会话变化时清空私有内容，迟到请求不能重新展示。未配置存储、无权限、请求结果待核对和版本过期均显示真实原因。

同次写请求的重试保留完整原内容、原操作编号与原版本；内容改变是新的用户意图。版本过期必须重新查看与确认，不能自动提交旧审核决定。成功后重新读取当前记录，避免重放结果显示过时状态。

本批从已合入第12份的共同版本e58c7fc开工，明确合并第13份后端318f263以联调，未改后端源码或公共接口。项目改稿需要真实项目许可核验，当前页面暂不开放。数字人/本人脸声同意、许可商品与选本分别由后续页面批次承接。
