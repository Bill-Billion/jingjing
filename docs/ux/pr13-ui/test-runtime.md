## 私有控制面

控制请求必须带 `Authorization: Bearer <本次 controlToken>`，并且**不能有 Origin 请求头**；控制面仅监听127.0.0.1，不提供 CORS。控制密钥仅由本地测试工具从0600状态文件读取，不交给前端页面，也不在示例命令、日志或报告中展开。

|请求|效果|
|---|---|
|`GET /code?phone=<上述号码>`|取刚通过真实短信挑战产生的合成验证码；未发送时404|
|`POST /storage?enabled=false`|关闭本次内存文件传输；私有下载等真实 API 返回503，而不是模拟前端错误|
|`POST /storage?enabled=true`|恢复本次文件传输|
|`POST /reviewer-permission?action=SUPPLY_REVIEW_PROFILE&enabled=false`|经治理服务撤销本次独立审核员的该项既有授权|
|同路径 `enabled=true`|经治理服务恢复该项原有授权|

`action` 仅接受 `SUPPLY_REVIEW_PROFILE`、`SUPPLY_REVIEW_RIGHTS`、`SUPPLY_REVIEW_CONTENT`，仅作用于这个固定测试审核员，不接受任意账号或权限。验证作品审核队列失权时需同时撤销 RIGHTS 和 CONTENT，因为任一有效通道仍可查看已提交作品。验收结束恢复原权限与存储状态。

建议用现有文件下载验证503，避免无关上传副作用。存储关闭时尝试上传可能留下真实 FAILED 上传记录；相同请求重试按后端返回409 `UPLOAD_RECONCILIATION_REQUIRED`，不得让前端换键盲目上传或假造 READY。
