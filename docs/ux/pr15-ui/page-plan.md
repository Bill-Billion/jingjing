## 真实接口与处理原则

普通记录使用当前活跃OWNER身份；独立审核不传办事主体。后台列表需TRADE_REVIEW，退款读取、审核和执行另需TRADE_REFUND；入口不自行授予权限。两端清理身份变化、401/403/404后的私有内容，忽略迟到回复。

订单合同直接读取订单内嵌`data.contract`，不借用独立治理合同查询。报价确认原样提交`content_sha256`，本地金额只用于展示与填写校验，不改服务器原报价。所有金额为整数人民币分，显示为准确元金额；规格交付项、报价行和历史原明细限制30项，匹配实际服务器上限。

未明确的商业价格、时长、修改次数、责任模式、买卖方、分期条件不代填。没有公开商品市场或主体搜索接口，不从后台权限偷取目录或补昵称、创建时间、统计数字。渠道可用性接口目前未实现，不据此展示已开通。

写入后的503、断流或网络异常都保留原请求编号、内容、版本和已知结果记录；先核对，重复提交仍用原编号。幂等重放可能返回记录当前状态。412重新读取并要求用户重新确认；结果未知时不得普通换页丢弃依据。付款、退款核对以服务器结果为准，不调用支付平台通知接口或伪造成功。

许可的原签署/身份/权属核验保持独立；付款达到原许可约定门槛后才可发放，核实退款后后续使用受限。对应许可页面增加订单关联或明确办理提示，不把完成付款当作许可已生效。

真实SDK调起、正式支付配置、Apple商品及商户资质仍待外部条件验证；本轮浏览器处理记录、核对结果和未开放说明，不安装新的原生插件，不恢复真机测试。制作进度、样片、交付验收及其付款节点属于第16份，不能由页面自报完成。商单、分账、结算和全量旧库迁移随后续阶段办理。
