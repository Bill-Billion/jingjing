## 当前导航规则

App顶层为广场、试镜、通告、消息、我的，对应规范地址如下。五栏共用一个主壳，切换栏目更新地址并保留各自滚动位置；表单和详情走返回式子页。切换账号、身份或退出时清除旧私密状态，隐藏栏目重新进入后按当前会话读取。

|入口|规范地址|本轮可办范围|
|---|---|---|
|广场|`/square`|找到“把我的故事拍成片”和“我的故事与草稿”；公开艺人、现货及试镜范围如实说明|
|试镜|`/audition`|说明预约尚未接入；可查看已有订单或写制作意向，不借用公开项目目录冒充试镜|
|通告|`/notices`|六类通告仍待接入；保留公开项目 `/projects/catalogue`、商业委托 `/gigs` 子页|
|消息|`/messages`|从汇总页进入已有系统业务通知与订单项目留言；消息主页不自动读取隐藏私密列表|
|我的|`/my`|按业务分组进入故事草稿、账号、合同、原订单及制作等现有子页，未开放事项明确说明|

`/customization` 为故事与草稿列表；`/customization/new` 选择已发布品类并新建；`/customization/<UUID>` 查看、继续草稿或查看正式提交状态。普通买家不必先创建数字人或取得星探资格。字段来自绑定模板；草稿可缺项，清空值不回填。提交后的“平台待查看／受理中”不表示付款、内容审核、授权通过或制作开工。

`/operations/notifications` 是系统业务通知子页；`/messages` 是消息主栏。已有 `/projects/catalogue`、`/gigs`、`/licensing/*`、`/trade/*`、`/production/*`、`/finance/*`、账号与合同子页继续按原权限使用。作者自助新投稿本期后置，原合同、历史订单及许可不能因主导航迁移丢失。

网页全部工作区共用 `WorkspaceNav.vue` 的41项入口；本轮新增“故事收件与受理” `/operations/customization`。列表和 `/operations/customization/<UUID>` 详情只高亮这一入口。详情显示不可变提交时的问题和答案；开始受理后显示人员和时间。菜单存在不代表拥有岗位权限，运营请求不携带主体头，失权或不可见记录按真实403/404清除旧内容。
