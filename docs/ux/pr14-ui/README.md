## 页面与审查路径

|办理事项|App入口|网页入口|审查要点|
|---|---|---|---|
|选剧本|入戏 → 已上架的剧本 → 详情|`/licensing/catalog`|人工核验的短试读；明确总价、应付金额、权利、用途、范围、期限及额度；短试读不冒充全文|
|办理许可|我的 → 订单与许可；或入戏 → 我的预留与许可|`/licensing/reservations`、`/licensing/evidence`、`/licensing/grants`|预留保存当时合同；真实上传签约和付款材料；材料提交、核验和取得许可是不同状态|
|供给商品|App查看商品详情|`/licensing/products`|原作须双审；商品价格、权利等主动填写；新价格版本不改旧合同；下架填写理由|
|独立核验|在网页进行|`/licensing/reviews/products`、`/licensing/reviews/evidence`、`/licensing/reviews/activation`|审核账号真实权限；人工核对身份、双方签署、合同哈希和收款事实；核验通过后另行发放|
|项目绑定|我的 → 我的项目；许可详情 → 绑定项目|`/licensing/projects`、`/licensing/bindings`|用途、地域、语言、集数与许可一致；绑定实际分配额度；新绑定单独读取，不按许可版本推算|
|受控阅读|入戏 → 我的阅稿授权 → 获准授权 → 阅读|`/licensing/readings`、`/licensing/reviews/readings`|指定账号、办事身份和截止日期；真实服务端水印纯文本；到期、撤销、失焦或身份变化清空正文|

本批不设置商业默认价格或权利组合，不把阅读许可当制作许可，不把保存历史合同当当前外部签署完成。人工材料核验保留 `EXTERNAL_MANUAL_REVIEW`，付款通道状态为 `NOT_REPORTED`。预留超时后发放接口即使返回成功，也可能只是进入人工补救，页面依实际返回显示。
