# 选本、许可和项目使用：本批页面方案

2026-09-30，用户授权完整开发第14份前端。本批从已合并第13份的共同版本`integration/90cb6a9`开始，明确合并第14份后端`ce576af`，分支`ux/pr14-pages`。第15–17份分支和后端源码不改写。

继续采用图册`acd5f99`的暖白App、赤陶主操作与浅色深绿网页。图册只决定布局和交互；实际字段、权限和可用操作以候选接口及返回事实为准。[图册字段和布局](page-plan.json) · [本阶段接口](../../collaboration/STAGE_5_API.md)。

|用户要办什么|App页面|网页页面|接口依据|
|---|---|---|---|
|选剧本|入戏目录、剧本详情、短试读|已上架商品目录和详情|PRODUCT catalog列表及详情；只展示人工核验的preview_text|
|管理许可商品|买方查看明确价格与权利条件|商品创建、新价格版本、审核和下架|products、records/reviews与closures；须双审原作和有效规则|
|办理许可|预留、历史合同、材料提交和进度|双方预留和证据、独立核验、许可发放|reservations、evidence、reviews、activation；保存当时条款价格与截止时刻|
|查看许可|我的许可、合同、用途和期限|许可凭证、暂停与项目额度|GRANT及suspensions；当前状态不能覆盖有效期|
|绑定项目|创建用途记录、选择许可并绑定|项目与绑定记录、用途和额度核对|projects及grants/bindings；无解绑或循环释放额度|
|按权限阅稿|我的阅读许可、带水印全文|作者指定读者和依据、独立批准、阅读和撤销|readings、reviews、closures与content；只展示服务端返回纯文本|

正文与短试读分开。阅读授权不授予制作、AI处理、训练或发行；独家不自动包含发行权。完整制作订单、支付通道、数字人同意、角色协作与发行留在各自后续页面批次。项目改稿提交入口在本批有真实绑定后接入，仍沿用供给材料和双审。

商品的价格、取得许可前应付金额、预留时长、各项权利、用途、地域、语言、开发期限、使用期限、项目与集数额度由用户明确填写，不设商业默认值。货币显示和整数最小币种单位严格对应。审核员逐项核对双方签署、身份、合同哈希、收款方、币种、金额与凭证；核验勾选不默认通过。

业务身份和平台审核身份分开；客户端菜单不授予权限。选择文件走真实私有上传，不把文件名当材料编号，不返回公共原文链接。网页继续共用主菜单，App保持五个顶层入口，表单和详情使用返回导航。

所有写入保留原请求编号、内容与对象版本；未知结果只允许原请求重试，版本过旧必须重新读取和确认。退出、身份切换及失权清空私有记录和迟到响应；受控正文不持久化、不执行HTML，到期或撤销后不能继续当作获准阅读。

验收覆盖目录、商品、预留、证据、独立核验、许可发放、用途和额度绑定、真实带水印阅读、过期和撤销、异常恢复；逐页对照图册，在网页桌面与手机宽度、Flutter Web检查所有入口和返回路径。生产服务、真机包和正式权利材料单独记录。
