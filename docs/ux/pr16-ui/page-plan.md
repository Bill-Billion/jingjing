# 制作、审片与交付固定页面方案

采用原图册 `acd5f99` 最终图片；App暖白铜色、网页浅色深绿，复用已验收主菜单、标题、卡片和表单。具体逐页结构、字段与原图校验值保存在 [page-plan.json](page-plan.json)。图册示例人名、价格、视频及验收状态不作为真实数据。

|用途|图册|实现重点|
|---|---|---|
|订单与制作入口|APP-14-01-v2|从原订单进入真实制作项目与约定付款节点|
|剧本确认|APP-15-01|具体已审版本、完整受控文本、原意见、确认说明|
|样片/粗剪/成片审阅|APP-15-02-v2|读取私有预览、阶段与版本、逐项核对、原订单规格|
|逐版反馈|APP-15-03|当前已审版本接受或要求修改；历史保留且不放行新版|
|交付作品与私人作品|APP-18-01/02|真实参与项目、最新版本和最终下载，未付清或未验收明确拒绝|
|制作项目列表/新建/负责人|WEB-16-01-v2/02/03-v2|原订单制作行、已审脚本、实际制作方成员、同意与私有证据|
|项目和私有素材|WEB-17-01-v2|原规格与合同快照、私有上传、按类型分页的版本/反馈/文件|
|独立开工核验|WEB-17-02|实际读取证据核对合同指纹、身份、外部签署和权属，不自审|
|生成状态与原任务|WEB-17-03-v2|默认未启用；已有任务真实状态、独立人员恢复原请求|
|逐阶段版本提交|WEB-18-01|当前负责人成交原文件，最终预览与原片必须不同；不覆盖旧稿|
|独立版本审片|WEB-18-02|实际读取文本/视频，审核与客户验收分别记录|
|客户阶段验收|WEB-18-03-v2|版本、规格/声音/标识核对、接受/修改、最终受控读取|

普通办理依据OWNER或实际被指派制作成员，独立操作依据PRODUCTION_REVIEW；页面显示入口不授予权限。未知记录/越权仍依接口拒绝，私有内容不能转成公开链接。身份变化、401/403清理已读内容，异步迟到结果不得串号。

所有写入保留原请求编号、完整内容及对象版本；结果未知先读取原记录/列表核对，同编号恢复，不新建收费请求。412重读并要求重新确认。上传按原application/octet-stream接口，50MiB仅技术上限；文件名不代表质量或标识通过。生成服务默认NOT_ENABLED，测试视频明确为合成媒体，不能冒充供应商成片。

开工审核通过与首款入账分开；SCRIPT→SAMPLE→ROUGH_CUT→FINAL的客户确认由服务器放行。新版本影响后续确认，原反馈继续保留。修改次数依据原订单规格；超限不自动加价。最终版本独立审核、客户验收、尾款成功、最终下载分别展示。

本轮仅本机浏览器与隔离MySQL/HTTP测试，不恢复原生安装或真机测试。制作与商单按独立阶段提交；依赖未合入PR15明确保留，原PR16业务源码不修改。
