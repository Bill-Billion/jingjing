## 具体路径与判断

|审查内容|路径|如何判断|
|---|---|---|
|原订单进入制作|订单详情→制作项目；网页 `/production/orders/{orderId}/new`|只选择原PRODUCTION明细，数量、规格与报价保留|
|剧本/样片意见|App `/production/version?versionId=`；网页 `/production/versions/{id}`|先真实读取该版，再确认；历史版不能继续验收|
|项目/版本历史|App `/production/project?projectId=`；网页 `/production/projects/{id}`|每次新稿与原意见独立显示，旧确认失效|
|私有交付|App `/production/works`→`/production/work?projectId=`|当前FINAL已验收且付清才可下载；退款/撤回后接口继续拒绝|
|开工、上传与审片|网页项目→负责人/文件/交付版本；制作独立核验→开工/版本|真实成员上传；审核人与当事人分开；人工核验不冒充自动签署|
|生成状态|网页项目→生成服务；独立核验→实际任务恢复|默认未启用不排假任务；恢复只核对原请求|

提交结果不明时留在本页，核对后使用原编号恢复；版本冲突后重新读取、重新勾选检查。有效菜单、正常登录返回和窄屏已检查。第17份在独立 `ux/pr17-pages` 继续，不在本分支混入其未审后端。
