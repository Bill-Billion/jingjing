## 五类外观核对

|项目|结论与本批适配|
|---|---|
|字体与层次|网页使用系统中文无衬线字族；App 使用 Flutter 系统字体。标题、正文、辅助说明和编号层次清楚，长编号/校验值换行。图册为生成图片，未把图片字形当成可复用字体。当前账号页信息密度高于图册单独核验页，因保留机构、邀请和能力操作，属本批功能整合|
|排版与间距|暖白底、白卡片、16像素页面边距和卡片间隔、12像素卡片圆角。桌面220像素侧栏，正文按合同信息、承诺、规则、服务分区。手机使用纵向滚动，固定返回栏；长内容没有挤压操作区|
|颜色与状态|App 赤陶色主操作 `#B45D3D`；网页深绿 `#335D46`；底色、边框和辅助文字已落到共享主题。未签署提示为浅暖色，错误使用危险色与文字说明，非只靠颜色区分|
|图片与图标|本批是文字和表单，不依赖业务照片；未伪造头像、签署证明或商品图。图册合同纸张插图未纳入第一批信息阅读页，采用标准 Material / Element Plus 操作图标，不用 CSS/SVG 临摹插图。插图和后续业务页面随对应阶段再采用|
|文案与内容|保留“合同内容已保存，尚未签署”，分别显示封存/签署事实。没有 PR号、接口路径或研发指令进入新合同 UI。手动合同编号、完整参与方编号、结构化原文用于当前真实接口；未伪造买卖方名称、价格或付款按钮|

全景比较之外，实测时近看并滚动检查了长编号、正文段落与数组、`0/false/null`、HTML 原文字串、规则展开、服务状态和权限错误；这些细节由真实页面呈现，无把截图当交互的替代实现。
