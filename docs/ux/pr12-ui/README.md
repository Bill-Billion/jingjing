# 第一批页面：合同、历史规则与统一界面基础

这批让用户按当前身份读取获准查看的合同、原始承诺和当时的规则，并查看支付、实名、电子签、数字人服务是否具备所需条件。合同封存与签署分别显示。本批已完成本地功能与外观验收，按用户要求通过[第12份申请](https://github.com/Bill-Billion/jingjing/pull/12)一并交付，已于2026-09-29合入integration/e58c7fc，8项远端检查通过，未部署；原始交付及检查结果见申请和任务记录。

## 功能边界

- 使用 PR12 三个真实 GET。当前共同版本已包含这些路由；接口未部署或不可用时显示真实失败。
- 入口为指定合同编号。当前没有全局合同列表、搜索、合同编辑、审批、下载或签署接口。
- 规则必须来自该合同的历史副本，不读取今天的规则替代。开放结构正文按文本呈现，保留数组、0、false、null 和原键名。
- 当前身份、会话或读取目标改变后，清空旧内容；失去权限时不保留原文，不缓存到本地存储。
- 服务条件检查不执行付款、实名、签署或生成，也不代表这些业务成功。正式供应商仍未验收。
