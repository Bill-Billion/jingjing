# 业务通知、对象留言、审计与报表页面方案

2026-10-03。本地原PR20后端57ca281，新增图册8张；App仅业务通知列表和详情，复用订单/制作/项目对象留言入口。网页提供通知、真实对象留言、只读权限审计和报表申请/队列/详情/CSV下载。继续固定acd5f99最终原图，App暖白铜色、网页浅色深绿；五tab与统一工作区菜单保持稳定。

通知使用当前账号和办事身份，刷新/继续读取按实际接口，无臆造全局未读数和全部已读。打开业务对象先重新读取当前权限；不再使用临时“项目通知与留言尚未开放”大卡。留言只在TRADE.ORDER、PRODUCTION.PROJECT/VERSION、PROJECTS.PROJECT范围内办理，普通文本最多4000字；回复须同一可见对象，作者可以撤回，独立运营可有理由隐藏且不能隐藏自己。已隐藏/撤回内容为null，不从缓存显示旧正文。

网页审计需OPERATIONS_AUDIT并受来源对象权限过滤，没有授予权限或编辑审计按钮。报表需实际OPERATIONS_REPORT或来源OWNER，申请成功只表示入队；worker关闭时明确等待，不冒充READY。失败可按原编号重试，完成报告是不可变快照；权限变化拒绝整份JSON和CSV，清理私有内容、Blob、待请求，忽略旧身份迟到结果。

报表明确CASH/SETTLEMENT/WORKLOAD、SANDBOX/PRODUCTION、UTC左闭右开时间区间，最多366天、2000行。现金流不等于利润，结算不是重复汇总收入，工作量状态以生成时为准。CSV带BOM/CRLF、环境期间与单位元数据，公式文本安全且不缓存。JSON content_sha256是数据快照指纹，不能冒称CSV字节hash。
