# 本批页面方案

按page-plan.json所列21张最终原图开发。App负责培育主入口、发布需求、接单约定、本人确认、直接MCN合作与三榜；网页负责需求/接单独立审核、规则、邀请与关系、佣金核算和榜单规则快照。使用原STAGE_8_API的18项接口；报价通过真实commercial_offer_id进入原订单，不设默认价格或佣金。

公开艺人目录、关注收藏和全平台通知暂无接口，保留统一样式并说明当前状态；可用的商单通知真实读取。榜单只认正式渠道的已核验交易与明确公开同意，测试数据不足时如实展示。佣金核算与退款冲回有历史记录，提现、出款、税款和发票未接入，不显示模拟到账。MCN能力须授权审核，本人不能在页面自批。

沿用各业务共有请求恢复和版本冲突机制；身份改变销毁私有证据，所有菜单、直达、返回、390/320宽均实际核对。商业首页静态装饰图可由imagegen生成，但不冒充真人或业务作品。
