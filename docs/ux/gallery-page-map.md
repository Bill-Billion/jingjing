## 怎样判定符合

当前页面先核对V5对应行的设计来源、信息主次、卡片排列、字段分组、标签和动作位置，再核对[共用视觉参数](gallery-visual-system.json)。旧图册用于未冲突组件。长合同、真实编号和更多权利字段可以使页面更长，但不能把它们都提升到主视觉或随意更换卡片／按钮风格。

实际检查包括页面结构和共用组件、App手机视口、网页桌面及窄屏、长标题和编号、表单及返回／菜单行为。当前R01实际结果见本轮交付；第14份交付和[第15份图册验收](pr15-ui/design-qa.md)保留为历史证据，不能充作本轮重测。未实点的业务或状态不计为运行通过，未接入页面随后续轮逐项登记并验收。
