## 怎样判定符合

每页先核对上表对应图片中的主次信息、卡片排列、字段分组、标签对齐和动作位置，再核对[共用视觉参数](gallery-visual-system.json)。长合同、真实编号和更多权利字段可以使页面更长，但不能把它们都提升到主视觉或随意换一种卡片/按钮风格。

实际检查包括源代码中的页面结构和共用组件、App手机视口、网页桌面及窄屏渲染、长标题和编号、表单及返回/菜单行为。真实截图与覆盖范围见第14份交付及[第15份图册验收](pr15-ui/design-qa.md)；未实点的业务或状态不计为运行通过。当前API之外的页面随后续阶段开发，每次仍按本表方法登记原图映射并验收。
