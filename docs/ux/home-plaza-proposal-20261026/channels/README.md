# 广场三个频道审阅图

2026-10-26。使用内置 image_gen，每个频道独立生成一张双屏设计板：左侧首屏、右侧下滑区。延续已选“轻导航＋刊物式内容推荐”，保留纸灰、墨黑、朱红、大宋体标题、直角影像和细线。底栏仍为广场／试镜／通告／消息／我的。

三张图均实际查看。已核对：品牌文字、当前频道红线、五个底栏标签、主要栏目、短入口、中文可读性、无明显遮挡或截字。分别采用肖像、横幅影片、城市和通告列表，未仅复制同一版面换标题。没有虚构播放量、匹配率、认证、价格、档期或交易成功；图外标有概念示意。生成图未经过 Python、SVG 或其他工具修图。

这组是供用户审阅的栅格概念图，不能替代可编辑 Figma 图层、精确字号和实际业务验收。人物、作品、活动名称及影像均为示意。可约试镜只是筛选入口，不表示图中人物具有真实可约档期；影片仅显示预览入口，完整内容仍走原购买与许可流程。通告继续进入原详情与投稿，不新增陌生人私聊。

实施时需复用统一组件，校准各图之间的字体和图标尺寸；精选来源、作品海报字段及未登录可见范围仍沿用主页方案的待确认事项。本组没有操作 Figma、App、后端或 PR，Figma 更新由主任务单独核实。
