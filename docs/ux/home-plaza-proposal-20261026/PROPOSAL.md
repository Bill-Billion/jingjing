# 广场主页：轻导航与刊物式内容推荐

2026-10-26，初版设计讨论稿。依据甲方新反馈、用户标注截图，以及最早“先锋电影刊物”原稿和当前前端。初次交付为分析与生成设计图，当时应用代码、Figma 和 PR36 均未变更。

后续已按用户选择更新原 Figma 精选主页，并补齐艺人、视频、同城三组双屏审阅图。实际远端节点、版本与验收证据见 [Figma 更新记录](FIGMA_UPDATE.md)，全部图片见 [审阅入口](index.html)。本轮仍未修改应用业务代码和 PR。

## 对甲方反馈的理解

“简单的跳转按钮类可以收成简单的图标，广场上还是搞一些花里胡哨的推荐模块”包含两个方向：让找功能更省空间，让可浏览的内容更早出现。用户截图中的 QQ 音乐展示了这两个层级：上方紧凑的导航和搜索，下方由封面、标题和分类构成的内容栏目。这里借鉴其信息层级，视觉继续采用当前项目的先锋电影刊物风格。

截图左侧主要是广场下方的入口目录。当前广场顶部还有约 430 逻辑像素高的故事主视觉、名录小图和常驻的黑色故事续办条。只缩短下方入口，仍无法让用户在首屏看到足够的艺人和作品。需要同时调整首屏空间分配。

## 推荐方案

| 区域 | 建议 | 用户收益 |
| --- | --- | --- |
| 品牌与全局入口 | 保留晶晶日上、城市选择、身份切换；搜索使用常驻图标。身份图标仍进入原账号/身份入口。 | 搜索与身份不淹没在长目录中。 |
| 内容频道 | 精选、艺人、视频、同城；保留既有艺人/视频维度。频道切换浏览内容，快捷入口打开完整功能或目录。 | 先看内容，再有目的地深入。 |
| 快捷入口 | 一排五项：找艺人、看作品、艺人榜、找机构、全部。图标配短标签，触达区至少 44×44；不把自定义业务都改成无文字图标。试镜和通告沿用底栏。 | 减少纵向占位，同时保持可识别性。 |
| 首屏推荐 | 一张精选影像，主视觉目标高度约 230–260 逻辑像素；保留不对称构图和错位宋体标题。紧接两张艺人肖像，让首屏有具体可点内容。 | 从功能说明页转为可逛的广场。 |
| 发现艺人 | 照片、姓名、城市及少量真实标签；点击打开原艺人详情。 | 通过形象与擅长方向判断是否值得进一步了解。 |
| 现成作品 | 横幅预览图、作品名、类型及查看预览；点击进入原作品详情或获准的预览。 | 内容丰富而不过度挤压手机宽度。 |
| 同城机会 | 两三条紧凑通告，真实类别、城市和有效期；进入原通告详情。 | 形成浏览到合作的自然路径。 |
| 故事与本人业务 | 保留写下故事及我的故事与草稿；订单、合同、制作、已购保留在我的与全部入口。真实待办存在时才显示紧凑续办条。 | 降低常驻工具对发现内容的遮挡，现有业务继续可达。 |

“精选”是编辑或规则选择的内容，“艺人／视频”是当前频道内的浏览，“找艺人／看作品”进入完整目录与筛选。实现时若用户测试发现重复入口仍造成困惑，可把对应快捷位替换为明确的服务入口；不要再叠加第二排同义导航。

## 视觉与交互取舍

- 纸灰 `#F3F1E8`、墨黑 `#151515`、朱红 `#EF4938`；标题继续使用 Noto Serif SC，正文 Noto Sans SC。丰富感主要由冷暖影像、人物肖像和大小不同的栏目构图产生。
- 采用“一张主图、两张肖像、作品横图、短列表”的节奏。朱红用于当前频道和主要动作；控件保持直角和细线。
- 第一版以一张精选主图为宜；需要多张时提供手动切换。视频默认展示静态预览，不自动播放或出声。正文不依赖遮在复杂照片上的小字。
- 城市选择要对所展示的同城内容真实生效。没有结果时显示空态或明确说明切换到全部城市，不能显示其他城市却保持“上海”筛选。
- 首屏优先加载少量内容与缩略图，下方按需加载。320/390/768 宽度、放大字体、长姓名和图片失效需要在实现时验证。
- 本稿展示“已登录、无待办”场景。若有本人草稿或待办，可在合适位置显示真实摘要和单一续办动作；不能用静态“正在制作”等文字推断业务状态。

## 已有能力与待补条件

| 能力 | 当前证据与可用范围 | 下一步 |
| --- | --- | --- |
| 紧凑导航、布局、原入口保留 | 当前 `app_shell.dart` 是本地图片与导航组合，未请求首页推荐数据。 | 前端可直接调整，核对每个入口与返回。 |
| 艺人内容 | 已有城市、标签、可试镜筛选、头像及获准预览读取。 | 前端复用目录与素材权限；明确精选来源，不能把目录顺序称为人气排序。 |
| 现成作品 | 已有目录、许可、价格和审核后的预览；目录模型未提供可直接当海报使用的明确封面 URL、播放量或时长。 | 确定封面字段或从获准素材制作封面的方式。未具备时采用诚实的无图排版，不编造播放量。 |
| 同城通告 | 已有类别、城市、有效时间及是否接收投稿。 | 前端展示有效公开通告；不新增陌生人私聊。 |
| 榜单和活动推荐 | 已有已发布榜单、月度活动与奖励曝光；奖励曝光有自己的资格和时效。 | 按原口径复用，不将奖励曝光改称付费广告或个性化算法。 |
| “本期精选”与专题编排 | 当前调用层未发现通用首页编排、专题选品或个性化推荐流。 | 产品确定选择人、更新频率和展示理由；服务端提供可维护的内容引用、顺序、有效期及撤回规则。第一版可采用简单人工选品。 |
| 游客浏览 | 当前相关“公开目录”仍要求账号登录；公开表示内容权限范围。 | 若希望未登录就能逛真实推荐内容，需后端明确匿名字段、媒体权限与撤回策略。 |

建议首先确定三件事：精选内容由谁更新、现成作品封面从哪里来、游客可看到哪些内容。无需为图标和版式修改等待一个完整推荐算法。

## 业务边界

- 公开展示不授予形象、声音或作品的商用权；素材撤回、过期或重新核权失败后应清除展示。
- 现成作品展示获准预览，完整内容继续按既有购买和许可流程办理。
- 榜单名次、认证、价款、播放量、匹配率和交易进度只来自真实且可展示的事实。
- 机构/出品人缺少公开姓名或照片时，使用现有可公开事实；不得用生成肖像冒充真实经营主体。
- 用户截图顶部的共同验收工具栏属于测试环境，不纳入正式产品首页。
