## 城市与推荐规则

本次把「随着IP走」理解为按所在城市推荐，而非影视IP内容专区。

- 已手动选择城市时，保留用户选择，后台定位变化不覆盖它。
- 首次无选择时，可使用已授权设备定位；没有设备定位时，可使用IP推测城市并允许纠正。两者均不可用时，显示选城或全部城市。
- 明星、本地艺人、同城机会联动同一浏览城市。作品精选使用独立作品池，保留全部作品入口，不把购片限制在本市。
- 本城没有明星时，显示简短说明及「查看全国明星」，明确全国范围；不把全国名单伪装成本城结果。
- 「明星」需要运营定义与本人公开资格，不以光环等级、榜单位置或可约标记直接推定。公开展示也不表示该人已开放试镜或当前有档期。
- 城市选择页区分「当前浏览」和「推荐城市」；推荐杭州不表示已经替换当前上海。用户可主动使用推荐城市或手选。

## 接口与实施边界

以本轮已核对的 integration `767d2ffc` 及其相同业务接口源码为依据：

1. 现有公开艺人城市/标签筛选可复用；目录按记录ID排序，不是明星或人气排名。明星标记、城市推荐名单、展示顺序和有效期需要产品定义及可维护的数据来源。
2. 当前主页只有手动城市输入；未发现已接入的IP粗定位或设备定位能力。城市选项已有「上海市」，自由输入又允许「上海」，后端按字符串完全匹配，需统一查询值与展示简称。
3. 现成作品目录、详情和获准预览可以复用；封面素材、作品精选名单与顺序仍需明确。现有公开返回没有海报、播放量或视频时长，效果图不添加虚构数值。
4. 同城通告保持原详情与投稿边界；不新增自由私聊。试镜继续核对真实服务、时段、审核、价格和接受状态。
5. 布局、字号、图标、矩阵和模块合并可由前端完成；定位、明星名单和推荐配置不能仅凭改版画面视为已实现。
