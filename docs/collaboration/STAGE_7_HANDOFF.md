# 第七阶段交付与异常恢复

已实现制作项目、负责人、私有交付文件、剧本/样片/粗剪/成片版本、独立审核、客户反馈与最终验收、对应付款条件和任务恢复边界。真实长期数字人联网接入仍缺供应商产品和接口资料，未实现具体供应商传输；本轮不能把这一项写成正式启用。

## 代码和双方影响

新增production模块和MySQL迁移0050–0054，新增PRODUCTION_REVIEW权限。原迁移不改。任务恢复允许传入已有业务事务，使任务恢复记录、业务状态和审计一起提交或回滚；旧调用方式保持兼容。

订单模块只通过production/payment-gate调用制作确认检查；默认拒绝已撤回同意、退款、无效许可等状态，不接收页面自报已验收。已购剧本必须允许PRODUCE；AI生成另外要求AI_PROCESS。创建长期数字人另外要求明确AI_TRAIN本人同意。通用改编、受控阅读和普通私用均不自动授予训练。

不改Flutter/Vue，不替队友认领。队友需要接新增页面及状态，不需要修改数据库或调用服务器内部函数。旧接口字段不变；满足真实制作确认后，第六阶段原先关闭的样片/最终验收付款节点才可能放行，仍按原订单付款计划。

## 独立验证

在backend_server目录按既有隔离MySQL说明配置环境后运行node scripts/test-mysql.js production。关联检查为trade、licensing和worker。仓库根运行node scripts/backend-check.cjs all作完整回归。接口校验用虚拟环境Python scripts/validate_contract.py，加--runtime-fixtures .local/production-http-fixtures.json可核对实际HTTP返回。

测试使用合成文本与视频占位字节、私有存储及数字人传输替身，验证权限、文件摘要、状态、并发和恢复，不代表视频质量通过。真实素材和真实试片必须另验，不能把自动测试计数写成甲方已验收。

## 运行和恢复

- 数据库按既有迁移工具升级，只在隔离副本自验。DDL失败保留已成功部分，按迁移状态修复，不删除历史数据或改写已执行迁移。
- 制作文件上传最多50MiB；重复上传同一请求在处理中被拒绝，不并发覆写同一个私有文件。结果未知先核对原记录，失败残留私有文件后续按保留与清理规则处理，不能转公开链接兜底。
- 后台程序明确设置PRODUCTION_WORKER_ENABLED=true才装配制作处理器，继续使用既有MySQL持久任务、租约及重试记录。没有供应商时，不会因此变成可生成。
- 真正供应商须在可信服务器代码中实现provider.js的接入，并有对应环境、配置版本和真实验证证据。必须支持按固定请求编号查原任务；不支持这一点不能启用自动恢复。不能仅填一个任意网址或设置一个环境变量就声称接通。
- 创建/生成提交不明时，任务进入BLOCKED，由审核人员核实后恢复同一请求，恢复只能查询，不能重新提交收费生成。过期工作进程不能写入结果。
- 同意撤回立即阻止继续使用；撤回处理器把已知资产标记待删除，不冒充已经在上游删掉。实际删除必须等供应商回执。若撤回发生在上游创建结果尚未查明时，须由运营依原请求号核对上游并处理可能已创建的资产，不能只删本地记录。该项属于真实供应商接入和删除验收的必要条件。
- 已验收最终版本不能由制作方直接覆盖。客户提出修改后按原规格次数与后续确认处理；商业条款或报价变化不能悄悄改写原订单。本阶段没有擅自建立自动加价或放行入口。
