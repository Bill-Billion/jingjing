# 八个扩展状态的契约矛盾修正

仅修改独立预览 pages-states.js 的 S02、S05、S10、S11、S15、S16、S17、S18 渲染函数。改前已留存独立副本，其他20态和公共helper未改。依据既有交易、星探共创、企业票据、试镜退款状态交接，不新增画布或运行证据。

- S02：内容确认不等于签署，移除假签署入口与分配比例。
- S05：不把CLOSED、超时或异常写成失败或未扣款；仅原记录核对，不开放重付。
- S10：active/valid_until不是恢复事件，删除恢复成功、日期和金额。
- S11：人数与门槛待真实读取，申请延期/取消与审核退款分开。
- S15：移除邮箱和假企业/付款信息，税号格式不等于企业已核实。
- S16：删除假媒体与已开放/可分享，明确本人许可、验收、整包付款及退款撤权待核。
- S17：删除固定拒单原因、金额与时间，不称退款已到账。
- S18：明确核实状态条件，不造渠道、时间和凭证；部分退款不当全额。

全部输入和业务按钮禁用。仅静态源码与差异核对，未测试、运行、编译或精确视觉校准；真实App、共享CSS/helper、索引未改。
