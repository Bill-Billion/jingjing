# 制作分页与状态文案静态修正

范围仅 production_api.dart / production_widgets.dart。未改页面、接口字段、后端、权限规则或写入恢复。

## 已据源码修正
- ProductionApi.all() 原末尾按 ID 直接覆盖，后页重复 ID 可将已读较新记录替换为旧版本。现保持插入顺序，仅以更大 record.version 更新同 ID；同版保留首条，与既有 67 版本历史规则一致。
- 整次 all() 固定起始 participant/epoch，调用每页之前和 await 后均调用既有 check。page 自己的校验、分页 cursor 循环拒绝、DTO 与项目 scope 均保留。异常原样抛出，不当空列表返回。
- 当前 APPROVED 未确认版本改为“等待买方负责人确认”，不向只读成员/制作人暗示其可确认。
- 非当前版本改为“历史版本，不能作为当前确认对象”，不暗示该历史版必然曾获确认。当前已确认分支不变。

静态影响：66 详情的版本及反馈、67 反馈读取、恢复路径读取反馈均使用 all()，只改变同 ID 合并和整次身份守卫，无新增确认动作。

## 边界
页间并非服务端一致性快照；此修正不承诺消除所有跨页并发变更。仅静态读 diff、符号与调用点；未运行测试、编译、分析器、格式化、业务接口或 UI 渲染。无提交推送。
