- 49：申请金额合法后显示“当前可用余额+本次申请金额”的条件算术估算，不是到账、服务开通、实际可充值承诺。不估算等级/晶钻/恢复日期或新会员有效期。原表单恢复、校验、提交与幂等未改。
## 尚欠与限制
- 最近充值接口无时间倒序/快照契约，当前全分页读取有大账户请求成本，且并发写入下不是一致性时间快照。建议服务端提供明确排序的本人 recent 接口后替换；不得宣称强一致完整交易账单。
- 49 会员恢复缺独立恢复事件及服务端时间契约；会员年累计不能简单视作申请金额相加即续年，不给假恢复结果。充值正式托管未接通边界保留。
- 23 目录的本人额度原先读取失败仍可能阻断目录；本批未重写其他业务加载逻辑。
- 本轮未新增规则、API/model 或后端；不代表全量钱包/权益视觉已完成。
