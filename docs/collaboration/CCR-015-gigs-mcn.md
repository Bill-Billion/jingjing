# 待共同审阅：商单、直接合作与佣金

本侧实现后端，队友检查页面能否准确表达如下规则。尚未获得对方实际批准。

- 商单用途与证明先审核；企业以实际身份操作，MCN合作须被邀请方接受，不能无感添加艺人。
- 单笔佣金随接单约定进入报价和合同；MCN从平台佣金中分出，不层层返佣，不重复扣供给方。比例无默认值，实际转账仍在后续财务范围。
- 合作终止阻断新约定，不改历史订单；部分退款按累计净实收重算，差额可核对。
- 榜单为明确同意上榜的真实商业交易事实，不混沙箱、演示或客户端自报点击；规则可解释、日期快照不回写。
