## 怎样检查

只检查账号权限规则，在新目录根执行：

```text
node scripts/backend-check.cjs party-unit
```

只需Node 22.19.0，不需要服务器依赖、MySQL或付费账号。它只检查规则，不代表数据库或接口已经通过。

完整数据库测试见[自动检查说明](AUTOMATIC_CHECKS.md)和[MySQL基础说明](../../晶晶日上工程交接包/01_源码/backend_server/docs/MYSQL_FOUNDATION.md)。按说明安装服务器依赖、启动本机隔离数据库后，设置`JX_MYSQL_TEST_ENV_FILE`为该工具生成的测试配置绝对路径，再从仓库根运行：

```text
node scripts/backend-check.cjs party
node scripts/backend-check.cjs all
```

没有隔离配置会失败；不要填正式数据库配置。接口格式校验方法见[接口入口](../../contracts/README.md)。GitHub会分别运行无需数据库的检查和完整数据库检查。
