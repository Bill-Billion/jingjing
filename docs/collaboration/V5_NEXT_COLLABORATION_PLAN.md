## 第一条流程怎样算联调通过

1. 普通买家不必先建数字人或购买身份，能保存、退出后找回并正式提交故事；无权账号读不到正文。
2. 运营看到同一正式版本，提出补件；买家保存草稿不会提前公开，重提后旧正式版本仍保留。
3. 平台签约主体报价，另一个有权人员复核；普通机构和报价人自己不能代替复核。
4. 买家能看懂规格、总价及付款节点，确认后只生成一个未付款订单；重复点击、刷新和丢失响应不重复下单。
5. 切换账号、个人/机构身份或失去权限后，旧私密数据及时清空，迟到返回不能重新显示。
6. 保存一份同版本结果和问题表：谁遇到、怎么重现、应当怎样、实际怎样、谁修、复测证据。阻断问题修完；非阻断问题写明负责人及下一批处理，不能用测试总数代替验收。
