# 待另一方审阅：订单承诺、真实付款和退款

本侧已实现并进行隔离测试，未获另一方批准。依赖第11至14份待审代码，不能直接合入共同版本。

请重点检查：

- 每个商品和报价明确规格、金额、规则与分期；买方确认摘要后封存原始承诺。新价格不能改变旧单。
- 订单归属、审核排除当事方、退款独立权限；外部签名校验与配置验证不能由页面绕过。
- 超时不重扣，重复通知不重复入账；真的重复扣款、迟到付款必须保留资金事实并人工处理。
- 退款按付款明细占用额度；线上许可费不足或已退时禁止后续许可使用。签署和身份核验仍独立。
- 旧99/4901记录原样保留但不冒充新到账；Apple只处理明确完整退款，未知情况不自动决定。

新增迁移0041–0049与16个HTTP入口，候选0.6.0-rc.1；原有接口不改字段，新增许可财务门槛可能返回LICENSE_PAYMENT_NOT_READY。App/Vue无需改数据库，只按新接口接订单页面。后续制作模块只需提供可信验收结果，不得接收页面自报已验收。
