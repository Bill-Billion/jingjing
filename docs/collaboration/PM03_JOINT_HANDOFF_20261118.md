3. 构建管理网页；Flutter Web 入口 `test/support/v5_business_browser_main.dart`，参数 `--dart-define=R05_R12_SYNTHETIC_ONLY=true --dart-define=JX_ACCOUNT_API_URL=http://127.0.0.1:5500 --no-web-resources-cdn`。这是合成联测入口，不作为发布入口。原生 App 则使用 `lib/main.dart` 及本机后端地址构建，Gradle 属性 `pm03Isolated=true` 使 debug 包带独立后缀；本机通过 `GRADLE_OPTS` 追加 `-Dorg.gradle.project.pm03Isolated=true`。模拟器用 adb reverse 对应本机后端端口。
4. 运行 `node scripts/pm03-batch-smoke.cjs ENV_DIRECTORY`，再运行 `node scripts/pm03-joint-ui.cjs ENV_DIRECTORY`，分别在 5500、5173 提供实际构建产物及回环代理。账号/验证码/会话仅保存在本机受控文件。默认 Edge；浏览器脚本可用 `PM03_BROWSER` 指定本机可执行文件。
5. 四组读取检查：`node scripts/pm03-ui-app-reads.mjs ENV_DIRECTORY`、`node scripts/pm03-ui-web-reads.mjs ENV_DIRECTORY`。
