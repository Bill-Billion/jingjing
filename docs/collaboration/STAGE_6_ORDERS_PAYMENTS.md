# 第六阶段：报价、下单、支付与退款

本侧负责MySQL、服务器和支付适配；队友负责商品/报价确认、收银、付款恢复、退款和运营页面，未代为认领。

范围：版本化规格和逐项报价；明确交易责任方、服务提供方、规则与历史合同；付款计划逐项分配，不默认50%等比例；可信支付宝及Apple购买核验、重复和乱序处理、未知结果保留待查询；按原支付及明细申请/批准/执行/查询退款；旧单承诺原样保存并独立复核，不按新价重算99/4901。

外部服务通过既有适配器和启用状态检查，测试只用隔离替身，不调用收费服务。Apple使用官方服务端库核验具体交易，核对应用、环境、商品、金额和购买绑定，不沿用旧“取收据最后一笔”。普通内购退款由Apple受理，本系统核实实际结果，不能假称服务器能替Apple批准。尚未接通的样片/成片验收条件不开放尾款。

验收：不信客户端paid；越权、错金额/币种/商户/应用/环境、伪签名、重复交易、并发多退、超额退款、未知重试、历史承诺和数据库失败回滚；MySQL/HTTP和完整回归、格式检查。完成后集中上传一份阶段申请，审阅、合并、上线各自记录。

依赖：共同版本仍7d139ff；本分支明确引入第五阶段ce576af及账号/合同/许可前置。第11至14份仍开放待审，应先验收；不改队友App/Vue，不直接合入main或部署。
