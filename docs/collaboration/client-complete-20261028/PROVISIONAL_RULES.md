# 先按这些方案开发，再由甲方集中审阅

版本：TEST-20261028-1。依据：用户2026-10-28明确授权“需要甲方确定的部分由你按合理方案暂定”。下列是**本侧暂定实施方案**，可以用于开发和隔离测试；甲方尚未逐条正式确认。已确认的30/60/10分期、先预览后补至90%、L1现货、退款待冲回、儿童实际处理关闭等不重新变更。

适用范围：当前完整测试版。真实价格/商业授权/财务产品/隐私法定依据不由测试方案制造；测试数据带版本及模拟标识。规则变更只影响明确的新版本，历史订单和已确认承诺不重写。来源对照为 [现有决定](../DECISIONS.md)、[完整缺口核查](../../testing/FULL_BUSINESS_CLOSURE_20261028.md)、[设计差异](../../reviews/figma-frontend-restore-20261023/NEEDS_CORE_OR_PRODUCT.md)。

## 怎样避免“暂定”变成永久悬案

本侧按上表实现并在测试版提示涉及的口径；甲方集中测试时只需给每项“接受/修改及理由”。修改时追加新版本和受影响页面/订单范围，不覆盖本记录。涉及真实法律文件、第三方权限和资金资质的材料仍列在正式启用条件表，不让它们阻止隔离业务施工。

本表为规则决定记录；实现是否写完、测试是否通过、是否已经合入和正式能用，分别查任务表。不得因为规则已暂定就把功能标完成。
