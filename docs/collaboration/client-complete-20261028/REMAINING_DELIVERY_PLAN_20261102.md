3. 本轮已实际验证业务库、附件及同订单反馈恢复；继续固定App/网页构建、模拟资料、反馈记录和保留订单的回滚方案；阶段集中审阅合入，随后按用户授权更新测试环境。
4. 用户开始人工检查时由后端准备环境、核实际版本、保留仍在用的会话，不要求用户自行执行日常启动命令。
