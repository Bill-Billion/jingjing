3. 不能完成主流程、串账号/串身份、授权绕过、付款/退款算错、私有文件暴露、数据丢失的问题必须清零；剩余轻微排版和明确非阻断改善给出清单，不隐藏。
4. 客户可自由浏览和办理，无邀请码、无“请选择测试业务”下拉；模拟标识清楚，付款/核验/签署等有可理解的等待、失败和成功反馈；原页面能反馈问题并附自动定位。
