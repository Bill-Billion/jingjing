## 请接三处

|事情|怎么接|怎样算通过|
|---|---|---|
|艺人公开资料的主肖像|现有展示申请 `POST /api/v1/artists/people/{person_id}/listings` 的 `listing` 内增加可选 `primary_portrait_asset_id`；只能选择同时在 `preview_asset_ids` 中的JPEG/PNG，允许null；更换继续走原新展示审核|旧展示未选择时有占位；私人但未选公开的文件不能被指定；待审不提前公开；审核后才展示所选图片|
|公开详情的图片、视频、声音|`GET /api/v1/artists/catalog/{listing_id}/media`，带登录凭证，不带办理机构头。返回 `listing_id`、`primary_portrait_asset_id`、`items`。每项是 `asset_id/media_type/media_kind/byte_size/content_sha256`；media_kind是IMAGE/AUDIO/VIDEO/DOCUMENT|按类型用正确控件，原字节仍由 `/catalog/{listing_id}/assets/{asset_id}/content` 受控读取并核对摘要；不拼公开存储地址，不把声音当图片；读取/解码失败显示占位；换身份、撤回、过期后清本页旧内容与对象URL|
|故事附件保留原因|原附件列表增加 `include_retention=true`；每项可选 `retention_reason` 为 `FORMAL_SUBMISSION` 或null。Vue当前严格字段白名单需要一并接受且校验此字段；不传参数时原格式不变|补件换新文件后旧正式附件仍显示“正式版本已引用，需按保留流程处理”；无历史引用不显示这一原因。不能写“已永久删除”或猜保留年限；服务端撤回仍是最终判断|
