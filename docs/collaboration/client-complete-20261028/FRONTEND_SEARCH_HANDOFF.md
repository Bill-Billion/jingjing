## 用户现在可以办什么

两端从服务器读取同一份快捷城市，用同一查询条件搜索当前可公开的艺人、现货、试镜和通告。关键词查询会继续遍历后续目录，不能只筛首屏。撤回公开授权、通告关闭、现货失权或试镜关闭后，重新查询不返回原记录。搜索结果不授予购买、预约或下载权限，仍须走原详情和办理入口。

|动作|接口（省略/api/v1）|约定|
|---|---|---|
|读取城市|GET /discovery/cities|返回revision、scope=QUICK_CHOICES、allows_custom_city=true、items；每项code/name/aliases|
|搜索或浏览|GET /discovery/search|kind必填：ARTIST、STOCK、AUDITION、NOTICE；可选city/q/cursor/limit（1—100，默认20）|

两项都必须登录，均不带X-Acting-Party。城市当前提供北京、上海、杭州、广州、深圳、郑州六个既有快捷选项；code依次为beijing、shanghai、hangzhou、guangzhou、shenzhen、zhengzhou。它是统一快捷目录，不是全国行政区划或全国业务开通声明。新搜索支持code、简称或带“市”的全称；其他城市可输入名称精确匹配。旧目录接口仍传name，不能向旧接口直接传新code。不改实名、合同及其他已存地址。选择“全部”时省略city；省略q就是浏览，不能传空字符串。

搜索响应data固定包含kind/city/q/items/next_cursor，city/q是服务器标准化值或null。items沿原公开目录格式：ARTIST用listing_id进入艺人详情；其他三类用id。复用原媒体接口，搜索不新增图片URL。机构及精选目录已有q筛选，继续用上一批接口。

匹配公开文字的完整字面子串，兼容大小写和全半角；不将百分号当通配符，不搜索编号、私人材料或隐藏价格。ARTIST搜索名称/介绍/标签，STOCK搜索标题/说明，AUDITION搜索标题/服务区域，NOTICE搜索标题/说明。排序按各类记录id升序，不冒称相关度排名。

## 翻页与异常

- 游标是不透明字符串，绑定登录账号、kind、标准化city与q；不得自行拼接。切换类别、城市、关键词或账号应清空旧结果及游标；保留已有迟到响应保护。本页独立城市优先于默认城市的规则继续沿用。
- 每次最多扫描10个底层页。可能items为空但next_cursor仍非空；应显示“继续查找”或受控继续读取，直到next_cursor=null才能显示“没有更多”。没有总数。不得无限自动循环请求，也不能将中间空页显示为最终无结果。
- 翻页顺序稳定，但不是跨请求快照：新上架且id排在已读位置前的内容需刷新列表；原内容撤权后会消失。换筛选后用旧游标返回400 INVALID_CURSOR，应清游标重查。
- 401回登录；400显示可恢复的条件错误；403/404/409按既有失效内容处理；503保留搜索输入并允许手动重试，不恢复被隐藏记录。关闭价格的试镜unit_minor=null，不显示为免费或0元。
- 每次重新搜索或切身份回收旧图片资源，点击详情再次核对有效性，原现货下架购买保护继续保留。
