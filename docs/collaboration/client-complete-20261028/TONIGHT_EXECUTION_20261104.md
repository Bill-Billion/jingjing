已知登录失败、切错身份、越权读文件、错误钱账、丢资料、主要按钮缺失或流程无法继续，均为阻断。非阻断文案/排版可以明确登记供甲方反馈，但不得用其掩盖业务不可办。12条正常主链是交付前必要条件，不代替151条全部有效预期；完整验收和独立审阅继续按原门槛。
