## 队友从哪里调用

接口文件为 `contracts/openapi.yaml`，版本 `0.22.0-rc.1`。本轮新增60个操作（含第7轮补项），总数353。接口可调用状态指隔离环境验证，不代表真实外部服务已启用。完整请求、响应和错误见接口文件；[合成返回](../testing/evidence/v5-r09/FRONTEND_FIXTURES.json) 是实际本机测试返回，编号只属于当次测试库。

所有接口需要登录。代表个人或机构的操作用 `X-Acting-Party`；运营审核不传该身份头，使用独立运营授权。写操作用 `Idempotency-Key`，修改既有记录另传 `If-Match: "版本号"`。普通响应是 `meta + data`，记录的具体内容在 `data.data` 内；日期为带时区时间，金额为整数分，分数与金额不可混用。重复请求沿用同一请求编号，不用反复新建订单来重试。

## 已确认的规则和仍需材料的部分

用户确认：星光值只做独立可配置记录；未配置不发放、不兑换。月冠军总分同分时依次比官方分、榜单分；仍同分先独立复核，不自动发奖。涉嫌刷票暂停计票，确认后作废，晶钻不自动退；申诉成立可恢复票或退晶钻。若原晶钻来源已因退款形成待冲回，退票先结清该批次欠额，不制造新余额。

出品人/机构城市榜权重未见明确数字，用户已确认“真实数据可展示、排序可配置且独立审核、未配置不排名”，决定见记录；合成测试中的权重不是正式规则。`buyer_rank` 可不配置；配置时个人四项权重依次为消费成长/完成订单/净消费/合规，机构三项为完成订单/净消费/合规，各组合计10000，是否优先星探另设布尔值。机构不自动获得个人钱包、充值或可花晶钻。

推荐比例必须来自审核规则，并与订单固定的平台分配一致；冲突保留人工复核状态，不从艺人份额补扣。支持带新版已审财务规则的订单；历史缺平台分配规则的旧交易不自动新增返佣承诺。定制按各行实际净收入及扣项核对平台预算，不用平均比例估计。追加试镜费用不继承原单推荐归因，也不重复计基础接活成长。

成长与榜单沿用原始信用成长文件所列可配置结构；星光数额、售后期、违规降权幅度、真实商品及活动规格必须有审核版本。代码中的测试值不等于正式默认值。页面显示未启用的支付、实名、存储、长期数字人服务，不因模拟检查通过改为正式可用。

## 只在本机使用的模拟支付

准备仓库既有隔离MySQL（127.0.0.1:33316），设置 `JX_MYSQL_TEST_ENV_FILE` 指向本机测试配置，运行：

```text
node scripts/v5-payment-sandbox.cjs
# 在另一个终端执行，把下方实例目录替换为启动时输出的目录
node scripts/v5-payment-sandbox-smoke.cjs .local/v5-payment-sandbox/<实例目录>
# 测试结束，在启动终端按 Ctrl+C，等待清理完成
```

启动脚本不接受额外参数。每次启动建立新 `jx_test_*` 库，生成临时账号；入口只监听127.0.0.1，最长60分钟；结束删除测试库和本地访问凭据。用启动时输出的本机地址及实例目录内的访问文件联调，访问文件不能提交Git或放进聊天。本轮不开放公网测试入口、不发真实短信。

模拟控制入口 `/api/v1/testing/payments/outcome` 与 `/testing/wallet/topup` 只在该脚本运行时存在，正常服务器没有这些路由。可选未知、等待、成功、关闭等结果，全部标模拟；不得把同一付款的最终状态任意改来改去。正式充值仍拒绝，测试资金不进入正式榜单和应付佣金。更换真实支付产品只替换服务接入层，不能绕过订单、权限和回执核验。
