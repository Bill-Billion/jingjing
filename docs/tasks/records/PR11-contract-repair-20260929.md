## 改了什么

1. 账号和机构的示例使用服务器已有的大写动作名称；仅对 `Account`、`Party` 增加枚举和停用状态校验，泛用动作定义保留。成员、能力示例不再虚构额外权限。新增6个正例及11个反例。
2. `IDEMPOTENCY_IN_PROGRESS`、`COMMIT_OUTCOME_UNKNOWN`、`RATE_LIMITED` 返回 `retryable: true`。重试须保留原请求键、内容、版本及身份；不能因此重新创建操作。其他错误保守返回 `false`，不等于原写入确定失败。
3. 限流窗口和短信冷却期用数据库时间计算剩余秒数，通过 `Retry-After` 返回并允许网页读取。短信申请不可用时保持不可重发，冷却后用户可明确新申请。
4. App、Vue沿用已有大写权限和原操作恢复逻辑；本轮没有修改页面、自动重试策略、数据库结构、迁移文件或依赖。
