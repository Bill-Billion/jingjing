## 这次新增的实际能力

|工作|现在的结果|
|---|---|
|保存规则版本|新规则从草稿开始，提交审核、批准、生效、停用分别检查操作权限和版本；内容不提供原地改写接口|
|保存合同当时的内容|规则从数据库读取；合同当事方与承诺由可信业务来源提供，封存后不随源内容变化而覆盖|
|限制谁能读|只允许明确获得该份合同读取授权且账号仍有效的人读取；机构成员不自动获得合同读取权|
|处理重复与同时提交|同一请求返回原结果，改内容重复用同一键会拒绝；同一来源即使用不同键同时提交，也只保存一份|
|保留操作记录|内容、读取名单、请求结果和操作记录一起提交；任一失败整笔撤回|
|读取历史|规则后来停用仍可读取当时封存内容；重新连接数据库后内容仍在；发现内容与校验值不一致会拒绝返回|

这里的权限由服务器端回调和数据库记录共同检查，默认不配置就拒绝。正式登录与运营角色、合同/订单来源尚未接线；测试用明确标识的合成身份与业务来源，不等于真实业务已可用。暂未提供公开HTTP、私有附件存储、真实签署、付款或许可生效处理。
