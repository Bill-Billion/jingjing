- 简历采用文字填写，文件分类及数量/格式限制便于审核；程序只检查完整性、文件归属和可用状态，人工判断真实性/是否合格。免费档案交付须有效本人同意和图片/声音文件，不能用一张图充当声音完成。
- 新规则以ARTIST_CONTRACT_POLICY显式切换，默认历史兼容供现有页面继续运行；当同版页面和审核规格到位再切换。代码已具备不等于当前网站已采用新价。
- 免费服务独立保存版本快照和办理记录，不生成零元“已付款”订单、不扣晶钻；失败记FAILED且无现金退款。长期模型和OSS状态不因权益成功而改变。
- 同一形象重复申请免费服务复用进行中/已交付记录；失败或取消可重新申请。旧创建单仍在履行时先处理原单，不能覆盖历史义务。照片/声音档案是基础服务，不含另行报价精修或1000元代做样片。
- 10元新版审核不接受普通退款申请；外部支付真实退款事实仍应记录，不在入账回调中掩盖。原同案补件不再次收费；正式撤回消耗原服务，另案重新申请须新的审核服务。旧费用不套用新不退规则。
