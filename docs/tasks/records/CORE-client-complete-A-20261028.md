## 本次做什么

1. 平台将已发布商品规格与原始规则绑定，提供卖家可读的销售说明；另一位有权运营核对后发布。卖家无需有历史商品即可选择，停用后不得新上架或购买，已购许可单独保留。
2. 按当前个人/机构与具体真人查询获准的数字人及销售、展示同意。机构实际经营委托与每位出镜人的本人授权同时校验，不从旧作品猜权限。
3. 审核退回后另建修改版本，再次进行内容和权利审核。审核通过前不出售新版本；通过后停止旧版的新销售，旧买家的订单、合同与文件不被替换。连续多次退回和再次修订均按版本链接处理。
