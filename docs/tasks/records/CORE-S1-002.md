## 这次实际做成什么

|具体事情|实际结果|
|---|---|
|一个人拥有个人身份，同时参与机构|个人账号、个人主体、机构、机构成员分别保存，互不覆盖|
|机构可以有多种业务能力|可同时提交MCN、制作、剧本供给等申请；个人可申请作者；全部待审核，不自动批准|
|发出成员邀请|只有机构创建者这一管理角色可以发出；邀请绑定一个明确账号和明确截止时间，没有默认合作期|
|本人确认|只有被邀请账号能接受或拒绝；发出邀请本身不产生有效成员关系|
|防止重复或过期操作|重复同一请求返回原结果；改内容复用同一请求编号会拒绝；过期、已撤回或版本不符不能接受|
|防止权限扩大|普通成员不能邀请别人；跨机构操作、客户端自称管理员或替别人确认均不放行|
|解除成员关系|本机构管理者可移除普通成员，保留个人身份、其他机构关系和历史确认；不能用此入口移除所有者|
|保留操作记录|成员变化、邀请与关键操作记录一起提交，任何一项失败全部回滚；服务重连后数据仍在|

接受邀请只获得本机构的基础成员身份，目前普通成员仅可读取机构基础资料。它不授予MCN商业代理、作品许可、收款、佣金或艺人收入查看权。机构仍待审核时，只允许申请与组建团队等准备操作，不因此正式营业。
