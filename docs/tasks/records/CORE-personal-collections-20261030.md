## 已写好和测过的内容

- 账号本人可以收藏/取消公开艺人、现货、通告，分页查看并回到原详情。机构代办和他人账号不能读取；个人清单按账号归属，不混入机构经营资料。
- 浏览记录默认关闭，用户明确开启后才接受实际详情访问；关闭同时清空，清空本身保持开关。单删、清空与开关变更都更新偏好版本；迟到请求不能越过清理，旧键重放不恢复被删内容。
- 最近记录按P08默认30天/200条，可配置；超量和到期记录实际删除。查询按本人/清单/类别签名游标，足迹还绑定偏好版本，跨账号或换筛选不可串用。
- 每次查看列表重查原公开资格；撤权、下架或关闭后显示不可用，不保留旧标题和城市。清单表不复制图片/简介/证据，原请求回执不存目标编号，失败不会伪造成功或直接丢弃收藏。
- 收藏不自动增加原榜单互动分数，现有engagement/interactions不是个人收藏清单。
- 后台清理复用现有任务系统和租约保护；无有效执行租约不允许删除。按最近一条到期时间安排后续清理，无记录后停止安排。启用时需要COLLECTION_WORKER_ENABLED=true，API与worker采用同一保存配置；停机、失败或阻塞任务需要运营恢复，不能宣称无后台运行也会准点物理清理。
