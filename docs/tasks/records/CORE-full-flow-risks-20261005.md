## 实际发现与修复

付款、退款和成员权限的前八组通过。第九组在已读样片后暂停剧本许可，服务器正确返回 `409 PRODUCTION_LICENSE_NOT_READY`，但网页保留旧视频、“已实际读取”提示和已读状态。截图已显示拒绝信息与旧播放器同时存在。App随后补两项回归，409/503均在原代码失败，仍保留旧阅读提示。

最小修复：网页在每次重读前撤销旧预览地址，清空旧内容和已读状态，失败后清除旧验收选择；以页面请求序号保护迟到结果。App先移除旧播放器、文字和已读状态，失败时清除验收勾选；正常成功阅读前已填写的检查不被无故清掉。正常服务恢复后仍须重新实际读取，不放松后端许可、付款和角色校验。

受影响文件：网页 `src/views/ProductionView.vue`；App `lib/production/production_pages.dart` 和对应控件测试。服务接口、数据库、商业规则未变，队友不需要改接口，需要审阅这两处页面行为。用户已授权本侧必要页面修复，但尚未替队友评审。
