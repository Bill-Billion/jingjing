## 已写好的能力

用户在个人或机构身份下，能通过三类接口找到自己有权查看的合同和约定、作品与购买记录、本人收入核算。15个来源分类复用原业务权限和详情；先查候选，再逐条通过原业务授权，不返回原始私有材料或可绕过权限的下载地址。

每类按真实创建时间倒序分页；同时间用编号稳定排列，游标包含账号、身份、类别与来源校验。单来源查询失败明确标为暂不可用，其他来源可继续看；指定source可独立重试。原业务域+编号是去重键，同一订单的约定和已购作品不会串成同一来源记录。

收入只取本人已登记的应计、调整、核验净支付和退回，不推算未来收益，不重复计入其他人的份额。商家的账面留存单列，不假称仍应向商家转账；待付不代表可提现，负余额明确待追回。每条保留币种和环境，不提供跨环境合计或实时银行到账结论。
