使用合成资料及隔离数据库。测试中的供应商替身只用于发现意外调用，未请求真实供应商。最初两次专项测试暴露的是新增测试数据缺必填字段（样片梗概、作者编号），补全测试数据后通过；未把这些失败计为产品缺陷。
