## 用户能得到的变化

1. **上传中断可用原请求恢复**：数据库预留记录后文件实际未保存，用户明确重试时先核对；仅存储明确确认不存在才补写相同内容与原文件位置，再核对内容后确认成功。读取失败/超时不当作不存在；内容不符不覆盖；不增加新上传名额，不自动换请求。
2. **补件旧附件有明确保留原因**：清单主动带 `include_retention=true` 时，服务端根据全部历史正式版本返回保留原因。换了新附件仍能知道旧文件为什么不能撤回。默认响应保持不变，旧页面不会因多一个字段失效；不是法定期限或物理删除证明。
3. **艺人主肖像有明确来源**：本人或原有有效委托者在公开展示申请中选择一张JPEG/PNG，必须同时属于本次公开预览，随展示一起审核。新读取接口给出主肖像及图片/声音/视频/文档分类、大小、摘要；没有选择的旧展示返回空，不自动取私人图。未审、撤回、授权失效及托管失效仍拦截。

接口版本 `0.31.4-rc.1`，沿用数据库0167，无新迁移。现有故事、列表、下载默认格式不变；主肖像及保留提示按[前端接入说明](../../collaboration/client-complete-20261028/FRONTEND_MEDIA_HANDOFF.md)接入。
