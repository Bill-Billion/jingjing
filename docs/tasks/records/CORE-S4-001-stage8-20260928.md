## 本阶段交付

|工作|写好了什么|怎样验证|
|---|---|---|
|商单发布与审核|按保存的品类规则、证明和用途审核；违规可暂停并通知当事方|禁入品类、缺材料、自审被拒绝；暂停后不再展示|
|直接MCN合作|邀请须被邀请方确认，有期限、范围、独家检查和终止记录|MCN不能代本人接受；独家重叠被拒绝；权限撤回立即生效|
|报价与合同|供给方提出约定，需求方确认准确版本，随后进入报价和封存订单|实际HTTP报价核对，约定只能对应一笔订单；不能改旧单比例|
|单笔佣金|按核验收款与退款计算供给方、平台和直接MCN的待结算金额|整数分金额守恒、重复核算不增加记录、部分退款追加冲回、无真实转账假状态|
|三类榜单|按明确规则和日期生成热度、新兴、地区快照|正式环境来源过滤、按订单去重、明确同意上榜、隐藏原始收款和订单ID|
|共同数据库升级|新增0055至0062，保留0050至0054原件|从截至0049结构升级、重复执行、事务审计失败回滚|

## 检查和限制

专项测试23项通过：真实隔离MySQL、实际HTTP、并发版本确认、审核利益冲突、成员/能力/同意撤回、历史佣金保留和退款差额。实际供应商和付款网络使用隔离测试事实，测试中的PRODUCTION标记也只是隔离库里的合成数据，不是真实支付。完整回归和远端结果另存同目录证据JSON。

具体品类、佣金比例和排名权重必须由有效规则给出，不内置推荐数字。商用身份证明、委托、签署和广告材料必须真实审核；程序检查勾选及权限不能替代实际查验。佣金为核算时点的待结算依据，页面显示前须重新核算；不表示打款、可提现或财务对账完成。

榜单只使用目前可核实的商单收款指标，不虚构作品互动或复杂防刷平台。可按日调用接口和补历史日期，生产定时调度未部署。真实供应商启用、前端联调、对方审阅、合并、部署均未完成；没有生产访问或收费调用。
