# 本人撤回授权与模型删除：本轮任务

起点feee2ea，分支core/v5-privacy-protection。2026-10-20开工时目录干净，已抓取origin/integration，仍为28662ab；沿用当前隐私基础和前批数据库迁移依赖。本批继续在本地开发，到阶段交付点集中上传。

本侧负责把本人申请接到真实业务操作、任务与结果，队友负责选择模型、撤回确认、进度提示。本人选择具体授权，撤回后禁止继续按该授权使用；删除只针对已登记模型。供应商配置缺失或不匹配保持待处理，只有可信后台任务确认具体模型已删除才显示该模型成功。不能显示整个账号已清除，也不能把本批当做已开通真实外部服务。

本轮验收：本人/机构/运营权限、重复操作、版本冲突、撤回实际生效、记录失败整笔回滚、供应商未配置/换主体/未确认删除、失败恢复与旧结果保留。沿用现有后台任务，未新增服务或让页面读数据库。

范围边界：本轮先覆盖制作模块已登记的长期模型和对应供给授权，不包含所有人物资料、源文件、进行中的模型创建或备份；账号注销、投诉对业务的实际处置、素材机审及文件标识仍在后续清单。正式隐私材料继续按EXT-PRIVACY-20261020等待甲方，不重复索取。


## 已实现的接口与兼容影响

新增本人模型列表、撤回授权、申请删除及动作查询4个接口；原有13个隐私接口不变。新增0157动作记录表，沿用原有供给撤回、事务消息和制作任务。模型、授权和后台任务分别保存，不让申请的人工答复替代实际结果。

关键行为：本人资格独立检查，机构和运营不能代操作；撤回使后续按同一授权的使用失效；旧申请在已有答复后仍可继续登记动作，但回到待处理，不改写旧正式答复；同一模型已有删除任务时复用原任务。主体配置不符或无确认回执不显示成功。重试使用原受权限限制的制作任务入口。

测试已覆盖机构和他人隔离、范围与版本、撤回实际失效、重复提交、两类事务回滚、未配置供应商、配置变化、不确认删除、恢复时不重复提交以及结果关联遭篡改。真实供应商未调用。完整结果在整体验证后补入本记录。
