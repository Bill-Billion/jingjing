## 已确认缺陷与处理

1. **测试服务无法在短信登录后重启**：旧启动脚本删除会话，触发登录恢复记录的外键约束。改为撤销旧会话，并按账号只生成一次新会话；保留历史关联。真实隔离MySQL演练已验证旧令牌及原登录请求不能复活、新会话读原订单；备份恢复9项通过，原失败证据保留。
2. **财务材料受限但仍能批准记账**：独立红测证明受限付款回执仍能将已付从0记为1000分，受限草案仍能新增；另有原约定依据受限却能新申请付款。现在引用及审批均重查隐私/侵权限制。限制时不新增钱账，解除后原申请继续，历史合同和旧账不删除。详见[红绿证据](../../testing/evidence/tonight-core-ui-20261104/finance-restriction/REPORT.md)。
3. **客服无法选到合格商单报价**：原通用报价下拉只读客服个人主体，无可选值。改为当前工单范围的独立客服选项，匹配双方、真人形象、有效授权及已审未过期报价；选择不取代提交时重核。页面同时自动保留所选报价摘要，不让客服复制内部编号。
4. **首次机构协作仍需内部编号**：已补当前公开艺人、已接受机构及本人有效证明的选择入口；同一套新记录实际完成邀请、本人接受、委托、员工授权，失效/撤权及旧选择提交反例已检查。详情见机构专项。

5. **个人制作方不能选择负责账号**：个人有效负责人现可直接按本人姓名选择；机构仍按原成员权限办理，提交时服务端再核验。没有新增全员搜索或代授权。
6. **新版商单结算格式两端不兼容**：服务端原订单已保存两层分配，但网页新建表单和App/网页读取仍只认旧固定份额。现补两类互斥校验，网页从原单冻结内容带入，App/网页解释不同计算基数；不改变费率、历史合同或真实出款开关。原读取失败与修复后证据分别保存。

7. **发行收入无法选择原合同平台方**：候选只来自已确认演员，漏掉原合同中的平台。现按当前项目已审参演合同补参与方，逐页核当前项目和版本，不查询全库、不凭选择自动分红。独立收入协议仍须各方确认。
8. **曝光材料跨单／用途可被直接提交**：组合前端新增逐单材料接口时，独立审阅发现原排期/完成写入未执行相同限制。红测均可错误返回200；已补新写入逐单及用途核查，错误返回409且不改状态，正确提交和原成功请求恢复继续。旧已完成记录读取保留。

9. **新形象让商单候选整页为空**：补齐公开艺人真实前置后复现，旧解析要求形象本身至少1份素材；新版素材保存在LOOK/VOICE。两端按真人关联、档案状态、未启用供应商和空材料格式严格兼容，旧格式仍拒绝空材料；不以空数组代替实际授权或产品准入。4份旧检查脚本同步按名称选择，完整9组及两笔商业订单各14步、机构网页交接16步通过，详见[补充报告](../../testing/evidence/ci-selector-repair-20261104/REPORT.md)。

## 测试环境补全

- 不同浏览器分配不同的合成业务资料；同一浏览器切岗位仍在自己的资料内，另一浏览器不能覆盖其订单和反馈。验证账号、个人/机构身份都不跨席位重复。资料不足明确提示，不回退共用账号。
- 席位分配随反馈持久保存；服务重启、增加新席位不改变原访客账号。替换或移除旧资料拒绝恢复，不静默换人。需要恢复整个环境时，业务库与附件、反馈批次都须恢复。
- 最新前端b0ed8878重建后，16个岗位入口及实际切换已核；测试App网页模拟付款、付款后反馈和三段样片播放通过；浏览器重启后账号和原反馈恢复通过。
- 自动检查用资料与人工新资料分开；不把跑过退款、注销和换号的账号直接交甲方当全新账号。凭据和启动配置仅放本机忽略目录，不进Git。
- 仅本机测试；新公网窗口尚未开放，旧窗口不自动延长。昆山真实服务和OSS仍关闭。

## 原文与流程补全

[28号“知情、决定权”](../../sources/contracts-20261029/extracted/28.md)原文：“清楚知道收集什么、为何收集、共享给谁；可限制处理范围、拒绝非必要授权。”据此，生效限制后不能继续以受限依据批准新钱账；具体事务检查位置、解除后原申请恢复属于实施补全，不新增退款比例或改写历史合同。

[19号第三条](../../sources/contracts-20261029/extracted/19.md)原文：“平台不提供用户自助式深度 AIGC 生成。”本轮按人工需求、报价、制作和交付验证，不向客户开放视频模型API。

用户要求甲方无需邀请码、无需业务路线下拉列表、自行操作；[今晚计划](../../collaboration/client-complete-20261028/TONIGHT_EXECUTION_20261104.md)具体写明“不要求甲方复制内部编号，不靠开发者改库解锁流程”。客服报价、机构选择、多人隔离、模拟回执和备份恢复均为达到这一目标的流程补全，不冒称甲方合同逐字指定了接口或数据库结构。
