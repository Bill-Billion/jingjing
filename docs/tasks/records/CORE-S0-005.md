## 这次实际做了什么

- 外部服务“配置填了”和“实际验证通过”分开记录。状态保存到MySQL，附上环境、用途、配置版本和证据引用；停用时保留历史，换配置后不能沿用旧证明。
- 写好六类服务共用的调用入口和私密OSS文件接入。缺代码、缺配置、缺验证或缺权限都失败，不假报成功；超时不自动重复付款等操作。
- 修复旧存储默认公开和配置不足回退本地的问题。本地仅能保存明确标成公开的测试文件，不能生成假的私有链接。
- 每个网络请求分配查找编号，调用和错误日志保留关联编号，不保留敏感正文。服务器能响应与是否具备必要运行条件分别检查。
- 新增的检查已纳入每次上传代码后的自动测试。
