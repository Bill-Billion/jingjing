## 实际验证

本机MySQL8.4、Node22隔离全套263通过，1项缺脱敏旧库样本跳过；本模块25项通过。专项与全套重叠，不能相加。40份实际许可HTTP返回通过候选0.5.0-rc.1校验；其他四组已有HTTP也复核。外部私有存储使用内存替身，不作为真实OSS验收。

检查覆盖：无权限、自审、外部事实不一致、未核验、重复收款凭证、重复请求、跨版本独家并发、项目额度并发、历史改价、下架、预留超时、阅读撤销/过期、文件损坏、项目改稿、许可暂停、审核权限撤销、审计失败事务回滚。

开发中发现并修复：不冲突结果空值；独家锁由共享锁升级导致竞争；发放许可的审核人员被误当买卖方阻止后续暂停。首次测试曾因本机MySQL尚未启动就绪失败；后续重试及全套已通过，不掩盖初次失败。

## 验证与启用的界限

没有真实人员授权、真实签署/付款/实名核验、生产访问、收费调用或部署。人工核验外部材料不会产生支付通道成功状态。需要核验真实证据后才能正式使用；供应商自动验签、支付、制作、退款与发行后续继续建设。

地区和语言只按明确的规范代码及全域标识比较，不理解自由文字法律含义。预留时长、条款、价格、项目和集数额度均需显式输入；实现中的输入上限是防止异常数据的技术限制，不是推荐套餐。日期影响实际使用，状态文字不能覆盖到期规则。
