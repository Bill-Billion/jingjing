## 流程补全与实施决定

- 复用现有 Flutter 工程、AccountTheme、本地图像字体和五栏导航；独立离线启动入口与 Android 应用标识。现有整页依赖服务器合同，离线选定页面由独立本机服务支撑。
- 五个虚构账号：普通客户、艺人本人、机构负责人、机构成员、出品方。账户切换操作同一本机SQLite数据库，角色动作仍检查权限。
- 祝福为人工定制示例，模拟报价、30/40/30付款、剧本/样片/粗剪/成片和收讫；本机按钮推进模拟平台工作。
- 预置照片与原创抽象演示短片；界面明确标注演示。选取的本地文件复制到应用私有目录。
- 参演用独立项目，从报名、模拟筛选、本人确认约定到项目进度，不把试镜或通告兴趣自动转成参演。
- 通告从草稿、角色要求、提交、模拟审核发布、艺人投稿到兴趣/婉拒和客服待办；机构为资料与成员邀请/接受/授权/移除。
- 演示金额、时长和约定是标注的虚构样例，不修改正式合同和接口规则。
