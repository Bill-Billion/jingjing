## 这次实现与选择

- 所有申请关联原订单、购买身份和出票方。金额依据已核实的收款记录，扣除已退、待退和其他申请占用；不从标价、优惠券或未经核实的付款状态推断。来源校验失败时明确不可核实，不返回假0元。
- 先锁原订单，再锁申请；并发申请不能超额。同编号相同内容重试返回当前申请，不把已撤回申请恢复。版本有变化须重新核对。
- 补件新增历史和引用，不覆盖旧材料；申请与票据引用均进入隐私删除依赖说明，未编造法定保留期限。
- 受理和票据核准使用单独权限，不自动发权。购买方不能自己审核；录入者不能核准同一文件。待核文件对申请人不可下载。
- 出具前可撤回，释放占用。已出具后只能请求更正；退款改变可开金额时提示处理。新更正另存不可变内容快照，旧票据标历史；归零更正只改开票占用，不代替退款。
- 模拟凭证由服务器生成文字文件，不允许上传一个看似正式发票的测试文件再对外声称已出票。正式人工PDF需可信服务端配置的出票方、版本、核验依据和有效期；配置变化会挡住旧待核文件。此分支只用隔离合成资料测试，无税务外部调用。
- 文件不返回公开或长期签名URL。下载核对记录权限、文件校验值和隐私限制，读取存储后再查一次权限，防止下载途中撤权仍泄露文件。
- 开票通知沿原订单进入，通知不包含税号、抬头或文件。原支付、退款、合同、个人中心及旧接口保持兼容。
