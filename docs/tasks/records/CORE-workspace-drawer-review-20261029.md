## 发现的问题与本侧修复

- 远端该提交两个网页作业失败，均在短信登录后等待已不存在的旧菜单按钮；其余 7 个返回的作业成功，不能称全部通过。
- 短信检查改为验证收起时身份可操作、展开抽屉、Escape 关闭及焦点返回。关闭短信、重复点击、错误验证码、正确登录和退出检查全部保留。
- 公共浏览器辅助函数改为操作真实抽屉按钮。报价、制作、商单、项目、财务、通知检查进入页面后先检查菜单可开关，再收起办理业务；检查菜单链接时明确展开。没有强行点击遮罩后的控件，没有删掉权限或交易断言。
- 故事浏览器检查补上“写文件失败→回列表重开→从抽屉去艺人页→等同账号资料重新读取→返回→恢复原附件→保存”。同一故事和附件贯穿，记录数量、摘要、字节数和私人草稿状态都核对。

本次只修验证工具，不改队友产品页面、不改公共业务规则。队友无需为本次工具修复修改页面。
