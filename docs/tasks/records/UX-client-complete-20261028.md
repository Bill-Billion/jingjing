# PR39 前端业务补齐

2026-10-28，用户明确要求按前述分析开发未完成前端、按 PR39 任务补齐业务页面。本侧 Bill-Billion 接手 18 项前端任务，从 `fa444c64` 开始，在 `ux/pr39-frontend-complete-20261028` 实施，集中更新 PR39。后端原负责人及任务认领保持；本轮没有修改接口、数据库、支付权限或部署配置。

**当前交付是可用接口范围内的前端增量，18 组整体验收仍未完成。** App 与 Vue 已补真实业务入口和交互；收藏、开票、换号等正式能力仍缺后端契约，不能由页面伪造完成。用户已明确回复“由同事补后端；本轮完成前端并交接接口需求”，本轮按该分工实施。

## 已落地

- App：通用表单离页确认、同页多表单单次确认、滚出屏幕后保留输入；切换人物、人数、发布类型和规则前确认。未知写入仍保留原键、原内容并要求恢复核对；成功后清除未提交标记，身份改变清掉私有输入。
- 登录回到已注册的本地业务页，保留试镜预约、邀请、城市等参数；回跳仅重新读取页面，不自动重放业务写入。外部地址、未知路径和递归登录不放行。
- 广场换城同步试镜和通告保活页面；用户手动设置的本页筛选优先，可选择恢复广场城市；旧城市的慢响应不能覆盖新结果。搜索入口补试镜，作品入口保留城市，接入实际支持的目录筛选。
- App 正常字号支持系统 2 倍缩放并保留非线性缩放。消息系统频道接入当前身份的真实最近通知，进入详情逐条已读，不把当前页记录数当总未读；新增按业务分类的合同、作品和收入目录，返回原单办理，不拼接总金额。
- 现货与试镜新申请不再从旧商品推断当前有效规则或机构授权。保留本人已发布 SPEC 查询、资料准备、填写、草稿保护与未知原请求恢复；缺有效规则时明确禁提交。被退回商品展示原审核原因及“关联新修订尚未开放”，不把重审旧内容当修改重提。
- 已提交故事可直接进入共创并预选原故事；建房展示故事、规则和承制方准备状态。共创与隐私补离页保护及上一页；隐私请求展示可读对象、状态、下一步和执行记录，明确单项处理与全部删除不同。
- Vue：草稿在切事项、切路由、身份变化和关闭页面时保护；字段校验给具体原因并定位；列表支持上一页、下一页以及详情返回后恢复筛选与页位置；按已确定的状态和主体关系限制动作，未知权限交由服务器核验。
- Vue 新增本人故事入口与独立页面：实际分类选择、新建和保存草稿、重开续写、正式提交、逐项补件及正式版本历史。本人身份与运营收件分开，私稿不写浏览器持久存储；结果未知保留原请求，版本冲突后即使读取失败也能保留新稿重读，核对前禁止写入。附件尚未开放时保留真实限制。
- Vue 目录增加共享默认城市，艺人及支持城市参数的业务目录跟随；本页筛选优先，允许恢复默认，换城清理旧游标并丢弃迟到响应。保留其余筛选与返回位置，不增加未经支持的关键词或定位。
- Vue 接入 `submission-options`、`invitation-context` 和当前公开艺人详情。具体通告投稿使用匹配授权；本人无通告主动投稿保留既有合法路径。邀约回包重新合并当前表单，保留等待期间编辑的正文，身份、来源或规则变化使旧回包失效。公开媒体在失效后清除。

## 下一步交接

Core 先交付 01/02/03 与 15 的最小选择和修订上下文，再按表内依赖补剩余正式接口。已有完整范围与暂定规则见 [双方任务入口](../../collaboration/client-complete-20261028/README.md)，本轮具体接线要求如下：

- **首次销售/试镜**：现有 `GET /trade/records?kind=SPEC`、`POST /stock/listings`、`POST /auditions/offers` 保留。请提供当前办理身份可选的生效规则、规则版本、本人/受托人物与对应用途的最小授权上下文；提交时重新校验停用、撤权、有效期和主体关系。不能依赖已经存在的商品来找到规则。
- **机构授权**：现有 `submission-options` 仅覆盖合作投稿。销售许可与公开展示需各自返回当前身份可读、当前人物和用途可用的选项，不能要求机构读取完整私人 CONSENT。选项包含供页面展示的可读名称、范围、有效期及提交所需引用，具体字段以同版 OpenAPI 确认为准。
- **商品修订**：明确关联原商品的新修订创建、暂存、提交及审核状态；保持原已售许可与原内容引用，退回原因可读。前端目前仅能显示原审核结果，不能把 `REVIEW_AGAIN` 当成修改内容。
- **故事与共创**：现有文字草稿、正式提交和补件契约继续使用。附件需受控上传、读取、撤权与保留规则，接口当前拒绝 `PRIVATE_ATTACHMENT`。本人首次建房需要可获准选择的承制方和规则；自由创作模板不能在前端凭空生成。
- 每项接口同时交付角色/权限、分页、版本冲突、幂等及未知结果恢复约定，以及空账号首次办理、权限收回、规则过期、审核退回的隔离示例。App 与 Vue 应接同版契约；未约定路径和字段不在本轮前端虚构。
前端接入同版契约后，以同一组业务记录重跑成功、退回、撤权、过期和结果未知路径。当前 151 项接受标准仍不标整项 PASS，严格定版检查应继续拒绝放行。
