## 已写好并检查的内容

- 商品规格、价格和报价按版本保存；明确每个付款节点和明细金额。买方确认内容摘要后封存合同，历史承诺不随新价变化，封存不代表签署。
- 支付尝试先持久保存再调用外部渠道；超时未知不盲目重发；支付查询仅本人订单可调用；平台签名、环境、应用、商户、订单、金额、币种、Apple商品/交易绑定分别核实。
- 实收和退款事实独立保存；重复通知不会重入账；真正重复扣款、迟到或取消后收款保留事实并转人工处理。
- 退款申请先占用付款明细额度，独立审核后执行，核实结果后入账。Apple完整退款单独核验，未知或撤销不猜结果。并发超退被拒绝。
- 旧99/4901金额、原承诺和材料保留，原报告已付不变成真实到账。旧接口继续禁用写入；这不替代完整旧库迁移。
- 许可费关联订单后，未到账不能发放；退款后拒绝新增绑定或改稿。签署、身份与权利核验继续使用第五阶段逻辑。制作样片与成片验收缺失时拒绝对应尾款。
