## 实现与使用

网页通过工作台的“合同与规则”进入，也可打开 `/contracts/<合同编号>`；App 通过“我的账号→读取指定合同”或 `/#/contract?snapshotId=<合同编号>` 进入。未登录时先登录、选择本人办事身份。页面只读取获准查看的指定合同，不编造合同列表。

两端均显示保存的承诺、合同编号/来源版本/参与方、封存与未签署状态、内容校验值、该合同引用的历史规则，以及支付/实名/电子签/数字人服务条件。正文按字段、段落和数组原样显示，保留零值、false、null 与 HTML 文本；编号可复制。读取失败、身份或目标变化使旧内容失效；不将正文保存在本地存储。

App 使用局部暖白、赤陶色主题；网页采用浅色、墨绿主操作。颜色、字体、间距、按钮、卡片及失败状态形成后续页面基础。旧业务页面按后续业务批次逐步采用，不把尚未实现的订单、付款或签署按钮加进本批。
