## 用户现在能办什么

- 当前MySQL版没有向客户开放旧视频生成接口；本轮另封堵旧服务器的直接视频生成写入口，已登录也返回人工定制说明，不调用模型。
- 隔离资料可发布“祝福短视频（人工制作）”需求表，客户填写用途、称呼、祝福内容、期望时长/日期和私有材料；草稿仅本人可读，正式提交后平台受理。它复用原定制流程，不是拍同款模板库。正式商品价格和上线启用未擅自设置。
- 开票接口现在根据当前操作人的岗位和记录状态给出可办动作，录票人不能自己核准。前端已有表单可据此复验，完整运营页面尚不能仅凭接口测试标为验收。
