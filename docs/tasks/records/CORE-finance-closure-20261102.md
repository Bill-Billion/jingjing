## 流程补全与暂定实现
- 对账日按北京时间的已结束入账日；分开记录渠道发生日和平台入账事实，晚到记录触发重查，不追改旧已审结果。
- 每批固定主体、支付渠道、应用/商户编号和测试/正式环境；不同账户/环境不得混算。当前渠道能力按既有代码声明，不因对账支持某类文件就冒称开通清分。
- 程序能直接核验收款/退款和有审核回执的分账事实；手续费及银行凭证须有独立来源材料和人工复核，标注人工核验部分，不伪称自动银行直连。
- 缺一类账单、差异未消除、事实发生变化时不能结案；零交易也须有完整性说明及凭据。修正只产生新版本，不写回支付成功或替外部机构转账。
- 单批/分页设明确技术上限，请求可分批追加；整个日账事实超限明确拒绝，后续需扩展容量，不能分段冒充完整结案，不能静默截掉记录。所有金额使用分，校验安全整数。
- 原151标准与本轮新增合同标准分开记录。局部接口/页面通过不替代跨端完整验收。
