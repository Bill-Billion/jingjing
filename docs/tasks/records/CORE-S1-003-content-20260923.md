## 这次完成了什么

- 创建规则内容版本，保留原文和校验值；改变源对象不会改变已封存内容。
- 保存合同当时采用的规则副本、当事方和承诺；后来更新或停用规则，旧内容仍能核对。
- 拒绝草稿、待审、仅批准但尚未生效、未来生效、已停用规则用于新的封存，拒绝同一规则混用两个版本。
- 拒绝异常内容，发现保存后条款、当事方或内嵌规则与校验值不一致。
- 封存只表示内容留存，固定为未签署，不补价格等未知参数，不产生付款或授权成功状态。

这是一组服务器内部工具，尚无数据库保存或页面可调用接口。输入状态、合同存在性、操作权限需要后续可信服务层验证；不能让客户端自报“有效”就直接使用。校验值不等于签名或公证。

## 测过什么

新增内容专项15项通过，既有不依赖数据库的账号权限规则6项通过。测试包含同内容不同键顺序、中文及表情、异常数值/文本/循环/访问器、历史承诺不变、有效时间、冲突版本、篡改和未签署边界。测试素材明确为合成示例，不是商业默认规则。
