## 实施补全和默认边界

- 7日按7×24小时记录；到期仍可补双方交接记录，不能借此恢复机构权限。捕获旧单不是重新授予人格授权。
- 48小时是新规则版本。现货未付款/未交付、试镜材料不可用或争议不允许自动完成；纠纷经独立处理恢复后重新给予完整窗口，保留原事件。此为保障办理的补全。
- 未开推荐计划的分账referral_bps=0可保留，但不能作为已启用的10–15%推荐计划。实际归因仍要求成长与分账规则一致。
- 监护时长、单笔/日累计金额来自已审规则；无规则不猜数字。合成测试30分钟/1元等不代表正式方案。一分钟预留时段是防并发超时的实现，不是合同约定；重放原请求不重复计时。休息提醒由接口提供阈值供页面显示。
- 适龄内容池采用独立审核名单，只能读预览；不开放一般成人目录、私人故事或付费文件。真实儿童采集、经营和收费关闭。监护消费同意不能转成实际扣款。
- 未成年退款先核实关系和事实，再进入原支付退款/独立复核/回执；保留实际支付和退款上限，普通商品售后门槛不能否定已核实的未成年专门退款申请。
- 注销延期须证据、理由和另人复核，原截止保留；完成须账户已关闭、处理任务执行完、必要删除及保留依据已核对。公开提示和实际办理依赖甲方真实联系/保留资料，不能伪造完成。
- 侵权24小时是运营目标，允许配置未来新案；先冻结再有选择送达，内部意见和未获准证据不交给另一方。只在站内记录送达，不冒称短信或司法送达。
