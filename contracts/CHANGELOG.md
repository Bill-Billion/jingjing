# 契约变更记录

## 0.3.0-rc.2 — 2026-09-24（待共同审阅）

- 新增合同后续动作必要外部服务条件GET，复用合同读取权限。共25操作/62结构，20操作隔离实现、5未实现。旧账号及合同内容格式不变。
- NOT_ENABLED带原因；SERVICE_READY仅表示必要服务条件就绪，不代表业务授权、签署或付款。环境来自服务器，前端不能自报已验证。当前启动入口默认未启用这些商业动作。
- 后台录入/复核/封存通过受控工具和实际会话，不提供写入HTTP。迁移新增至0028；真实订单、支付、签署及前端联调仍在后续范围。

## 0.3.0-rc.1 — 2026-09-23（本地候选）

- 新增合同未签署内容读取和指定历史合同中的规则内容读取两个GET；原0.2接口不变，共24操作/60结构，19操作已隔离实现。
- 每次校验登录、当前身份成员关系、合同当事方范围与该合同的独立读取名单。机构成员不自动获得合同内容；规则查询必须给出获准读取的snapshot_id。
- 返回实际保存的JSON内容与校验值，不编造文件asset ID；两个旧文件元数据接口仍未实现。客户端将条款作为文本展示，不把任意条款字符串作为HTML执行。
- 只有未签署内容读取；不提供网页自行创建、批准、签署、付款或授权入口。无写入兼容迁移要求，但服务器启动前需应用完整0015–0024升级。
- 第11份账号代码仅作为明确待审依赖合入本地；本次未改变其远端状态，未宣称新格式已获评审。

## 0.2.0-rc.1 — 2026-09-22

- 账号API实现短信申请、登录、退出、本人资料/身份分页、机构创建/改名、能力申请、成员查看/移除、邀请创建/响应/撤回；复用探针，共17个操作隔离测试。其他5个操作继续未实现。
- 新增9个操作、14个Schema；保留0.1既有请求/响应格式。新增SmsProvider枚举；前端遇到未知供应商或动作应保持禁用而非崩溃。
- 作用域明确：新账号级接口不需要X-Acting-Party，机构/个人主体路径需要与头部一致。邀请响应、撤回和成员移除要求If-Match；创建不要求对象版本。
- 新登录会话为数据库保存的随机不透明令牌，不接受旧JWT；前端切换到新API时需重新登录，不能把旧SQLite用户编号当新账号UUID，不自动迁移旧身份。
- 新增HTTP实际响应校验；隔离测试只替换短信发送，HTTP、MySQL和权限真实运行。真实短信、浏览器/App联调和正式启用尚未验证。
- 本次新增共享格式仍待另一方检查，未宣称已合入。配置、限制和测试见第二阶段交付说明。
